# AI 协作记录：预测被实测否定后的诊断过程（2026-10-21）

> 本文件记录"B 的模型预测 → A 的实测否定 → 归因"这条链路上的判断与纠错，
> 供赛事"大模型协作与自我纠错轨迹"一项使用。
> 结论与证据在 `report/verification/asg-field-2026-10-21/`，本文只记录推理过程。

## 1. B 给出的预测与依据

用 A 交出的三个标定文件，B 于 2026-10-21 得出：

| 项 | 预测值 |
|---|---|
| 路径峰值 | +26.06 dB @381 Hz（H1 估计，相干 0.970） |
| 旁路起振 | −26.1 dB |
| 抵消起振（256 抽头） | −12.5 dB |
| ASG | +13.5 dB |

并据此给出三个现场点位（−32 / −24 / −12.5 dB），要求 A 在 −24 dB 上看到
"旁路啸叫、抵消安静"。

## 2. A 的实测否定

- 旁路要到 −19.5…−18 dB 才起振（比预测高约 7 dB）。
- 抵消在 −19.5 dB（人声，10 s 窗口）就起振；把窗口从 2 s 拉到 10 s 后，
  2 s 的结论整体推翻。
- 起振频点：抵消 232 Hz（噪声）/ 274 Hz（人声），旁路 423 Hz；381 Hz 两次都没起振。
- 由两条不等式反推：`max|H−Ĥ| ≥ 19.5 dB`、`max|H| < 18.0 dB` ⇒ `CD_worst ≤ −1.5 dB`。

**符号错了，不是量级差了。** 这个否定是决定性的。

## 3. 归因：先排除的三个方向

A 提出的候选解释是"256 抽头 = 5.24 ms，频域分辨率约 190 Hz，200–300 Hz 只有一两根谱线，
Ĥ 在低频相位误差大"。我把它拆成三个可独立检验的方向，逐个排除：

| 方向 | 检验方法 | 结果 |
|---|---|---|
| 滤波器太短 | 抽头 128/256/512 在**同一失配条件**下比 ASG | 512 比 256 **更差** 1.3 dB |
| 低频分辨率不足 | 200–300 Hz 子带单独看 | 该子带确实最差，但 1000–3000 Hz 同样差；不是低频特有 |
| 估计器不好 | 把**已知真值**截断到同抽头数，与拟合模型比 | 差 0.15 dB，拟合已在最优附近 |

三个方向共同的错误前提是"模型结构不够强"。真正的变量是**输入**：
标定时的 H 与使用时的 H 不是同一个 H。

## 4. 决定性的一步：只用一个自由参数

把实测旁路阈值当作唯一输入，反推耦合比 β：

```
β = 10^((18.00 − 26.06) / 20) = 0.395   (−8.06 dB)
```

此后 β 没有任何可调余地，用它去算**抵消**阈值：

- 预测 `max|H−Ĥ| = +21.6 dB` ⇒ 抵消应在 −21.6 dB 起振；
- A 实测 ≤ −19.5 dB，即 `max|H−Ĥ| ≥ 19.5 dB` → **一致**（预测值不小于观测下界）；
- 逐频点的相位过零点预测 262 / 417 Hz，A 实测 274 / 423 Hz → 偏差 ≤1 个 FFT bin。

**一个参数解释了两个互相独立的观测量**（旁路阈值、抵消阈值），再加起振频点。
这是"幅度失配"比"结构不足"更可信的核心依据——后者只能解释其中一个。

CD 为负的机理很直接：Ĥ 按强 2.5 倍的路径拟合，减得过深，
`|βH − Ĥ| > |βH|`，残差比原环路更强。

## 5. 本轮修正的三处技术错误

记录在这里，因为它们都会以"看起来合理的数字"形式出现，下次很容易再犯。

**① 相位过零条件写得太宽。** 第一版判据把"相位接近 π 的整数倍"也算作候选，
导致几乎每个频点都成为候选（输出间隔 12 Hz，而正确间隔应接近 fs/延迟 ≈ 688 Hz）。
当时的输出"命中 274 Hz"是假命中。改为真正的 2π 穿越判据后，候选收敛到
262 / 691 / 1347 Hz，反而与 A 的实测吻合。**先怀疑判据，再相信命中。**

**② 差点做了循环论证。** 初版把"用 A 的旁路阈值定 β，得到旁路阈值与 A 一致"
当成验证——那是把同一个数搬了两次。改为"用 β 预测**抵消**阈值"才是真检验。
判断标准：这个一致性里，有没有第二个未被使用的观测量。

**③ 整数闭环模拟的发散判据有缺口。** 试图用 `closed_loop_sim` 复现实测阈值时，
发现高增益下 ADC 削顶会让环路"不再增长"，于是被判成稳定；同一份数据里
g=−20 dB 判发散、g=−10 dB 判稳定，非单调。已修掉麦克风满幅未计入判据这一条
（与 A 的实测判据口径本来就该一致），但非单调性未消除，本轮结论**未依赖**
`find_msg`，只用频域口径。已写入 STATE 的未验证项。

## 6. 可复用的判断

1. 预测与实测不符时，先问"**输入条件是否相同**"，再问"模型是否不够好"。
   这次两边 `fixture_id` 与 `hp_volume` 都相同，但**摆位没有记录**，
   差异正是从这里来的。
2. 标定数据的 metadata 必须记录会改变耦合的一切：麦克风型号、Codec 输入选择、
   两只换能器的坐标、功率放大器旋钮位置。缺一项，标定就只能当次有效。
3. 起振阈值对幅度失配极其敏感：**耦合弱 6 dB（β=0.5）就让 CD 从 +13.5 dB 翻到 −0.3 dB**。
   这个容差要在设计阶段就写进指标，而不是等实测才被发现。
4. 更长的滤波器在失配时更危险，不是更安全。这与"抽头越多越好"的直觉相反。

## 7. 后续：这条诊断链为什么断了（2026-10-22）

A 查明有源音响会待机。上一节的 β 因此作废。这里记录断在哪、下次怎么避免。

**断点一：用"没发生"的事件做定量反推。**
β 的唯一输入是"旁路 −18 dB 跑满 10 s 没叫"。这个观测至少有三种解释：
耦合真的弱 / 音响待机使回路断了 / 10 s 还不够长。当时只考虑第一种。
负向观测只能证明"不很大"，**不能定出具体数值**。
而且我拿它去"验证"抵消阈值时，抵消那次起振若发生在音响在线时是真的——
两个观测可能来自不同的音响状态，那个一致性是巧合，不是验证。

**断点二：把"相位与幅度无关"从旁路推广到了抵消。**
旁路 `H_eff = βH` 是纯缩放，相位确实不变（β=1 与 0.395 的候选都是 417 Hz）。
但抵消 `H_eff = βH − Ĥ` 是两个矢量之差，β 改变相对长度就改变合成相位
（β=1→226 Hz、β=0.5→274 Hz、β=0.395→262 Hz）。
所以"262 Hz 命中实测 274 Hz"这条也同样依赖 β，一并作废。
**判断一条结论是否依赖某个参数，要看它在这个参数变化下是否改变，不要凭直觉分类。**

**断点三：没有把"传感器是否真的在工作"当作前置条件。**
所有判据都读麦克风电平，而"音响待机"与"耦合很弱"在电平上无法区分。
唯一可靠的区分是正向对照（直放一段已知电平，确认麦克风响应在基线范围）。
这条必须排在任何现场测量的第一步；否则后面每一张表都要重做。

**保留下来的**：标定数据本身（与 β 无关）、标定条件下的模型能力、真值截断测试、
旁路起振频点的相位预测，以及 A 的所有正向观测（"叫了"不会因待机而假阳性）。
