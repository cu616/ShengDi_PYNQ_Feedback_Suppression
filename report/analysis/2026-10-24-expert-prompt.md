## 提示词正文（从下一行开始复制）

你是一位有硬件与声学工程经验的资深工程师。下面是一个已经运行了数周的 FPGA 声反馈抑制项目，
我需要你**独立复核它的结论是否成立、瓶颈判断是否正确、以及是否还有我们没想到的路线**。
请**不要客气**，如果我们的推理有漏洞请直接指出。

### 背景

- 平台：PYNQ-Z2（Zynq-7020），PL 100 MHz。
- 采样率 48828.125 Hz。
- 通道：MAX4466 模拟麦克风 → 板载 Codec `LINE_IN`；板载 Codec `HP+MIC` → 惠普 NS1 Pro 小音箱。
  `hp_volume` 已设为最大 40。**麦克风型号不可更换（端口限制），音箱也不打算换。**
- 现场：桌面 0.5 m 间距，1 只音箱，无封闭箱体，可调整到 0.5–1.0 m。

### 当前算法

```
residual[n] = mic[n] − (Ĥ * played)[n−2]      // cancel 模式；bypass 时 residual = mic
played[n]   = sat(gain · residual[n−2])        // gain 为环路内增益，可取 −18…+18 dB
```

- `Ĥ`：512 抽头 FIR，`lag_first = 1`，10.5 ms 记忆；BRAM 已占 80%，无法再加大抽头。
- 标定方式：白噪声数字注入，最小二乘拟合 `Ĥ`；固定模型，**没有自适应（无 LMS）**。

### 已测到的关键数字（都可复现）

1. 标定批次上的抵消量 CD = 20log10(|H|/|H−Ĥ|)：300–1000 Hz +12 dB、3–6 kHz +19.7 dB、
   **8.2–8.6 kHz +29 dB**。即模型在其标定批次上是准的。
2. **同增益对照**：增益 0 dB、同一代码路径，`Ĥ=0`（普通扩音器）时环路顶到满幅（mic −1.2 dBFS）；
   用真模型时稳定（mic −35.4 dBFS）。→ 抑制确实来自抵消。
3. **会话传递**：同一方法复测现场 H，8.38 kHz 处 |H| 从 11.13 dB 降到 5.15 dB，相位变 +39.5°。
4. **夹具电平重复性**：6 次完全相同的 1 kHz −20 dBFS 定音，麦克风 RMS 极差 **4.71 dB**（σ=1.59）。
5. **物理降耦**：麦克风侧放使宽带 |H| 下降 **5.72 dB**，但可用增益只涨 **0.85–1.62 dB**
   （限制点从 441 Hz 移到 358 Hz，该处 CD 从 +12.3 降到 +8.2）。
6. **前向带限**（300–3400 Hz 带通，6 阶）：把 8.2–8.6 kHz 的环路项压到 −35.75 dB，
   但可用增益只从 +3.65 到 +3.89 dB（限制点 381 Hz 在通带内）。
7. **抽头/抽取扫描**（拟合在抽取域，14 训练 / 6 留出）：
   8× 抽取下 384/768/1536/3072 抽头（63/126/252/503 ms 等效记忆）对应 300–1000 Hz 残差
   **−12.83 / −12.27 / −12.53 / −7.49 dB**；16× 抽取更差（−8.44 / −6.94）。
   即**记忆长度不是瓶颈**，残差地板约 −12.8 dB，由该频段相干 0.87–0.89 决定。
8. **上板实测**：0 dB 稳定 2/2；+3 dB 稳定 1/2（另一次啸叫，峰值 −1.7 dBFS）。
   多次观测到的"起振主频 9131 Hz"经查是**音箱/房间共振**（开环标定段也有 8744 Hz、Q≈293 的峰），
   不是环路自激；真正的限制点是 358–441 Hz。
9. **真实人声扩声未成功**：−15 dB 时只有嘶声（播放电平比原声低 15 dB，本质是衰减）；
   −9 dB 时白噪声为主并伴随轻微啸叫（环路处于临界）。

### 我们的结论

- 抵消把环路稳定的增益上限从 **−6 dB** 提升到 **+11…+13 dB**（两条独立路径交叉验证）。
- 但要让听众"听出放大"，需要约 **+20 dB**；**差距约 9 dB**。
- 该差距不能靠：加抽头/抽取（地板由相干决定）、前向带限（限制点在通带内）、
  物理降耦（只兑现 1/4）——三条路都已用数据排除。
- 唯一剩下的两个方向：提高低频相干（把 0.87 提到 0.95 理论上可到 +15 dB）、
  或提高音箱的声效率（硬件）。

### 我请你回答的问题

1. **上面第 9 条（差距 9 dB）的判断是否正确？** 我们的"可稳增益"用的是小增益判据
   `max|gain·(H−Ĥ)| < 1` 加上相位穿越判据，是否高估或低估了真实可用增益？
2. **"残差地板由相干决定、不由抽头决定"这个推断是否成立？** 如果是，
   在**不存在自适应**的前提下，是否还有可能把低频残差从 −12.8 dB 推到 −18 dB 以下？
   例如：更好的激发信号、多电平平均、正则化、非线性拟合、或用多个麦克风？
3. **在固定 512 抽头 / 无自适应 / 麦克风与音箱都不可换**的约束下，
   是否还有我们没想到的架构或信号处理手段能把可用增益抬高 6–9 dB？
   请具体到可实现的结构，不要泛泛而谈。
4. **自适应反馈抵消（AFC，助听器的标准做法）** 在这个平台上值不值得做？
   我们 BRAM 只剩 20%，PL 有空间。以我们的耦合强度（|H| 最高 +11 dB、0.5 m 开放、
   房间混响），AFC 的收敛与稳定性会遇到什么问题？
5. **"听众能否听出放大"这个验收判据**，我们用的是
   `ratio = gain × 音箱对听众效率 / 声源对听众直达`。这个建模是否合理？
   有没有更合适的判据（例如可懂度、信噪比增益、或直接测听众位置的声压差）？
6. **如果我们必须在一个月内交付一个能演示的东西**，你会建议把目标改成什么？
   （例如：不追求净放大，而是演示"同样的增益下不啸叫"，并给出可稳增益的量化提升。）

### 请你给出

- 对上述 6 个问题的明确结论（同意/不同意/证据不足）。
- 如果有更优路线，请给出**优先级排序**与**每条的预期收益、实现代价、失败判据**。
- 指出我们数据中**任何自相矛盾或可能错误的推断**。
