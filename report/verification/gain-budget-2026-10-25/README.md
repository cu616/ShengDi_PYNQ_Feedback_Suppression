# 512 抽头能不能在最差频段给 15 dB？——增益预算（A 的提问，2026-10-25）

> 问题（A，`50f30dd`）：新布局（100 cm、侧对）净耦合 +3.0 dB；要让听众辨出扩声需 +6 dB 数字增益，
> 此时环路 +9 dB。**512 抽头、`lag_first=1` 的 FIR 能否在最差频段提供 ≥15 dB 抑制？**
> 本文件只用已有数据给数字，不新增采集、不改模型、不动系数。

## 0 一句话

**不能。** 在本侧唯一可复算的 16 段标定批上，512 抽头在限制点（435 Hz）的抑制是 **9.4 dB**，
允许的最大数字增益是 **+2.77 dB**；要 +6 dB 需要该点 **12.6 dB**（若新布局峰值为 +9 dB，则是 **15.0 dB**），
差 **3.2…5.6 dB**。加抽头也补不上：256/512/680 → 4.5 / 9.3 / 10.2 dB，且 680 装不进现有位流。

## 3 预算：+6 dB 数字增益需要多少 CD

全局绑定 bin = **435.1 Hz（相干 0.945）**，`|H| = +6.62 dB`、`|H−Ĥ| = −2.77 dB`：

| 数字增益 | 需要 CD | 现有 CD | 差 | 结果 |
|---|---|---|---|---|
| 0 dB | 6.62 | 9.40 | +2.77 | 够（与 A 实测 −14…−8 dB 才稳不矛盾：那是峰值处） |
| +3 dB | 9.62 | 9.40 | **−0.23** | 临界，环路 +0.2 dB |
| **+6 dB** | **12.62** | 9.40 | **−3.23** | **环路 +3.2 dB，必然啸叫** |

换成新布局的量级：A 测得宽带 +3.0 dB，我这批的峰值/宽带比是 6.62 − 0.38 ≈ 6.2 dB，
所以新布局峰值约 `+9 dB` → +6 dB 增益需要 `CD ≥ 15 dB`，正好等于 A 提的那个数。
我们这边能给 **9.4 dB**，差 **5.6 dB**。

这条对应关系也是自洽性检查：A 观测「0 dB 饱和 / −8 dB 再生 / −14 dB 稳定」把阈值夹在
(−14, −8)，与峰值 +9 dB 对得上（阈值 ≈ −|H|_peak）。

### 3.1 用 A 的观测反推"新布局峰值至少多少"——这一步不依赖新数据

A 报的三件事：宽带 `|H| = +3.0 dB`；0 dB 数字增益就饱和；−14 dB 才稳。
把判据 `g + |H|_peak − CD < 0` 代入：

- 0 dB 都稳不住 → `0 + |H|_peak > CD`。若新布局的 CD 与我这边同量级（9–10 dB），
  则 **`|H|_peak > 9.4 dB`**，比宽带 +3.0 dB 高 6 dB 以上，与一个房间峰/宽带比 6 dB 的常识一致。
- 要让 **+6 dB** 成立，需要 `CD > 6 + |H|_peak`；按 `|H|_peak ≈ 9.4…10 dB` 算，
  **需要 CD ≈ 15.4…16 dB**。A 提的"≥15 dB"正是这个数。
- 我们手上 512 抽头在最差 bin 的 CD 是 **9.40 dB**，差 **6 dB 上下**。

**所以结论不依赖"峰值到底多少"**：只要能 0 dB 就啸叫，就该点 CD 已经不够，+6 dB 只会更不够。

### 3.2 就算 435 Hz 被完全修好，天花板也只有 +6.4 dB

逐频查表（§2b）里，除 435 Hz 外最紧的是 **3898 Hz**：`|H−Ĥ| = −6.41 dB` → 该点允许 **+6.41 dB**。
也就是说 435 若被压到不出问题，下一个限制点是 3.9 kHz，`g_max` 只能到 +6.4 dB，
**给 +6 dB 留的余量只有 0.4 dB**。这解释了为什么"只修一个峰"也不足以换来宽裕的工作点。

## 4 加抽头能不能补上（逐段重拟合，训练 10 段 / 评估留出 6 段）

| 抽头 | 全局绑定 bin | \|H−Ĥ\| | CD@绑定 | 允许 g |
|---|---|---|---|---|
| 256 | 417 Hz | +2.90 dB | 4.50 dB | −2.90 dB |
| **512** | **435 Hz** | **−2.68 dB** | **9.31 dB** | **+2.68 dB** |
| 680 | 3910 Hz | −6.11 dB | 10.18 dB | +6.11 dB |

- 抽头翻倍大约 +5 dB CD，然后迅速收敛；680 只比 512 多 **0.9 dB**，而且**限制点跳到 3910 Hz**。
- **680 装不下**：单 MAC 每抽头 3 拍 + 3 收尾、帧预算 2048 → 上限 681；而 512 时 BRAM 已经 80%。
- 想靠抽头把 435 Hz 拉到 15 dB，按这个斜率要 **~2048 抽头等效（≈42 ms 记忆）**，是现有架构的 4 倍。

## 5 所以最小改动是什么（按"确定能用 / 不确定"分开）

**确定能用的（算术关系，不依赖新数据）**

1. **降需求**：`CD > g + |H|_peak`，每 1 dB 耦合下降或 1 dB 数字增益下降，需要的 CD 就少 1 dB。
   现有 CD = 9.4 dB（435 Hz）下，`g_max = 2.77 dB`；要让 `g = +6 dB` 成立，需要把该点 `|H|` 从
   +6.62 dB 降到 **+3.4 dB 以下**（即再降 **3.2 dB** 耦合，且新限制点不更差）。
   若新布局峰值确实是 +9 dB，则要再降 **5.6 dB**。
2. **不改架构的唯一出路就是这个**：既要 +6 dB 增益、又要 512 抽头，就必须让最差频点的耦合再降 5–6 dB。

**不确定的（需要验证，不能当承诺）**

3. **更长的记忆**：`8× 抽取 + 384 抽头`（6.1 kHz 域 ≈ 60 ms，等效 ~3000 抽头）理论上够，
   但本轮**没有可用的验证数据**——上一轮那个两级仿真已因拼段历史作废。要上必须先补可控实验，
   且它要改 RTL、要过时序与 BRAM，10/28 前不现实。
4. **前向陷波（已被 C 判过"EQ identity"，不重开）**：按这次的数据，只需在 **435 Hz 压 3.3 dB**
   就能把该点 `g_max` 从 +2.77 抬到 +6.0；但这时限制点立刻换到 **3898 Hz（+6.41 dB）**，
   所以"只陷 435"的天花板是 **+6.4 dB，对 +6 dB 只有 0.4 dB 余量**。
   要留 3 dB 余量，得同时陷 435 与 3898 到 +9 dB 量级，代价是语音 F1/F2 上的明显音染。
   ——这条只是算术结果，**是否重开由 C 与队长定**，本侧不擅自改前向通路。

**明确不建议**：新开 AFC / 频移 / 非线性架构——队长冻结令在前，且这三条都需要长开发期。

## 6 这个答案的边界

- 数据是**旧布局（0.5 m 正向）**，不是新的 100 cm 侧对。CD 取决于模型对 H 的拟合能力（模态结构），
  不随耦合绝对值等比变化——A 自己在 10-24 的侧放实测里已经证明：降耦 5.72 dB 只换来 0.85–1.6 dB
  阈值提升，因为限制点从 441 移到 358 Hz、那里 CD 只有 +8.16 dB。
- 所以**若新布局的最差频点仍落在 300–6000 Hz，答案是"不能"，差 5–8 dB**。
- **唯一可能翻盘的情形**：新布局的最差频点落到 8200–8600 Hz。这一段我这边的 CD 是 16.69 dB，
  但只有 5/67 个 bin 过门控，**属于未知区，不能据此承诺**。
- 本页所有数只在过门控 bin 上成立；不含听感、不含全程声学，也不构成 ASG。
