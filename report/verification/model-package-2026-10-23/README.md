# 2026-10-23 模型口径复核与交付包（B 线）

本轮按新分工（`docs/lines/b-algorithm.md` §4）复核四项会影响模型选择的分析问题，
并交付 C 可直接集成的模型包。数据：`manifest/`（房间 0.5 m，6 段旁路直采，−24 dBFS RMS，
mic −25.1 dBFS，延迟全 125）+ `candidate_room_v1_256_final(1)/`（独立场次，4 段可用，
mic −12.9…−14.6 dBFS）。

## 1. 因果延迟：四项可执行检查全部一致

`python scripts/check_causal_alignment.py --taps 256|512`（证据 `01-causal.txt`）：

| 检查 | 结果 |
|---|---|
| `predict` 对脉冲的响应 = h 延迟 1 帧 | 偏差 0.000e+00，脉冲前无提前输出 |
| `fir_response` = `predict` 冲激响应的 FFT | 最大偏差 4.7e-14 |
| 拟合索引与 `predict` 同一套 | 系数偏差 6.2e-07，回代残差 −81.6 dB |
| `history_matrix` 首行 = `[u[taps-1]…u[0]]` | 是 |

**结论：`src/feedback/` 里三处（`history_matrix`、`predict`、`fir_response`）用的是同一套
`lag_first=1` 约定，没有漏拍。** A 审阅到的漏拍只在临时脚本 `_a_work/compute_cd.py`
一类实现里；本仓库 `scripts/` 下没有任何脚本自行计算 FIR 频响，全部走 `fir_response`，
因此此前基于它得出的 CD / ASG 数字不受"漏一拍"影响。

漏一拍的代价（同一份系数、同一批数据）：

| 频率 | 相位误差 | 相对幅度误差 | 对 CD 的影响 |
|---:|---:|---:|---:|
| 1000 Hz | +7.4° | 12.9 % | +17.8 dB（把差模型算成好模型） |
| 4000 Hz | +29.5° | 50.9 % | +5.9 dB |
| 8400 Hz | +61.9° | 102.9 % | −0.25 dB |

也就是说漏一帧既能把残差算小、也能把残差算大，**它不能用来解释任何单一方向的偏差**。
这一点要写清楚，避免把分析错误误诊成 RTL 需要改历史语义。

## 3. 三个口径复核

### 3.1 高频负 CD：本批数据里一个都没有

相干 ≥0.5、100–12000 Hz 共 397 个 bin：`model_256` 与 `model_512` 的 **CD<0 的 bin 数都是 0**。
在"显著耦合"（`|H|` 距峰值 20 dB 以内）的频点上，CD 最差分别是 **+1.4 dB（256，334 Hz）**
与 **+7.4 dB（512，1979 Hz）**。

所以"6–12 kHz 负 CD"只成立于 **0.49 相干**那批低信噪比数据（A 在
`2026-10-22-512-taps.md` §13.1 已用高信噪比标定独立确认）。**它不是模型缺陷，也不能据此
建议改硬件或加分频段。**

### 3.2 "过预测 → 相减会增加能量"：本批数据不支持

判断相减是否增加能量，只能比 **同一频带内的残差能量与观测能量**，不能比
`max|pred|` 与 `max|mic|` 的峰值——两者出现在不同时刻，峰值比没有物理含义。

按带宽能量比：`baseline_256` 只在**跨场次**的 100–300 Hz 出现 `+1.2 dB`（残差略大于观测），
其余全部为负；`candidate_512` 在同一处是 `−4.5 dB`。**"过预测"是一个频段、一个场次条件下的
现象，不是普遍性质。**

### 3.3 离线 CD 与"闭环残差/麦克风"不是同一个量

A 在稳定点用 `|residual|/|mic|` 当作"闭环里还剩多少抵消"，得 −1.8 / −3.7 dB，
并据此认为残差带通路有问题。这个量不能这么用。线性平稳条件下：

```text
residual = s / (1 − g·(H−Ĥ)·z⁻²)
mic      = s · (1 + g·H·z⁻² / (1 − g·(H−Ĥ)·z⁻²))
⇒ 有外部声源时  residual/mic = 1 / ((1 − loop) + g·H·z⁻²)
⇒ 没有外部声源时 residual/mic = (H−Ĥ)/H      ← 这才是 −CD
```

`python scripts/closed_loop_metric_check.py` 的实测（`03-metric.txt`，g = −6 dB，相干 0.5）：

| 模型 | 有源闭环 residual/mic | 尾段 residual/mic（=−CD） |
|---|---:|---:|
| 部署 512（CD 最差 +7.4 dB） | −0.6 … −4.5 dB | −11.6 … −25.9 dB |
| **完美模型（Ĥ=H，CD 无穷大）** | **−0.6 … −4.4 dB** | −3000 dB |
| 空模型（Ĥ=0，等于旁路） | 0.0 dB | 0.0 dB |

**完美模型与真实模型在"有源闭环"这一列几乎重合。** 这个指标在模型完全正确时也不接近
0 dB，在完全没有模型时又恰好是 0 dB——它不含模型信息，**不能用来判断"模型还剩多少抵消"，
也不能与离线 CD 相减。**

A 测到 −1.8 / −3.7 dB，落在这个指标对完美模型也会给出的范围内，因此
"残差本身在闭环里只有几 dB"这个结论**不成立**；"离线 6 dB vs 闭环 3 dB"的差也不是
通路问题，是指标不同。

**正确的做法**：用**尾段**（无外部声源）算 `residual/mic`，它严格等于 `−CD`，
可以直接和离线结果比。A 已经采到 1 s 尾段，只需把统计窗口换到尾段。

## 4. 基线与候选的结论

候选 = `room_v1/candidate_512`，基线 = `room_v1/baseline_256`，唯一差别是抽头数
（同数据、同拟合方法、同 Q 格式）。

| 口径 | 本场 | 跨场（更接近现场） |
|---|---:|---:|
| 宽带 RMS | **−1.28 dB** | **−2.03 dB** |
| 300–1000 Hz | −1.19 | **−5.32** |
| 8200–8600 Hz | **−5.09** | −0.73 |
| 8600–12000 Hz | −1.36 | +0.19 |

**房间夹具上候选成立**：每个子带都不差，本场在 8.2–8.6 kHz 好 5.1 dB，跨场在 100–300 Hz
好 5.6 dB。**箱体夹具上候选不成立**：部署 256 验证集 −9.79 dB，重拟合 512 验证集 −10.17 dB，
只差 0.38 dB（且 512 需要 1539 拍、BRAM 已 80 %）。

所以结论不是"512 更好"，而是**按夹具分**：房间用 512，箱体用 256 就够。
两者都保留，由 C 按夹具选择，不能让一个配置冒充两个场景。

## 6. 下一轮实测的预测与否定条件

**预测（模型推算，非实测阈值）**

- 房间夹具、同一场次内 512 相对 256 的抵消起振点上移 **+2…+5 dB**；
  模型中心估计 +7.6 dB，但实测历史只兑现 +4 dB，所以取 +2…+5 作为可检验区间。
- 尾段 `residual/mic` 在 8200–8600 Hz 应读到 **−18…−26 dB**（512），而不是 −1.8 dB。
- 主导演视频段：256 在 300–1000 Hz（模型 CD 最差 +1.4 dB @334 Hz）；
  512 转到 1000–3000 Hz（CD 最差 +7.4 dB @1979 Hz）。

**假设**

- 同夹具、同 `hp_volume=40`、同在线音响只数、同数字增益标度；标定与实测之间路径未变。
- 线性：mic ≤ −6 dBFS，功放与限幅未进入压缩区。
- 环路延迟 1.45 ms（2 帧调度 + 约 71 帧路径）——这是**推算**，尾段衰减率可以反过来验证：
  `r` 对增益的斜率应为 `1/T_loop ≈ 690 dB/s per dB`。

**否定条件**

1. 若同场次内 512 的抵消起振点比 256 高出不到 **1.5 dB** → "抽头数"这个候选在房间夹具上被否定，
   回到基线，转查电平依赖。
2. 若尾段 `residual/mic` 在 8200–8600 Hz 读到 **−6 dB 以内**（远差于 −18 dB）→
   闭环里的 `H` 与标定的 `H` 不是同一个，优先查电平依赖、对齐与增益标度，而不是继续改模型。
3. 若 8.4 kHz 峰在 mic −14 dBFS 标定下比 −25 dBFS 时低 **3 dB 以上** → 模型的相位/幅度在
   工作电平上偏乐观，§6 的预测全部作废，需按新电平重标定后再给范围。

**建议测试范围**（衰减率外推，不是"某档一定叫"）

- 256：−12 / −10 / −8 / −6 dB；
- 512：−8 / −6 / −4 / −3 / −2 / −1 / 0 dB；
- 每档前后做一次正向对照（−40 dBFS 直放，mic 约 −17 dBFS），确认回路真的通。
