# 重标定现场批次（2026-10-31）

队长指令要求：原验证位置 + 一个**事先写死**的新位置，各自重新标定并重复验证；每次只改一个变量。

## 一、固定条件（两个位置共用，全程不动）

| 项 | 值 |
|---|---|
| 位流/包 | `audio_switch`，bit `2113a454…`，驱动与本包绑定 |
| 数字增益 | `gain_db = −8.0`（`gain_q12 = 1631`） |
| Codec 音量 | `hp_volume = 40` |
| 输出边界 | 不变；不降增益、不静音、不限幅换通过 |
| 保护 | 输入满幅/四类饱和/故障停声与恢复，全部保持原样 |
| 开环采集 | `zero_coeff=True` + `direct_only=True`（`gain_q12=0`），白噪 **RMS −19.3 dBFS**，6 段 × 16384 帧 |
| 拟合 | `scripts/fit_newlayout_candidate.py`，512 抽头，`ridge = trace×1e-9`（不改） |
| 判据 | 声学差 ≥ 环路提升−1.5 dB 且 \|过冲\| ≤ 1.5 dB（不改） |

## 二、两个位置

| 位置 | 麦–音响 | 朝向 | 说明 |
|---|---|---|---|
| **P1 原验证位置** | **100 cm** | 侧对，金属板 + 棉 | 与 10-26 标定批同一几何 |
| **P2 新位置** | **130 cm** | 侧对，同一朝向、同一金属板与棉 | **只改距离一个变量**（+30 cm），其余全部不动 |

选 130 cm 而不是更近：更近会提高耦合、增加自激风险，会把"重标定是否有效"和"稳定性是否够"两件事混在一起。130 cm 单变量、可解释。

## 四、重复验证规则（每个位置）

同一位置必须保持**相同增益、相同声源、相同几何**做抵消开关对照；用**稳态音**（322 Hz 纯音）做量化比较，语音传递另行检查。

- 每个位置至少跑 **2 次**完整重标定 + 三点，两次结果都记录，**不挑最好的一次**；
- 只测 322 Hz **不足以**宣布该位置有效；需同时记录语音段是否可用、是否触发保护、有无额外衰减；
- 两臂都不啸叫 **不等于** 抵消有效（那只是"没出事"）。

## 五、已知会破坏可解释性的做法（禁止）

1. 同时改摆位 + Codec 音量 + 输入增益；
2. 为了 PASS 而降低增益、限幅、静音或放宽判据；
3. 把 L1 缩放后安装（会把 322 Hz 增益砍掉 82 倍，做出假 PASS）；
4. 手工移动录音去凑 171 帧对齐（先核对数据定义）。
