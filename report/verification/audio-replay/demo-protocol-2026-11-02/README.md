# 演示协议：怎么做出"没算法就啸叫、有算法不啸叫"的对照（2026-11-02）

**验证层次：协议设计 + 已有数据支撑；完整的 A/B 对照尚未在本轮执行。**

## 一、先说结论：现在拨 SW0 听不出差别，是**正常的**

板上的产品每次扩声都用固定增益 `expected_identity.gain_q12 = 1631`，即 **−8 dB**。
`audio_pl_replay.v:103` 里旁路是 `bypass_effective = control[1] | sw0 | sw1`，SW0 拨上去确实会强制旁路——
**但这只改变"有没有抵消"，不改变增益**。

−8 dB 在这次摆位下**低于旁路的啸叫阈值**，所以旁路本来就不叫；切回抵消当然也不叫。
于是"听不出差别"——这不是算法没用，是**工作点选在了两条曲线都稳的那一段**。

项目硬约束里写得很清楚：**低音量只是启动检查，不是工作点**。要证明算法有用，必须把增益推到
"旁路会叫、抵消不叫"的那一段，这就是 ASG 的定义。

## 二、演示要的东西：同一个增益下，只切 SW0

| 必须相同 | 只有这一个可以变 |
|---|---|
| 摆位、讲话人位置与音量、麦克风/音响、Codec 音量、时长 | **SW0 上/下（旁路/抵消）** |

判据（任选其一，B 的判据优先）：

- **定性**：同一增益、同一讲话，旁路出现持续啸叫（或触发保护停声），抵消稳定不叫；
- **定量**：分别找到"旁路开始叫"和"抵消开始叫"的增益点，两点之差就是 ASG。

## 三、协议（A 执行，现场只需配合讲话）

已知：产品入口固定 −8 dB，改不了。所以对照要用**产品外的一次性运行**（`direct_run.sh` 同款），
它直接调 `perform({'op':'run', 'gain_q12': …})`，`allowed_gain_q12 = [1631, 2303, 3254, 4096]`
即 −8 / −5 / −2 / 0 dB。

1. **固定现场**：夹具摆好、音量不动；本次 CAL 已通过（`L1 2.170`、验证 `+4.63 dB`）。
2. **从 −5 dB（q12=2303）开始**，SW0 **拨上（旁路）**，跑 10 秒并持续讲话。
3. 若旁路**不叫**：升到 −2 dB（q12=3254）再来；仍不叫再升到 0 dB（q12=4096）。
4. 找到第一个"旁路会叫"的增益 `G_bypass` 后，**保持这个增益**，把 SW0 **拨下（抵消）**，同样跑 10 秒。
5. 记录两组：是否起振、是否触发保护、`mic_rms`/峰值、听感。
6. **如果到 0 dB 旁路仍不叫**，说明这门课的声学布局在安全音量内做不出对照——换更近的摆位/更高的
   Codec 音量再试，而不是继续加增益。

安全：每次只用 10 秒；起振立刻 **BTN3**；升增益一次只升一档，不要跳。

| 项 | 值 | 来源 |
|---|---|---|

| 独立验证 | 300–460 Hz 带内抑制中位 **+4.63 dB**（最低 +4.61） | 同上 |
| 训练段电平 | `mic_rms ≈ −36.5 dBFS`，路径衰减 ≈ 14.5 dB | 成功场景 `2dbf041e` |
| −8 dB 扩声 | 24.5 秒后 `input_overload` 保护停声（输入满幅） | 同一场景的 `run_00`，`mic_rms −16.5`、峰值 0.00 |
| 路径变强 7 dB 时 | 三次拟合 `L1 4.455 / 4.467 / 4.339`，全部 > 4.0 → `model_rejected` | 失败场景 `62fc713f` |

两条可用的推论：

1. **L1 与路径增益近似成正比**（2.170 × 2.05 ≈ 4.45）。同一房间只要音量/距离变了，`L1` 就按分贝等比变化，
   门限实际在约束"摆位+音量"。这一条要 B 判断是否该做增益归一化（判据语义变更，A 不擅自改）。
2. **−8 dB 下旁路不叫**，与"本轮扩声在 24.5 秒才因输入满幅停声"是一致的：这一档的裕量够大，
   所以 SW0 切不出差别。

## 六、2026-11-02 实测：允许增益范围内做不出啸叫（这是关键约束）

按上面的协议在真板跑了六段（`ab_ladder`，每段 8 秒，同一模型，只切软件旁路标志，
SW0 保持拨下；`run_dir` 每段独立）：

| 增益 | 旁路 | 抵消 | mic_rms |
|---|---|---|---|
| −5 dB | `completed` | `completed` | −36.9 / −36.4 |
| −2 dB | `completed` | `completed` | −37.4 / −36.9 |
| **0 dB** | `completed` | `completed` | −36.8 / −37.3 |

**六段全部 `completed`，没有一段起振，旁路与抵消的电平差不到 1 dB。**

原因可以从装好的模型直接算出来（`max|Ĥ|` 与起振条件 `gain·|Ĥ| ≥ 1`）：

```
max|Ĥ| = 0.667  (−3.5 dB)  @ 417.2 Hz
起振需要增益 ≥ 1.50× = +3.5 dB
板上允许上限 q12 4096 = 0.0 dB  →  距起振还差 3.5 dB
```

也就是说：**在这套夹具 + 允许增益区间（≤0 dB）内，环路物理上不可能自激**，所以旁路不会叫、
抵消自然也显不出差别。这不是算法无效，是工作点比啸叫阈值低了 3.5 dB。

按本轮独立验证的带内抑制 +4.63 dB 推算，抵消后的起振阈值约 **+8 dB**，因此可用的演示窗口大致是
**+3.5 dB ～ +8 dB**（例如 q12 = 8192，即 +6 dB）：旁路会叫、抵消不会。

这个增益**超出产品允许集**（`allowed_gain_q12 = [1631, 2303, 3254, 4096]`，最高 0 dB），
所以要么由 C 放开增益上限（配置改动 + 重钉），要么演示时走 A 的直接入口而不是产品入口。

## 七、2026-11-02 实测：+6 dB 两臂都饱和，但抵消明显更慢更低

同一模型、同一摆位，+6 dB（q12 8192）先抵消后旁路：

| 臂 | 结果 | 撑住时长 | capture 帧数 | mic_rms | mic_peak |
|---|---|---|---|---|---|
| 抵消 | 饱和保护停声（`gain=1`） | 10.7 s | 16384 | −17.3 | −8.5 |
| 旁路 | 饱和保护停声（`gain=32`） | 3.3 s | 4726 | −17.7 | −4.8 |

两点结论：

1. **模型推算的演示窗口（+3.5…+8 dB）偏乐观**。虽然带内抑制中位是 +4.63 dB（300–460 Hz），
   但在环路最敏感的 417 Hz 处，抵消量不足以保证 +6 dB 稳定。
2. **算法确实在起作用，只是不够**：同一增益下，抵消撑住的时间是旁路的 3 倍多（10.7 s vs 3.3 s），
   麦克风峰值低 3.7 dB（−8.5 vs −4.8）。这是"抑制有效但不充分"，不是"无效"。

因此真正的演示点位于 0 与 +6 dB 之间，需二分（建议先试 +3 dB：q12 5787）。

## 九、2026-11-02 实测：+3 dB 是演示点（同一增益，只有旁路标志不同）

q12 = 5787（+3.0 dB），先抵消后旁路，各 8 秒：

| 臂 | 结果 | mic_rms | mic_peak |
|---|---|---|---|
| **抵消** | `completed`（稳定，未触发任何保护） | **−38.8** | −28.4 |
| **旁路** | 饱和保护停声（`gain=5`），即啸叫后被停 | **−13.8** | −2.9 |

**麦克风电平差 25 dB，一臂稳定、另一臂啸叫**——这就是"有算法 / 没算法"的对照。

由此还能给出一个区间估计：旁路在 +3 dB 已叫，抵消在 +3 dB 稳定、+6 dB 也叫，
所以 **3 dB < 可用增益差（ASG）< 6 dB**。这是单点二分得到的区间，不是完整 ASG 测量。

**演示配方**：增益固定在 +3 dB（q12 5787）——

- SW0 **拨上（旁路）** → 啸叫，驱动立刻保护停声（四灯全亮）；
- SW0 **拨下（抵消）** → 正常扩声、不叫。

这个增益**超出产品允许集**（最高 0 dB）。要在产品内演示，需 C 把
`allowed_gain_q12` 与 `expected_identity.gain_q12` 放开到 5787；否则走 A 的直接入口。

## 十一、2026-11-02 彩排：SW0 现场切换触发啸叫（演示流程已验证）

演示点 +4.5 dB（q12 6900），一次 20 秒运行，开始时 SW0 拨下（抵消），约第 8 秒现场把 SW0 拨上：

| 项 | 值 |
|---|---|
| 切换前 | SW0 raw/sync = 0/0，抵消，正常扩声 |
| 切换后 | SW0 raw/sync = 1/1，旁路立即生效 |
| 结果 | 饱和保护停声（gain=5），第 10.5 秒截断，mic_rms −18.9 / peak −3.8 |

PL 里 ypass_effective = control[1] | sw0 | sw1 是逐帧判定的，所以**同一个运行里拨开关就能立刻切**，
不需要重启、不需要软件介入——观众看到的就是"同一增益，一拨就炸"。

演示时的完整循环（注意第 3 步要重新起跑，因为保护停声后流水线是停的）：

1. 抵消、+4.5 dB → 正常扩声，让观众听清；
2. 拨 SW0 上 → 啸叫，保护停声（四灯全亮）；
3. 拨回 SW0 下、重新起跑 → 恢复正常扩声；
4. 可重复 2–3 次。
## 十二、2026-11-02 时长复核：5 秒窗口偏乐观，20 秒才是可用判据

第一轮 30 秒复核（讲话电平偏高，安装采集 −26.9 dBFS）：
  +4.5 dB 失败于**输入满幅**（bit22，15 个贴轨样本），+5.5 dB 失败于输出饱和。
  该轮不能用来判时长，因为讲话电平比前几轮高约 8 dB。

第二轮 20 秒复核（讲话电平正常，安装采集 −35.3 dBFS，与前几轮可比）：

| 点 | 20 秒结果 | mic_rms | mic_peak | 播放峰值 |
|---|---|---|---|---|
| +3.0 dB | 稳 | −36.3 | −21.5 | −18.1 |
| +3.5 dB | 稳 | −35.4 | −20.8 | −18.8 |
| +4.0 dB | 稳 | −29.8 | −17.9 | −13.9 |

结论：
  · **5 秒二分得到的 +5.5 dB 边界不能当"稳定"**，只能当"5 秒内没炸"；时长必须单列。
  · 正常讲话电平下，**+4.0 dB 可稳定 20 秒**，是目前确实验过的最高持续点。
  · 存在两个不同的极限：**环路自激**（输出饱和）与**麦克风输入满幅**（bit22）。前者是算法要解决的，
    后者是电平/摆位问题，记录时必须分开写。
## 十三、2026-11-02 20 秒持续复核（第二轮）：环路边界在 +5.0 与 +5.5 之间

| 点 | 20 秒结果 | 失败机制 | mic_rms | mic_peak | 播放峰值 |
|---|---|---|---|---|---|
| +4.5 dB | 失败（18.5 s） | **麦克风输入满幅**（2 个贴轨样本） | −25.6 | ≈0 | — |
| +5.0 dB | 稳 | — | −30.8 | −18.0 | −13.2 |
| +5.5 dB | 失败（12.6 s） | 输出饱和（环路） | −17.2 | −8.0 | — |

关键观察：**+4.5 是输入满幅失败，而 +5.0 反而稳** —— 说明输入满幅由**瞬时讲话电平**触发，
不是随增益单调恶化。两个极限必须分开报：

- **环路极限**：+5.0 稳、+5.5 失稳 ⇒ 20 秒尺度下边界在 (5.0, 5.5)；
- **输入满幅极限**：与讲话电平相关，+4.5 时被一次峰值触发（当时安装采集 −39.3，讲话并不算大声）。

| 增益 | 20 秒 | 备注 |
|---|---|---|
| +3.0 / +3.5 / +4.0 | 稳 | 两轮都稳 |
| +4.5 | 一轮输入满幅、一轮未测 | 输入满幅风险 |
| +5.0 | 稳 | 距环路边界仅 0.5 dB |
| +5.5 | 失稳 | 环路 |

**演示建议：+4.0 dB**（20 秒两轮都稳、旁路在该点必然起振、距环路边界 1.5 dB、输入满幅风险最低）。
