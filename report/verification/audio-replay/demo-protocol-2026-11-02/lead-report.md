## 4 问题清单（按"是否已解释"分类）

### 4.1 已定位且有证据

1. **`L1 ≤ 4.0` 判据缺陷**：`L1` 是最坏情况上界、按绝对尺度卡，等于按最坏情况拒收；已由 B 书面提案、
   A 代实施改为 `max|conv|<0.30`。产品链路已实测生效（`L1 4.117` 被接受）。
2. **`REJECT_SCALE` 重试白烧时间**：h 与激励电平无关，实测三次 L1 几乎不动（4.455/4.467/4.339）；已去掉。
3. **标定耗时**：186 → 150 s（训练段 6→4）。余下大头：拟合 53 s、每段位流重下 4×7 s。
4. **两个不同的保护来源**：输出饱和（`guard`）与麦克风输入满幅（bit22 `input_overload`），过去被混用；
   已分开记录。高增益下更容易触发的是**输入满幅**。
5. **旁路 0.03 s 瞬断**：多次测量停在同一帧数（1289 帧），形态像**起跑瞬态**而非声学增长。

### 4.2 未解释（需要队长判断）

| # | 现象 | 证据强度 | 已排除 |
|---|---|---|---|
| U1 | **声学路径比早上强约 4.7 dB**（405 Hz `|H|` 0.667 → 1.14~1.29） | **强**（单音五次、跨重启、跨包、跨标定复现） | 板子状态、线缆接触、模型元数据 |
| U2 | **8.4 kHz 存在 `|H| ≈ 1.12` 的耦合峰** | 强（单音实测），但**时有时无** | 充电头（已换回原 USB 口） |
| U3 | **产品偶发"卡死"**：进程 84% CPU、`wchan=do_select`、状态文件 20 分钟不更新；重启服务即恢复 | 中（发生 3 次，均有现场记录） | 算法子进程超时（有 150 s 兜底） |
| U4 | 早上 +3.0 dB 可用、现在 +3.0 dB 失稳，而用户保证现场环境未变 | — | — |

## 5 关于 U1/U4 的可能原因（假设与强弱，供队长判断）

| 假设 | 支持 | 反对 | 强弱 |
|---|---|---|---|
| H1 音响音量旋钮/位置变化 | 4.7 dB 增量正好对应距离减半或音量变化 | 用户明确保证未动；`hp_volume` 配置未变 | 中（物理上最像，但被现场否认） |
| H2 Codec 模拟增益实际值与配置不符 | 4.7 dB 量级符合 PGA/DAC 音量步进；驱动只写部分寄存器（`0x400A/0x400B/0x400C/0x400D`、`0x4023/0x4024`），**未做全寄存器回读比对** | 寄存器写入值由配置确定、每次调用都写；断电重上电未改变 | 中 |

## 9.1 先更正三处表述（撤回/收窄）

| 原表述 | 更正后 |
|---|---|
| "路径强约 4.7 dB" | **不成立/需收窄**。0.667 是**拟合模型值**、1.154/1.287 是**单音开环实测**，且频率不同（417 vs 405 Hz）。**同口径复算**后：早上两场标定的原始数据估算 H405 = **0.855 / 0.983**，当前场景 = **1.159~1.479**，差值 **2.5~4.6 dB**（不是单一 4.7 dB）。模型值比原始估算**系统性低约 2.2 dB**，我拿模型值去比单音值是口径错误。 |
| "\|H\|>1，意味着任何正增益都会自激" | **撤回**。稳定性涉及幅度、相位与延迟；抵消开启时应看残余环路，不能由 \|H\| 单独下结论。只保留现场观察：当前状态下抵消在 +2.0 dB 时好时坏、+3.0 dB 失稳，+1.0 dB 两次 20 秒通过。 |

## 9.2 早上基线拆成真实试次（不再是"一个成功配置"）

原报告把四个不同来源的数字拼成了一个"基线"，**这是错的**。逐项对应如下：

| 数字 | 真实来源 | 说明 |
|---|---|---|
| L1 2.170、验证 +4.63 dB | 场景 2dbf041e（当天**首次**成功标定） | 模型 2dbf041e-…，原始数据 H405 = **0.983** |
| 模型 max\|H\| = 0.667 @417 Hz | **另一场**标定 2a20c3e9 的模型 | 原始数据 H405 = **0.855**，模型值 0.660 |
| +3.0 dB 演示点、SW0 拨上 3.49 秒停声 | **A 的直接入口**运行（ab_runs/ 下），不走产品面板 | 与产品包增益无关 |
| 24.5 秒后 input_overload | 场景 2dbf041e 的**产品**运行，run_00.status.json：input_clip、completed_frames=1045039（≈21.4 s） | 该次运行走产品包，**当时的包增益是 1631（−8 dB）**，不是 +3.0 dB |

## 9.5 五项结论（按队长要求）

**1）已能确定的事实**
- 早上四个数字来自**四个不同试次**（§9.2），不存在单一"早上成功配置"可整体回滚。
- 标定训练数据是**开环**的（forward_path_open=true, gain_q12=0），与单音测量同拓扑。
- 同口径下：早上两场 H405 = **0.855 / 0.983**；当前三场 = **1.159 / 1.367 / 1.479**；
  即**后几场 405 Hz 估计值高于前两场，过程中先升后降**（a186a788 1.479 → 1459ef92 1.367 → 03bf86f3 1.159），
  不是单调抬升。幅度差 2.5~4.6 dB。
- 模型估计值与原始估算**逐场差值**：2a20c3e9 +0.195、2dbf041e +0.112、a186a788 +0.517、
  1459ef92 +0.305、03bf86f3 +0.181（原始 − 模型）。**各场差值不同，不写成"系统性低估 2 dB"**。
- 405 Hz 相干 0.81–0.85，可判读；数字链路（bit_exact、位流/驱动/HWH 哈希）全程健康；
  Codec 配置（hp_volume=40、AUX 0 dB）与早上一致。

**2）被纠正的解释**
- "路径强 4.7 dB"：撤回，改"2.5~4.6 dB，且部分差值来自模型 vs 实测的口径混用"。
- "\|H\|>1 ⇒ 任何正增益必自激"：撤回。
- "早上的成功基线"：撤回，改为四个独立试次。
- "旁路 0.03 秒瞬断=起跑瞬态"：降级为待判。
- 单音测量：拓扑正确（真开环），但**未排除启动/尾段/削顶**，且**原件未保存**，只能作弱证据。

**3）最有依据的原因及对应证据**
目前证据**支持**："不同时段的训练数据所反映的 405 Hz 通路幅度不同：后几场高于前两场，过程中先升后降。"
证据：同一估计器、同一窗口、同一网格下，五场标定原件的 H405 = 0.855 / 0.983（前两场）
→ 1.479 / 1.367 / 1.159（后三场，先升后降）；相干均 ≥0.81。
**但"通路为何不同"仍无证据**：现有记录缺"变化时刻"的物理/电气快照，无法区分
"房间/摆位真的变了"与"某处模拟增益实际值变了"。
**本节不把幅度差异直接解释成物理根因**；交叉残差只用于判断"数据是否变了"，不是"为什么变"。

**4）仍缺的最小证据**
- **一次开环 H405 基线记录**（每次标定顺手存一条），当前没有"变化前 30 分钟内"的同类基线可比；
- **交叉残差复算**：旧模型 × 新数据、新模型 × 旧数据（本轮已完成，见 §10），它只能回答"数据是否变了"；
- 8.4 kHz 峰的原始数据复算（本轮时间盒内未完成）。

**5）下一步只推荐一个动作**
**执行"旧模型 × 新数据 / 新模型 × 旧数据"的交叉残差复算**——**已在 §10 完成**。
按队长要求，该项只用来区分"两批数据是否不同"，**不用其单向/双向退化直接判定物理根因**。

## 10.6 对队长三问的回答

**问 1：当前模型在当前独立数据上是否比旧模型更好？**
**是。** 在 4 个晚间数据批次上，带内抑制当前模型 4.86/6.76/6.76/6.41 dB，旧模型 4.79/5.11/5.37/4.85 dB

（当前领先 1.0~5.5 dB）。**但在早期数据上反过来**（旧模型领先），与 10.1/10.2 的"数据不同"结论一致。

**问 2：当前抵消器主要在哪个频段留下较大残差？**
**150–300 Hz 几乎无抑制**（resid/mic = −0.5 / +0.3 dB），**4–10 kHz 也很弱**（−0.9 / −0.4 dB）；
抑制最好的在 300–2000 Hz（−3.2 ~ −6.9 dB）。
即：当前验证判据盯的 300–460 Hz 恰好在"好的那一段"，而**低频段未被覆盖也未被告警**。

**问 3：已有记录能否指出具体的配置差异？**
**不能。** 已记录的模拟链路字段（AUX 0 dB/raw 5/5、hp_volume 40）早晚完全一致；
DAC 实际寄存器与音响侧状态**没有记录**。能确定的只有 10.5 的"12:37→13:13 阶跃"，以及包的增益/模型身份不同
（这些是设计预期，不是异常）。**结论：通路响应确有差异，但物理/电气原因仍不能区分。**
