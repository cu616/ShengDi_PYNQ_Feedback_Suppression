# 512 抽头改建：位流、回归与箱体复测

日期：2026-10-22　执行：A　数据：`_a_work/b512`、板上 `/home/xilinx/b512_*`、`box_cal513/`、`box_loop512/`

## 1. 为什么改

B 用房间夹具 6 段高信噪比采集做了抽头扫描，结论是判据不是宽带误差，而是 **CD 最差频点**：

| 模型 | 300–1000 | 1000–3000 | 3000–6000 | 6–12k | 全带 ASG |
|---|---:|---:|---:|---:|---:|
| shipped 256 | −0.53 | −1.96 | +3.26 | +0.20 | +6.73 |
| refit 256 | −0.62 | −2.80 | +2.86 | +2.33 | +11.32 |
| refit 384 | −0.13 | +2.08 | +4.82 | +1.86 | +16.80 |
| refit 512 | **+5.41** | **+3.76** | +6.38 | +4.32 | +16.32 |

256 抽头在 300–3000 Hz 两段 CD 为负（抵消后环路更强），这正是"宽带压低 20 dB、ASG 只有 4 dB"的形态。
预算上 512 抽头 = 3×512+3 = **1539 拍 < 2048 帧预算**，不需要加 MAC 单元。

## 4. 回归测试：512 位流 + 256 模型补零

用补零到 512 的 256 模型跑箱体，检验"重建没有改变行为"：

| 项 | 256 基线 | 512 位流 + 补零模型 |
|---|---|---|
| 控制项麦克风 | −18.1 dBFS | **−18.1 dBFS** |
| `ref→mic` 延迟 | 114 帧 | **114 帧** |
| 逐帧校验 | bit-exact | **bit-exact**（0 处不符） |
| 预热帧 | 256 | **512**（`history_excluded_frames`） |

**结论：重建是干净的**，512 位流在输入等同于 256 时逐位复现 256 行为。

## 5. 箱体 512 标定

第一次用记录噪声分段（峰值归一化到 −30 dBFS）失败：麦克风只有 −31 dBFS，
`ref→mic` 延迟在 67/68/100 之间跳动、2 段完全无相关——说明采集被底噪主导。
**改用合成白噪声、按 RMS 定标到 −36 dBFS**：中位电平 −28.5、延迟 67、5/6 段可用。

| 抽头 | 验证集降低 | max\|H\| | 峰值频率 | 尾部能量 |
|---:|---:|---:|---:|---:|
| 256 | 6.22 dB | 25.21 dB | 416 Hz | 5.9 % |
| 384 | 6.34 dB | 25.72 dB | 398 Hz | 0.1 % |
| 512 | **6.49 dB** | **26.45 dB** | 417 Hz | 0.9 % |

独立一致性：`max|H| = 26.45 dB @417 Hz` 与 §9 记录的箱体 +26.3 dB 吻合。

## 8. 房间夹具：用 B 的判据（逐频点 CD）做 256 vs 512

不需要闭环即可测量。白噪声标定采集（6 段、延迟 125、电平 −25.4、全部通过对齐门），
用相干加权互谱估 H，再算 CD(f) = 20log10(|H| / |H−Ĥ|)，只统计实测相干性 > 0.5 的频点：

| 子带 | 256 最差 | **512 最差** | 256 中位 | 512 中位 | 相干（中位） |
|---|---:|---:|---:|---:|---:|
| 300–1000 Hz | **−0.41** | **+3.34** | 5.27 | 10.95 | 0.59 |
| 1000–3000 Hz | +0.72 | **+2.55** | 9.45 | 10.53 | 0.78 |
| 3000–6000 Hz | −1.45 | −0.88 | 4.31 | 4.58 | 0.92 |
| 6000–12000 Hz | −4.89 | −4.71 | −0.23 | −0.27 | 0.96 |

**512 把 300–1000 Hz 从负 CD（−0.41）翻成 +3.34，1000–3000 从 +0.72 提到 +2.55**，
与 B 在另一批数据上的结论方向一致。6–12 kHz 两版都为负（中位约 0），是模型最弱的一段，
与实测 8.4 kHz 强峰（max|H| 10.8 dB）吻合——该段残差相对 |H| 偏大。

同批标定的宽带验证集降低：256 = 9.56 dB、512 = 10.65 dB（+1.09 dB）。

## 9. 房间闭环起振点：本轮的测量判据失效，结论作废

尝试用两侧起振点给 ASG，跑了两批共 20 余次，**全部作废**，原因是判据本身有问题：

- 保护逻辑看的是**饱和计数器**，它反映输出有多响，**不是环路是否失控**；
- 房间 max|H| 只有约 10.8 dB，可观测区间窄，于是出现
  「−3 起振、−2 稳定、−1 又起振」这种物理上不可能的序列；
- 被保护中止的试次**不落盘**，事后无法用包络复核（本轮 12 次只有 2 次留下捕获）。

另外本轮一开始还踩了两个坑，一并记录：
- 麦克风 VCC 与 LINE_IN 两根线都松了，链路一度是死的（麦克风读数 −100 dBFS）；
- 用**语音**做正向对照时 
ef→mic 互相关有歧义（同一几何下单音 117 帧、语音 177 帧），
  只有白噪声能给出唯一延迟（125 帧）。所以延迟门禁只能用白噪声测。

**下一步的正确做法**：把判据换成捕获上的包络增长（连续 N 个块单调上升到轨才算起振），
并且**在保护中止前先落盘**；激励降到不进入功放压缩区的电平。

### 9.1 判据修正后的复核（2026-10-22 晚）

改动：
eplay_trial.py 的保护分支**先落盘再抛异常**（GUARD_CAPTURE_SAVED），
判据改成捕获上的包络增长（12 块，末块比首块高 6 dB 且贴近自身峰值才算起振）。

结果（同一场次、白噪声 −26 dBFS RMS、1.8 s/项、控制项电平全部通过）：

| 模型 | 旁路 −8 / −7 / −6 | 抵消 −3 / −2 / −1 |
|---|---|---|
| 256 | 稳定 / 稳定 / 保护中止 | **保护中止（15 ms，仅 646–751 帧）** / **保护中止** / 起振 |
| **512** | 稳定 / 稳定 / **稳定** | **稳定 / 稳定 / 稳定**（麦克风 −35 dBFS，接近底噪） |

要点：
- **256 在抵消 −3 dB 就撑不住**，补偿器自身在十几毫秒内饱和；**512 到 −1 dB 仍稳定**，
  且残余压到底噪附近（−35 dBFS），说明抵消在中低频真正生效。
- 旁路两侧都能到 −6～−7（无抵消，符合预期）。
- 与 §8 的 CD 表一致：256 在 300–1000 Hz 的 CD 为负，正是它在低增益就崩的原因。

**仍差最后一步**：那条运行时保护只要**任一饱和计数器非零**就中止，
于是 256 的失效试次都在 ~15 ms 被切断，拿不到完整包络，**256 的抵消起振点数值仍空缺**。
把该门限改成可配置（或按包络判据替代）之后，一次梯子就能补上。

**这一轮可以确认的定性结论**：房间夹具上 512 比 256 至少多容忍 **2 dB 以上**的抵消增益
（256 在 −3 dB 已饱和中止，512 在 −1 dB 仍稳定且静音）。
## 10. 为什么 512 在箱体无用、在房间有用：CD 一次说清

用同一套方法（相干加权互谱、只统计相干性 >0.5 的频点）算箱体的 CD。
箱体白噪声标定 5/6 段可用、延迟 67、电平 −28.5：

| 子带 | 箱体 256 最差 | 箱体 512 最差 | 房间 256 最差 | 房间 512 最差 |
|---|---:|---:|---:|---:|
| **300–1000 Hz** | **+10.15** | +10.55 | **−0.41** | **+3.34** |
| 1000–3000 Hz | +5.84 | +6.49 | +0.72 | +2.55 |
| 3000–6000 Hz | +0.50 | +0.47 | −1.45 | −0.88 |
| 6000–12000 Hz | −0.35 | −1.74 | −4.89 | −4.71 |

（箱体 CD 中位数：300–1000 为 17.4 / 19.3 dB。）

**箱体 256 在语音频段已有 +10 dB 正余量，没有缺陷可修**，所以 512 只多 0.4 dB——
与 §6 的闭环空结果（起振点不变）一致。房间 256 是负的，512 翻正。

### 10.1 原因是 \|H\| 的绝对水平，不是冲激响应长度

初版这里写的是"箱体路径短、几乎无混响、256 抽头已覆盖"，**这个解释是错的，已删除**。
B 用箱体与房间的能量累积给出反证：

| 夹具 | 峰值帧 | 能量 95 % | 能量 99 % |
|---|---:|---:|---:|
| 箱体 | 68 | 236 | 452 |
| 房间 | 125 | 235 | 522 |

两者的 95 % 能量点几乎一样（236 vs 235 帧），256 抽头对**两者都只覆盖到 95 %**。
真正的差别是 \|H\| 的绝对水平：箱体 300–1000 Hz 的 `max|H|` 是 **25.45 dB**，房间只有 **4.70 dB**。
CD 是比值——箱体有 25 dB 的本钱，模型差 13 dB 还剩 +12；房间只有 4.7 dB，
同样 5 dB 的绝对误差就翻负。**房间失败不是"模型对房间更差"，而是房间耦合弱、容错小 20 dB。**

## 11. 修正后的起振点与 ASG（2026-10-22 晚第二次）

判据按 B 的意见改成「**保护触发即已起振**」，并用包络复核是声学增长还是数字过冲；
激励白噪声 −26 dBFS RMS、2.2 s/项、控制项电平全部通过（−31.2…−31.8 dBFS）。

| 模型 | 旁路 | 抵消 | 房间 ASG |
|---|---:|---:|---:|
| 256 | ≈ −6.5 | ≈ **−5.5**（−6 稳定、−5 起振） | **≈ 1.0 dB** |
| **512** | ≈ −6.0 | ≈ **−0.5**（−1 稳定、0 起振） | **≈ 5.5 dB** |

- **512 在房间夹具上带来约 +4.5 dB 的 ASG。** 此前"至少多 2 dB"的说法低估了。
- 抵消侧的触发是声学增长（包络 −23.1 → −14.7 dB，+8.4 dB），判据成立。
- **旁路侧不能用这条判据**：旁路下保护看的是预测饱和，而两个模型的预测强度不同
  （512 的 `max|H|` 更高、更容易饱和），所以旁路两侧的差不可直接比较；
  这里取的是"包络干净稳定"与"输出已钉在 −2.3 dBFS"之间的中点。
- **与早先的 4.0 dB 不可比**：那次的麦克风增益、激励电平和本次都不同
  （同一 −10 dBFS 人声，麦克风从 −26.7 变成 −20.5）。房间 ASG 的**绝对值**只在同一场次内有效，
  **跨场次只能比差值**。

### 11.1 口径提醒（B 指出）

CD 最差（逐频点比值的最小值）与起振阈值（`max|H−Ĥ|` 的绝对值）是**两个量**，
决定起振的是后者。本报告 §8/§10 给的是 CD，起振点给的是后者，两者不可互相替代，都必须报。

## 12. 房间的 8.4 kHz 共振：真实存在，但属于标定问题（B 的分析）

B 在六段数据上确认 8.3–8.5 kHz 有 +9~10 dB 的峰（相干 0.85–0.98），不是伪影；
8416 Hz 的环路相位 +19.6°，属允许起振的位置。

关键是模型余量：shipped 模型在该点 `|H−Ĥ|` = **+2.56 dB（欠余量）**，
而高 SNR 重标定的 refit 模型同一位置是 **−12.10 dB（余量 22 dB）**。
**所以 8.4 kHz 不是夹具缺陷，是低 SNR 标定学不好高频。**

由此 B 给出的下一步顺序是两步：

1. **先用高 SNR 数据重标定**（本次的 6 段就够）——这一步同时把 8.4 kHz 修好，成本最低；
2. **再上 512**——refit 256 的瓶颈回到 300–3000（CD −0.38 / −2.56），512 把它翻正（+5.49 / +3.30）。

只做 512 不重标定：300–3000 修好了，8.4 kHz 还在。

两条约束：
- **不要用低通切掉 6 kHz 以上**：切掉之后旁路在该点仍是 10 dB，环路增益从"抵消后 2.56"
  变成"旁路 9.26"，更容易叫。
- 判断某个负 CD 要不要管，**看该频点的 \|H\| 绝对值，不看 CD 的符号**
  （箱体 6–12 kHz 的 CD 也是 −3…−4.5，但那里 \|H\| 只有 2.9 dB，不影响稳定性）。

## 13. 高信噪比标定与残差带测试（按 B 的两条指令）

注入从 −24 提到 **−14 dBFS RMS**，标定段麦克风到 **−17.2 dBFS**（此前 −25.4）。

### 13.1 300–1000 Hz 的负 CD 是低信噪比伪影，已确认

高信噪比下（相干性 0.86，此前 0.49），以相干 >0.8 为门：

| 子带 | 256 最差 | 512 最差 | 256 中位 | 512 中位 | 实测 max\|H\| |
|---|---:|---:|---:|---:|---:|
| 300–1000 Hz | **+0.52** | **+5.81** | 6.10 | 13.46 | 5.46 |
| 1000–3000 Hz | +0.49 | +4.85 | 10.97 | 12.22 | 4.17 |
| 6000–12000 Hz | +0.45 | +1.16 | 3.31 | 3.37 | 4.75 |

**256 在语音频段不再为负，6–12 kHz 的负值也消失。** 与 B 的判断一致：
低信噪比下 76 % 的麦克风功率与参考不相关，任何滤波器都减不掉，于是 CD 被压成负值。
**因此 §8 与 §10 里"256 低频 CD 为负"的说法只成立于低信噪比条件，不能当作模型缺陷。**

### 13.2 残差带测试：残差确实偏差，缺口不是判据造成的

B 给的判决法：在稳定点看 8.2–8.6 kHz 的 |residual|/|mic|，
≈ −23 dB → 残差正常、是起振判据把阈值测高；≈ −12 dB → 残差真差、属通路/电平/对齐。

| 稳定点 | 300–1000 | 1000–3000 | **8200–8600** | 6000–12000 |
|---|---:|---:|---:|---:|
| 512 cancel −1 dB | −2.8 | −3.5 | **−1.8** | −4.3 |
| 256 cancel −6 dB | −3.6 | −7.3 | **−3.7** | −3.5 |

（单位 dB，全部为负值越小表示抵消越多。）

**实测 −1.8 ~ −3.7 dB，比 B 的 −12 dB 分支还差。**
所以结论是：**残差本身在闭环里只有几 dB 的抵消，11–12 dB 的 ASG 缺口不是起振判据造成的**，
而要按"通路/电平/对齐"方向查。

注意这也与离线拟合矛盾：同一批数据离线验证集降低有 5.7（256）/ 6.3（512）dB，
闭环里却只有约 3 dB。**这个离线与闭环之间的差本身就是待查项**，
优先怀疑：捕获里 esidual_pcm 的口径（增益前/后）、预测所用参考与捕获参考是否同一时刻序列。

### 13.3 本轮给 B 的三个数

1. 高信噪比 CD：256 最差 +0.52、512 最差 +5.81（300–1000 Hz），**256 不是负的**。
2. 8.2–8.6 kHz 残差比：**−1.8（512）/ −3.7（256）dB**，落入"残差真差"分支。
3. 离线 6.3 dB 与闭环 ~3 dB 的差异，需查 esidual_pcm 口径与参考对齐。
