输入：`manifest/`（6 段旁路直采，16384 帧/段，ref RMS −24.0 dBFS，mic RMS −25.1 dBFS，
延迟全 125，`gain_q12=0`）+ `model_256.json` / `model_512.json` / `model_256_pad.json`。
对照场次：`candidate_room_v1_256_final(1)/`（9 段，其中 seg_1/5/6/7 可用，mic −12.9…−14.8 dBFS）。

**显著耦合频点上的谱残差**。不用 `CD(f)` 的符号、不用 `max|H−Ĥ|` 的无门控最大值。

## 6. 8.4 kHz：可复现、被抵消得很好，不是瓶颈

十个段（两批）全部在 8345–8416 Hz 出现峰，幅度 +9.7…+11.1 dB，半功率宽度 405–811 Hz。
这是稳定特征，不是伪影，也不是漂移。

而模型在那一带的抑制是 **−18.4 dB（256）/ −23.4 dB（512）**，谱口径的 CD 也一致
（+16.2 / +20.8 dB）。所以**它已经被处理掉了，不需要单独做分频段或改摆位。**

A 表里「6–12 kHz CD 最差 −4.89」的负值来自 `|H|` 的零点：那里 `|H|→0` 而残差不为零，
比值必然是很大的负数，与「是否放大环路」无关。**判据应该是残差的绝对电平，
不是 CD 的符号**——这一点我 10-23 已经提过一次，这次给出可执行的替代口径：
只在 `|H|` 距峰值 20 dB 以内的频点上取残差（`scripts/score_time_domain.py` 用整条带能量比，
等价但更稳）。

## 7. 未解决：实测阈值比模型低 11–12 dB，且对两个模型完全一致

| | 模型预测抵消阈值 | A 实测 | 差 |
|---|---:|---:|---:|
| 256 | +6.54 dB | −5.5 dB | 12.0 dB |
| 512 | +10.58 dB | −0.5 dB | 11.1 dB |

**恒定的 11–12 dB 说明这不是模型质量问题**（那会让两个模型差得不一样）。
它能被一个共同因子解释，两个候选：

1. **残差起始电平低 + 判据要求饱和。** 抵消侧的残余起始在 −35 dBFS 左右（近底噪），
   旁路的起始就是激励电平。要「看到饱和」需要的超额增益与起始电平有关，
   所以抵消侧被**系统性高估阈值**。旁路侧差 3.9 dB，抵消侧差 11 dB，方向与此一致。
2. **残差通路的实际增益与标定不一致。** 那会同时抬高两侧，但旁路只差 3.9 dB，所以单独不足。

**一次实验可以判定（不需要改代码，也不需要啸叫）：**
在确认稳定的增益（例如 512 在 −4 dB）手动存一段 `mic` + `prediction_pcm` + `residual_pcm`，
比较 8.2–8.6 kHz 的 `|residual|/|mic|`：

- 实测 ≈ −23 dB → 残差本身是对的，模型没问题，**是判据把阈值测高了**，改判据；
- 实测 ≈ −12 dB → 残差真的变差了，那是通路/电平的问题，再查标定条件。

A 已经做了 `GUARD_CAPTURE_SAVED`，只需要在**未触发保护**的稳定点上再存一份。

## 8. 其它两条口径澄清

- **`max|H−Ĥ|` 与 `CD 最差` 是两个量**：前者是残差的绝对电平（决定起振阈值），
  后者是逐频点比值的最小值（可能落在 `|H|` 零点上）。两个都要报，但不能互相替代。
- **A 报的「绝对值整体低 6 dB、怀疑麦克风增益变了」：两批标定数据不支持这个解释。**
  两批电平差 12 dB，`max|H|` 只差 0.3 dB（10.19 vs 9.87）。麦克风增益若真变了 6 dB，
  标定里会直接体现。所以那 6 dB 出在闭环测量，不在麦克风。而且 ASG 是两个阈值之差，
  纯增益变化会自动抵消，解释不了 ASG 的缺口。

## 9. 复现

```text
python scripts/score_time_domain.py --data-dir <目录> --cross-dir <另一场次> --taps 256,512,680
```

输出 `run.txt` 与 `score.json`（本目录）。脚本会自动剔除静音段与延迟不一致段，

## 10. 2026-10-23 追加：绑定频点不同，所以两个模型的偏差方向相反

A 改用尾段余振测阈值（源 1 s + 尾段 1 s），得到 256 ≈ −5.5 dB、512 ≈ −1.5 dB。
用同一批标定数据算「相位允许且显著耦合」的起振点（含 `played[n+2]` 的 2 帧调度）：

| 模型 | 绑定频点 | 模型残差 | 预测阈值 | 实测 | 差 | 该点相干 |
|---|---:|---:|---:|---:|---:|---:|
| 256 | **405 Hz** | −3.30 dB | +3.30 | −5.5 | **2.2 dB** | 0.59 |
| 512 | **334 Hz**（余量最紧但不可信） | −10.89 | +10.89 | −1.5 | 12.4 dB | 0.51 |
| 512 | 4196 Hz / 8655 Hz（可信的次紧点） | −11.10 / −11.52 | +11.10 / +11.52 | −1.5 | 9.6 / 10.0 dB | 0.85 / 0.95 |

**关键点：256 与 512 的绑定频点不是一个地方。** 256 被 405 Hz 的低频限住（模型在那里准，
只差 2.2 dB）；512 把低频补上之后，瓶颈转到 4.2 / 8.4 kHz，而模型在那里乐观约 10 dB。

所以「实测比模型低 11–12 dB」不是一个共因，是**两个不同频点上的两个不同问题**。
这也解释了为什么 256→512 实测只涨 4 dB，而模型说应该涨 7.6 dB：涨得少的那部分，
正是被高频那个学不准的点吃掉的。

### 10.1 高频那 10 dB 的可能来源

实测残差若换算成幅度比：512 实测 |H_eff| = 1.19，模型 0.296，差 4 倍。
在 |H(8392)| = 3.23 的条件下，0.296 对应约 **5°** 相位误差，1.19 对应约 **21°**。
多出的 16° 不可能由一个 24 Hz 的峰值位移解释（窄共振 ±1 bin 只有约 5°），
更像是**该峰在闭环电平下幅度低了 3–4 dB**（3.23−2.04 = 1.19，正好）。

判别只需一次采集：把标定注入提高到 mic ≈ −14 与 −9 dBFS，看 8.4 kHz 峰的幅度。
若峰随电平下降 3–4 dB，这条就成立。（这次采集同时解决低频相干的缺口，一次做完。）

### 10.2 尾段判据的两个结构性缺陷

1. **在底噪上分不清「稳定」和「回路断了」。** 两者都表现为「尾段贴底噪、斜率 ±2 dB/s」。
   2026-10-22 已确认有源音响会待机，实测同一电平下麦克风从 −29.8 掉到 −64.3 dBFS。
   所以 A 表里「256 在 −6 失控、−4 却安静」这种非单调，最可能就是那一次的回路没通，
   而不是物理现象——LTI 回路里增益越高不可能越稳。
2. **失控段的「斜率」不是环路的指数增长率。** 按 T_loop ≈ 1.45 ms 换算，
   +7326 dB/s 相当于 10.6 dB 的超额增益；而 −4 dB 又是稳定的，2 dB 的增益变化
   不可能产生 10.6 dB 的超额。说明那个斜率是在极短窗内拟合的瞬态，不能用来推余量。

### 10.3 建议的测法：用衰减率外推，不用增长判据

突发结束后立刻测包络衰减率（这一段 SNR 还有 20–30 dB，不需要碰底噪）：

```text
r(g) = 20·log10(g·|H|) / T_loop   [dB/s]
```

`r` 对增益（dB）是线性的：**斜率 = 1/T_loop ≈ 690 dB/s per dB**（T=1.45 ms）。
把 3–4 个「稳定」增益点的 r 做线性拟合，**r = 0 的横截距就是阈值**。

这个测法的三个好处：

- 不需要推到啸叫，全部在稳定区完成；
- 不需要在底噪上分辨，用的是突发刚结束那 20–30 dB；
- **死环路会表现为异常陡的衰减**，自动暴露成离群点，不会像现在这样伪装成「稳定」。

顺带它还能反过来校验环路：拟合斜率若明显偏离 690 dB/s per dB，说明延迟或增益标度记错了。

### 10.4 激发方式：不要换扫频，换成「对准绑定频点的窄带突发」

总 RMS 不变（不削波）的前提下，把能量集中到绑定频点周围 400 Hz：

- 20 kHz 宽带 / 400 Hz 窄带 = **17 dB** 的能量集中；
- 尾段起点随之抬高 10 dB 以上，SNR 问题一并解决；
- 且不会像扫频那样在每个频点只停留很短时间。

256 的绑定频点在 405 Hz，512 在 4.2 / 8.4 kHz —— 频带随模型变，不要写死。
