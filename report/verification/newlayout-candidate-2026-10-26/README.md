## 3 系数语义

| 项 | 值 |
|---|---|
| 抽头 | 512（`logical_taps = loaded_taps = 512`，**不需要补零**） |
| `lag_first` | **1**：`p[n] = Σ h[k]·u[n−1−k]`，与 RTL 读 `u[n−1−k]` 一致 |
| Q 格式 | `signed24_fraction20`：`coefficients_q20 / 2^20` |
| Q20 范围 | `[−31959, 43681]`（远小于 ±2^23，无溢出风险） |
| float ↔ Q20 最大差 | `4.729e-07` |
| bias | 文件里写 0.0；**RTL 没有偏置项，不装载**。评价也按 bias=0 做，不用 bias 修饰残差 |
| 舍入 / 饱和 | 系数按"半值远离零"量化；板上累加 58 位、输出 24 位饱和（RTL 既有行为，未改） |
| 帧预算 | 3×512+3 = **1539 拍** < 2048 |

## 4 对齐依据（为什么可以把 mic 挪 1 帧）

六份 capture 的 `ref→mic` 延迟不是同一个整数：

| capture | 整数延迟 | 亚采样延迟（抛物线插值） | 位移 |
|---|---|---|---|
| calib6_1746799426007669601 | 184 | **183.629** | +1（前补 1 个零） |
| calib6_1746799460431974953 | 185 | 184.695 | 0 |
| calib6_1746799495671311695 | 185 | 184.640 | 0 |
| calib6_1746799530870174448 | 185 | 184.706 | 0 |
| calib6_1746799566241828611 | 184 | **183.605** | +1（前补 1 个零） |
| calib6_1746799601922597315 | 185 | 184.670 | 0 |

- **不是"同一个值被取整"**：两组相差 **1.07 采样**，组内只差 0.04–0.09 采样。所以这是两档确定的整采样相位，
  不是连续漂移。
- **不是把延迟消掉**：只把 2 段各**滞后 1 帧**到共同 185，物理延迟完整保留在 H 与模型里；
  对齐后的亚采样延迟仍是 184.66 帧。
- **不是靠对齐凑拟合**：时域拟合对整数平移几乎不敏感（FIR 可以整段平移吸收），这一步真正改变的是
  **跨段累加的交叉谱**——不对齐时门控覆盖率 0.9 %、3000–8200 Hz 相干中位 0.53；对齐后 26.0 % 与 0.92。
  也就是说对齐是把**估计**修对，不是把结果修好。
- **部署口径复核**：把同一套 Q20 系数**不对齐、直接**跑原始六份，总体抑制 +3.16…+4.05 dB
  （中位 +3.58），300–460 Hz +3.77…+5.61 dB（中位 +4.76）。对齐后合并口径是 3.65 / 5.19 dB。
  两者差 0.1–0.4 dB，**收益不是对齐造出来的**。
- **有效窗口**：每份 16384 帧，源实际只覆盖前 **15407** 帧（尾部 977 帧源已停、只有底噪）。
  拟合与残差统计**只用这 15407 帧**，再跳过前 512 帧历史，因此每段有效 **14895** 帧；六段合计 **89370** 帧。
- **段内一致性**：每段前/后半的整数延迟相同（见 `answer_new_layout_325` 的 `[1]` 节），排除段内漂移。

部署轴核对：实测 H 的冲激响应峰在**第 185 帧**，模型冲激响应峰在**第 184 帧**，抽头峰也在第 184 个。
差 **−0.66 帧**是亚采样残差（真实延迟 184.66 帧），整数抽头消不掉，**不据此平移系数**——平移是在同一批数据上
挑一个更"好看"的整数，属于自欺。

## 7 事前预测（现场前写定，不许事后改）

- **预计方向**：装上新系数后，同夹具、同源、同音量、同轮次的闭环扫描边界应**明显高于参考臂**。
  量级按界口径推：旧系数 −8.69 → 候选 +5.32，差 **14.0 dB**；旧系数的界比它的实测（−5.5）保守 3.2 dB，
  若这份保守程度同样成立，候选实测边界约在 **+5…+9 dB**。**但 460–3000 Hz 没测过，那里可能产生新的绑定点**，
  所以合理预期写 **+2…+9 dB**，不给单点值。
- **主导频带**：300–460 Hz，尤其 **423–435 Hz**（界的绑定点）。若现场叫在新系数下仍发生在 325 Hz 附近，
  说明还有别的机制（相位/电平），不是模型拟合本身。
- **假设**：路径在本批电平附近线性、时不变；模型被真正加载（哈希核对）；Codec 档位与音量不变。
- **否定条件（看到就走下一步，不解释成"还需要更多数据"）**：
  - 候选臂比参考臂高 **< 3 dB** → 候选被否定（界口径预期 14 dB，只兑现不到 1/4 说明另有机制），
    回头查场景/电平/装载，不再加算法。
  - 高 **3–8 dB** → 记录实际值，不宣称"显著改善"，工作点按实测边界下 6 dB 取。
  - 高 **≥ 8 dB** → 支持候选，但仍需第二轮同条件重复才能写"可重复"。
- **不能由这次实验得出的**：ASG（需要旁路/抵消成对，且听众判断）、"能听清"、"可以长期用"。

## 8 给 C 的测量条件建议（只给能站住的，其余写未知）

- **不给具体注入档位**。本批只有一档电平（含源 mic ≈ −33 dBFS），没有第二档证据，"再高多少 dB"是未知。
- **给判定量，不给拍脑袋的门限**：
  - 每个绑定频点（321.9 / 327.8 / 423.2 / 429.2 Hz）的相干必须 **≥ 0.8**，否则该频点/该档判**无效**；
  - 必须同时记录**含源总电平**与**源静音底噪**（同窗口、同带宽、同增益），并注明两者之差是
    `(S+N)/N`；若要以纯信号 SNR 表述，用 $\mathrm{SNR}=10\log_{10}(10^{\Delta/10}-1)$ 换算，
    **不能把总电平差直接叫 SNR**（Δ=3 dB → 0.0 dB，Δ=4 dB → +1.8 dB）；
  - 记录削顶/饱和计数与保护事件，二者不等于声学失稳，也不等于 ASG 改善。
- **适用频带**：本候选的有效证据只在 **300–460 Hz 与 3000–10200 Hz**；460–3000 Hz 用本批数据无法评价，
  若现场在该段出问题，不能用"离线已验证"反驳。
- **建议测试范围**：从 **−14 dB 起、以 1 dB 步进向上**，直到出现持续增长的反馈或保护；每档 ≥ 2 s 且要覆盖
  完整起振过程；**每档独立保存**（保护前数据先缓存、触发后先静音再保存）。
- **必测的对照**：同一轮里必须包含**零系数（Ĥ≡0）**与**候选**两个臂，同夹具、同音量、同源。
  旧系数已有负面证据，不需要再在多个增益点重复证伪。

## 9 兼容性与加载

- 支持：现有 512 抽头 `feedback_fir` 位流（`TAPS=512`，`3N+3=1539 ≤ 2048`），**不需要补零**，
  不存在 `loaded` 置位失败的问题（`load_index==TAPS-1` 时置 `loaded`，512 项正好发满）。
- 拒绝条件：位流 `TAPS ≠ 512`；`lag_first ≠ 1`；系数个数 ≠ 512；Q20 任一项超出 ±2^23。
- **加载后必须核对** `coefficients_sha256 = c771a02d…`。仓库已有回归 `sim/feedback/test_newlayout_candidate.py`
  钉住"文件哈希 / 系数哈希 / 清单条目"三者一致——这正是旧系数不在登记里踩过的坑。
- **已知绑定缺口**：采集元数据里的 `fixture_id` 仍是 `room_v1_20261021`，与本模型的 `room_v1_20261026` 不一致。
  C 侧登记批次时要按实际布局覆盖，A 侧最好在采集端改掉源头。

## 10 恢复基线与未做的

- 恢复基线：把 `models/room_v1/candidate_512.json` 或零系数装回去即可；本模型没有改任何 RTL、驱动或接口。
- 明确不做：AFC、多速率、抽头扩展、频带加权、多场次合并。理由：本批只有一场，任何"调参"都会把
  同场交叉验证变成调参记录，无法再作为验证。
- 若本候选被否定，需要的唯一补采（一次给全）：**第三场同夹具 ≥ 8 段的开环 ref/mic**，它能决定
  "跨场次可迁移性"是否存在；在拿到之前，不宣布"物理上无法建模"。
