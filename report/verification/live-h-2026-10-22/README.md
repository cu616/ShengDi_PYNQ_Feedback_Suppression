# 2026-10-22 B 线：用 A 的开环采集与板上 pred 重算，小信号下抵消是有效的

> 数据：A 于 2026-10-22 交付两份采集。
> `live_h_2026-10-21_m30.npz`（reference + microphone）；
> `h30_2026-10-21_m30.npz`（另含板上实际算出的 `prediction_pcm` / `residual_pcm` / `coefficients_q20`）。
> 注入峰值 −30 dBFS，麦克风 −17.88 dBFS RMS / −6.43 dBFS 峰值，零削顶，
> `hp_volume=40`，`fixture_id=box_v1_20261016`，**两只音响都在响**，箱盖关闭。
> 本文所有数字为模型/数据推算，不是实测 ASG。

结论先写：**这份 H 与标定时几乎相同（max\|H\| 26.32 vs 26.06 dB），
在这个小信号电平下抵消是有效的，ASG 约 +9.5…+15 dB。**
A 看到的 `CD +2.4 dB` 是相干门控不足造成的，不是抵消失效。

## 1. 最硬的一条：板上的 pred 直接把 mic 压掉 11 dB

`h30` 里的 `prediction_pcm` 是 PL 用真实系数算出的预测，`verification.bit_exact=True`、
`prediction_mismatches=0`（16128 帧）。所以这一条**不依赖任何模型、任何窗长、任何门控**：

| 量 | 值 |
|---|---|
| max\|mic\| | 4000755 码（−6.43 dBFS） |
| max\|mic − pred\| | 1075878 码（−17.84 dBFS） |
| **峰值比** | **−11.41 dB** |
| **RMS 比** | **−14.06 dB** |

也就是说：把这份 mic 减掉板上算出的 pred，峰值降 11.4 dB、RMS 降 14.1 dB。
**如果一个系统在减完之后信号变小 11 dB，它就不是在放大环路。**

另外验证了板上 pred 与 Python 模型 `fir_response(coefficients_q20)` 的一致性：
幅值比中位 −0.07…+0.30 dB，相位差中位 −1.0…+0.2°，**等效延迟差 −0.115 帧**。
所以 RTL 实现与模型没有错位，这一层不需要再怀疑。

## 2. A 要的三个数

口径：`nperseg=2048`（Hann、50% 重叠、15 段）、频带 100–12000 Hz、**相干门控 ≥0.8**。
用板上 `pred` 作 Ĥ，所以没有模型假设。

### ① 全带

| 量 | 值 |
|---|---|
| max\|H\| | **+26.32 dB @381 Hz** |
| max\|H − H_pred\| | **+11.25 dB @381 Hz** |
| max\|H − Ĥ\|（`fir_response`） | +14.62 dB @429 Hz |
| **ASG** | **+15.06 dB** |
| 抵消预期起振 | **−11.25 dB** |

`H_pred` 与 `Ĥ` 的差别（11.25 vs 14.62）来自 429 Hz 那个 bin：板上 pred 用的是
逐帧定点运算（含 Q20 截断与舍入），与浮点 `fir_response` 在该点差几度相位。
**以 `H_pred` 为准**，它是板上真实发生的事。

### ② 逐子带（CD = 该子带内最不利频点的抵消深度）

| 频段 | max\|H\| | max\|H−H_eff\| | CD 最差 | 相干中位 |
|---|---:|---:|---:|---:|
| 300–600 Hz | +26.32 | +11.25 | **+15.06** | 0.94 |
| 600–1000 Hz | +18.85 | +3.68 | **+14.83** | 0.88 |
| 1000–3000 Hz | +12.62 | −5.61 | **+18.23** | 0.93 |

100–300 Hz 与 3000–12000 Hz 在门控 0.8 下没有可用 bin（相干不足），不给数字。

### ③ CD ≤ 0 的频段

```text
门控 0.8 下 CD<=0 的 bin：0/20（0.0%）
=> 没有 CD<=0 的频段；CD 最低 +14.83 dB @668 Hz
```

**所以在这份数据上，抵消在最不利频点仍有 +14.8 dB 的余量。**

## 3. A 的 `CD +2.4` 是怎么来的：相干门控不足

同一个 300–1000 Hz 子带，只改门控阈值：

| 相干门控 | 参与 bin | max\|H−Ĥ\| | CD 最差 |
|---|---:|---:|---:|
| 0.0（不门控） | 29/29 | +22.89 dB | **−14.26 dB** |
| 0.5 | 18/29 | +22.89 dB | **+2.37 dB** ← A 报的 +2.4 |
| 0.7 | 16/29 | +14.62 dB | **+9.49 dB** |
| 0.8 | 15/29 | +14.62 dB | **+9.49 dB** |

那个 +22.89 dB 的残差落在 **906 Hz，相干仅 0.532**。900 Hz 附近的相干一片塌陷：

```text
906 Hz  0.532     882 Hz  0.378     930 Hz  0.448
739 Hz  0.005     858 Hz  0.047     763 Hz  0.063     787 Hz  0.237
```

相干 0.005 意味着该频点的 mic 基本与 ref 无关，`H = Sum/Suu` 在那里是两个噪声相除，
**算出来的 |H| 和 |H−Ĥ| 都没有物理意义**。把它们算进 max，就把结论拖成"抵消只有 +2.4 dB"。

这与 2026-10-21 在标定数据上踩过的坑是同一个（当时 12 kHz 以上相干 0.05，
把 CD 中位数拉到 0）。**门控不是可选项。**

## 4. 与闭环观测对照：抵消侧吻合，旁路侧已知是假阴性

| 观测量 | 本报表预测 | A 的闭环实测 | 判定 |
|---|---|---|---|
| 旁路起振 | −26.32 dB | −18 dB "稳定 10 s" | **矛盾**，已由音响待机解释 |
| 抵消起振 | −11.25 dB | **−12 dB 起振** | **吻合**，差 0.75 dB |
| ASG | +15.06 dB | 无法测（旁路缺失） | — |

抵消侧那一条是有分量的：A 是在完全不知道这份 H 的情况下，在板上把增益推到 −12 dB
看到抵消起振的；而这份 H 与板上的 pred 给出的预测是 −11.25 dB。**两者差 0.75 dB。**

旁路侧 −18 dB "稳定" 与预测 −26.3 dB 差 8 dB，正是 A 查出的音响待机那一段。
**把待机那一侧去掉，剩下的一侧支持"抵消有效"。**

### 4.1 "抵消比旁路更饱和"这条比较不成立

A 观测到 −12 dB 时抵消饱和计数 8501、旁路 1030，据此认为抵消更早失稳。
但若旁路阈值确为 −26.3 dB，−12 dB 远在其上，旁路本该持续满幅、计数很高。
计数低更可能是那次旁路试验时音响已经待机（回路断开，只剩底噪）。

**比较两个阈值，前提是两次试验的音响状态相同。** 这一条不只是"稳定侧不可信"，
**"起振侧的跨试验比较"同样不可信**。单次"叫了"是可信的（待机不会伪造啸叫），
但"抵消比旁路更早起振"需要两次都有效。

## 5. 所以"H 随电平收缩"暂时不需要假设

A 提出：小信号 H 说抵消为正、大信号闭环说抵消更差，所以怀疑 H 随电平变化。

**这个矛盾在门控 0.8 下就不存在了**：小信号 H 给的抵消阈值 −11.25 dB，
与闭环 −12 dB 起振吻合。A 之所以觉得矛盾，是因为他用门控 0.5 的估计
（CD 只有 +2.4 dB，对应阈值 −2.4 dB），而闭环却在 −12 dB 就起振——看起来像"H 变了"。

按正确口径，**不需要引入电平依赖就能解释现有一切**。

电平扫描仍然值得做，但它的目的变了：不再是"解释矛盾"，而是"确认在大信号下
（尤其是啸叫满幅那种非线性区）抵消是否退化"。优先级低于重测闭环阈值。

## 6. 给 A 的下一步建议

### 6.1 优先级 1：重测闭环阈值，每档带正向对照

这是唯一能给出可写进报告的 ASG 的东西。要求：

- 每档试验**前后各做一次**正向对照（直放已知电平，麦克风电平落在基线 ±3 dB 内才算有效）。
  直放电平建议 −40 dBFS（麦约 −17 dBFS，离削顶 17 dB，待机那种 −30 dB 的塌陷一眼看得出）。
- 旁路与抵消**同一次会话内交替做**，不要隔开，避免音响状态漂移。
- 每档录 mic 与 pred 两路（像 `h30` 那样）。

### 6.2 优先级 2：电平扫描（A 提的判据，改三处就够）

| A 的打算 | 建议 |
|---|---|
| −30 与 −18 dBFS 两档 | 改成 4 档：麦克风约 −30 / −24 / −18 / −12 dBFS。闭环工作点在 −12 dB 附近，只测到 −18 覆盖不到 |
| 只看 `max\|H\|` 是否收缩 | 看**三样**：① 时域 `max\|mic−pred\|/max\|mic\|`（无窗长依赖）；② CD 最差（门控 0.8）；③ `\|H_high/H_low\|` 的频响形状（区分"整体缩放"与"形状改变"） |
| 16384 帧（15 段） | 改 65536 帧（1.34 s，63 段）。现在 15 段的方差已经大到窗长从 2048 换到 4096 就使 ASG 从 15 变 9 |
| 激励用现有宽带噪声 | 够用。扫频不必——它反而让相干门控更难设，而且非线性在正弦上更难判 |

**判据**：若某档的时域抑制从 −11 dB 掉到 −5 dB 以内，或 CD 最差降到 +3 dB 以下，
就是非线性开始吃掉抵消余量的证据，那时再谈架构。

## 7. 局限

- 16384 帧只有 15 段，`|H|` 的估计方差偏大：同一份数据换窗长，ASG 在 +9.3…+15.1 之间变化。
  **这只影响精度，不影响符号**——所有窗长下 CD 都为正（除 8192 那个只有 3 段的退化情形）。
- 频带只覆盖到 1000–3000 Hz 有可用 bin，更高频相干不足，不能对高频下结论。
- 本文的 ASG 是小信号（−30 dBFS 注入）的线性预测，**不是实测 ASG**。
  实测 ASG 必须来自 6.1 的闭环重测。
- 两只音响都在响时，声场是两个源的叠加；本文没有分离它们各自的贡献。
  若标定与实测的在线只数不同，H 会不同——这一点仍需 A 确认。
