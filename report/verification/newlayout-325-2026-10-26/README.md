# 新布局 325 Hz：A 的三个数字与延迟错配

回答 A（提交 `f45449d`）的三个问题：新布局 325 Hz 处的 `|H|` 与 `CD`、512 抽头在新布局允许的最大数字增益、
只压一个点的陷波要多深。同时用数据判断他第 4 节那条推测（不可预测能量里有超出 512 抽头记忆的拖尾）。

结论先说：**差的不是 8.3 dB，也不是模态从 435 移到 325。板上那套系数（`93f7ab6e`）的冲激响应峰在
第 128 抽头，而新布局的路径延迟是 185 帧——整套模型早了 57 帧（1.17 ms）。** 用同一个判据在这份新数据上
重算，预测边界 −5.66 dB @326.5 Hz，A 实测 −5.5 dB @325 Hz，差 **0.16 dB**。

## 2 口径

- H：`diagnose_peak_margin.estimate_H`（Welch 交叉谱，Hann，50 % 重叠，nfft=8192 → 5.96 Hz/bin），
  相干 ≥0.8 且 ≥300 Hz 才进门控。nfft=4096 作分辨率敏感性。
- 判据：`reproduce_b_screening.thresholds`，两套分开报——**采样网格小增益界** `−20·log10 max|(H−Ĥ)e^(−jω2)|`
  与 **正实轴穿越**；`lag_first=1`、2 拍调度各计一次。
- 拟合：`segment_gram`/`solve_ridge`，ridge=1e-9，窗口不跨段，`y[n]=Σh[k]·u[n−1−k]`。
- 逐段时域残差用 `predict_stream`。
- 本脚本**不新增任何判据**，只多做"逐段对齐"这一步。

## 4 (a) 325 Hz 处的 |H| 与 CD

325.0 Hz 不落在 5.96 Hz 的网格上，取两侧 bin（321.87 / 327.83，相干 0.87 / 0.86）在对数幅度上插值：

| 模型 | \|H\| | \|Ĥ\| | 残差 \|H−Ĥ\| | **CD(325)** |
|---|---|---|---|
| 板上 `93f7ab6e`（旧布局） | **+1.04 dB** | −2.31 dB | **+5.41 dB** | **−4.37 dB** |
| 新布局重拟合 512（in-sample） | +1.04 | −1.41 | −10.07 | **+11.10** |
| 新布局 512，CV 折 a（train 024→test 135） | +1.04 | −2.00 | −8.98 | +10.02 |
| 新布局 512，CV 折 b（train 135→test 024） | +1.04 | −0.72 | −11.15 | +12.19 |
| 不装模型（Ĥ≡0） | +1.04 | — | +1.04 | 0.00（定义值） |

两侧 bin 的原值：板上 CD = −4.47 / −4.27；重拟合 CD = +13.58 / +8.88。

**CD 是负的。** `|H−Ĥ|` 比 `|H|` 还大 5.4 dB：板上这套系数在新布局上不是"抵消不够"，是**在放大残差**。
这个判断不依赖分半噪声：325 Hz 处两半 H 的差是 −12.8 / −10.6 dB，而残差高出它 15.95 dB。

重拟合的 +11.10 dB 则是**下界**：残差只比估计噪声高 0.5–1.6 dB，噪声只会把 CD 压低，不会抬高。

## 5 (b) 512 抽头在新布局允许的最大数字增益

| 配置 | 采样网格小增益界 | 正实轴穿越 | 与 A 实测 −5.5 之差 |
|---|---|---|---|
| **板上 `93f7ab6e`（A 实际跑的）** | −8.49 @417.2 | **−5.66 @326.5** | **−0.16 dB** |
| 新布局重拟合 512（in-sample） | +4.95 @429.2 | +12.88 @322.2 | +10.45 |
| 新布局 512 CV 折 a / 折 b | +5.19 / +4.35 | +10.41 / +17.91 | +10.69 / +9.85 |
| 不装模型（Ĥ≡0） | −3.16 @423.2 | −1.64 @328.3 | +2.34 |

三条都要读：

1. **A 的实测和我们的模型没有差 8.3 dB。** 他拿 −5.5 去比的是**旧布局**的 +2.77。在同一份新数据、同一套
   板上系数上，穿越判据说 −5.66 @326.5，与实测 −5.5 @325 差 0.16 dB——频率和电平同时对上了。
2. **他跑的那套系数比不装模型还差 4 dB**（穿越 −5.66 vs −1.64）。所以"限制点从 435 移到 325"不是主因：
   残差在 310–450 Hz 整段都是正的（CD 全负），相位选中哪个 bin 就哪个 bin 叫。
3. **换成在新布局上重拟合的 512，界到 +4.35…+5.19 dB**，比现在的实测边界高约 10 dB。但这是离线数字，
   必须用 A 的同一套扫描在板上复测才算数。

小增益界比穿越判据保守约 3 dB（板上：−8.49 vs −5.66，实测 −5.5）。这是充分条件的正常代价，不是矛盾。

## 6 (c) 只压 325 一个点的陷波要多深

陷波在目标频点上是乘性的，深度 A 直接把该 bin 的 `g_bin` 抬高 A dB。所以"要多深"只能和"压完之后天花板
在哪"一起问——天花板 = 挖掉 325 ± 25 Hz 之后剩余过门控 bin 里最紧的那个。

| 基线 | 到 0 dB | 到 +6 dB | 挖掉 325±25 后的天花板 | 单点陷波够不够 |
|---|---|---|---|---|
| 板上 `93f7ab6e` | 325 处需压 **5.41 dB** | 需压 **11.41 dB** | **−8.49 dB @417.2** | **不够** |
| 新布局重拟合 512 | 已 +10.07，不需压 | 差 4.07（但实际绑定在 429.2，只差 ~1 dB） | +4.95 @429.2 | 0 dB 够；+6 dB 差一点 |

板上系数那一行是决定性的：**325 处压 5.4 dB 确实能把那一个 bin 推到 0 dB，但 387–447 Hz 这一整片
（CD −7 到 −8.5 dB）会立刻接住。** 300–460 Hz 逐 bin 允许增益（dB）：

```
板上      310:-3.3  316:-3.9  322:-4.8  328:-6.0  334:-6.0  370:-4.3  387:-7.5  393:-7.8
          399:-7.8  405:-7.7  411:-7.9  417:-8.5  423:-8.3  429:-7.8  435:-7.2  447:-4.9
重拟合    310:+13.0 316:+15.2 322:+13.3 328:+7.2  334:+6.4  370:+5.2  387:+8.6  393:+8.7
          399:+10.1 405:+9.1  411:+8.3  417:+6.3  423:+5.3  429:+4.9  435:+6.4  447:+10.4
```

不是"一个单模"，是**一整片 140 Hz 宽**。所以答案是：**在现在这套系数下任何浅陷波都不够；换成新布局的
系数之后，325 Hz 上根本不需要陷波**，那时的限制点是 `|H|` 峰 429 Hz，再到 +6 dB 只差约 1 dB。

## 7 机制：不是模态搬家，是延迟错了 57 帧

| | 冲激响应峰位 | 对应滞后 |
|---|---|---|
| 板上 `93f7ab6e` | 第 128 抽头 | 128 帧 |
| 新布局重拟合 512 | 第 184 抽头 | 184 帧 |
| 实测路径延迟 | — | **185 帧** |

旧 0.5 m 正向夹具的 `ref→mic` 延迟是 124/125 帧。板上那套系数的能量峰正好落在 128——它是按旧几何做的，
而新布局的路径长了约 60 帧（1.23 ms）。整套滤波器的抽头都指向一个早到 1.2 ms 的信号，所以低频残差是正的。

纯延迟平移扫描（只挪系数、不动别的）：

| shift | 小增益界 | 目标点 CD |
|---|---|---|
| 0（现状） | −8.49 | −4.37 |
| +40 | −6.43 | +0.22 |
| +55 | −2.28 | +6.44 |
| **+60** | **−1.05** | **+10.03** |
| +68 | +2.98 | +12.96 |
| +80 | −0.24 | +5.18 |
| 参照：重拟合 | +4.95 | +11.10 |

**CD(325) 15.5 dB 的缺口里，约 14.5 dB 只由延迟错配解释。** 但平移不是修复方案：它同时砍掉 60 抽头的
尾部记忆、并把高频拟合全打散（界只到 −1…+3，重拟合是 +4.95），所以正解还是按新布局重拟合。

## 8 A 的第 4 节推测：长记忆到底值多少

时域残差（总体 / 300–460 Hz）与小增益界，in-sample 与 3/3 交叉验证：

| 抽头 | 总记忆 | 扣掉 185 帧延迟后可用 | 总体抑制 in/cv | 300–460 in/cv | 界（CV） |
|---|---|---|---|---|---|
| 256 | 5.24 ms | 1.45 ms | 1.74 / 1.62 | 1.50 / 1.38 | −2.25 |
| **512** | 10.49 ms | 6.70 ms | 3.81 / 3.56 | 4.76 / 4.62 | **+4.35** |
| **680**（器件上限 681） | 13.93 ms | 10.14 ms | 4.08 / 3.78 | 5.90 / 5.73 | **+4.97** |
| 1024 | 20.97 ms | 17.18 ms | 4.53 / 4.17 | 7.41 / 7.32 | +9.12 |
| 2048 | 41.94 ms | 38.15 ms | 4.83 / 4.33 | 8.20 / 7.96 | +10.74 |

三条判读：

1. **方向对，量级不如他想的。** 512（10.5 ms）→ 2048（42 ms）在 300–460 Hz 只多 3.3 dB（cv），总带只多 0.8 dB。
   不是"一半干扰是拖尾"，拖尾确实是可收的，但收它是小头。
2. **真正卡住的是器件，不是物理。** 512→680（装得下）只 +0.6 dB；512→1024（装不下）才有 +4.8 dB。
   所以"加抽头"这条路的收益上限被 681 抽头/BRAM 80 % 锁死，不在算法。
3. **256 只有 1.45 ms 可用记忆**——512 抽头里 3.79 ms 是纯传播延迟。这解释了为什么 64/128 抽头完全无效
   （够不到直达声），也说明"抽头数"和"记忆长度"在这个距离上不是一回事。

结论不变：**换系数（+10 dB）≫ 加抽头（≤+0.6 dB）> 加陷波（板上系数下不可达）。**

## 9 边界（不得越过）

- 全部是**离线数字**。没有板上复测的新系数，没有 ASG，没有 MSG，没有听感。
- 460–3000 Hz 未过门控（相干中位 0.28–0.35），该段的 `|H|`、CD、允许增益一律**未知**，不得插值。
- 板上 `93f7ab6e` 不在 `models/` 任何一条里，"它是旧布局模型"只由冲激响应峰位 128 和实测残差支撑，
  不由训练记录支撑。
- 重拟合的 +4.35…+5.19 是同一场次 in-sample / 3-3 交叉验证，**不是留出场次**，也没有第三场。
- 参考电平只有一档（mic −33 dBFS），"H 随电平变"未被检验。
- 单点陷波那张表按"陷波只改幅度、不改相位"算，是上界；真实 biquad 的相位会改变穿越点。

## 10 给 A 的一条可执行项

3. 判成功的口径不是"没叫"，而是"比 −5.5 dB 高多少 dB 仍稳"。
