# 新布局 325 Hz：A 的三个数字、判据稳定性与延迟错配

回答 A（提交 `f45449d`）的三个问题：新布局 325 Hz 处的 `|H|` 与 `CD`、512 抽头在新布局的允许增益、
只压一个点的陷波要多深。同时用数据判断他第 4 节那条推测（不可预测能量里有超出 512 抽头记忆的拖尾）。

**先说两条修正，都是我自己上一版说错的：**

1. **穿越判据在本批数据上不稳定。** 上一版报"预测 −5.66 dB @326.5，实测 −5.5 @325，差 0.16 dB"——
   那是一组分析选项（nfft=8192 + 全 16384 帧窗口）下的结果。换窗口或换分辨率，这个穿越点就消失或跳走
   （见 §6）。**所以它不能当定量验证，只能算一次巧合级的支持。** 能站住的是小增益界。
2. **不是"差 8.3 dB"。** 但也不是"完全对上"：旧系数与零系数的差，按界口径是 **+5.5 dB**、
   按穿越（唯一给出低频点的那个组合）是 +4.0 dB，A 现场约 3 dB。**方向一致，量级 3–5.5 dB。**

真正稳的结论只有一条：**板上那套系数（`93f7ab6e`）的冲激响应峰在第 128 抽头，而新布局的路径延迟是
185 帧——整套模型早了 57 帧。** 换系数后离线界从 −8.69 dB 升到 +5.27 dB（+13.9 dB）。

## 2 口径

- H：`diagnose_peak_margin.estimate_H`（Welch 交叉谱，Hann，50 % 重叠，nfft=8192 → 5.96 Hz/bin），
  相干 ≥0.8 且 ≥300 Hz 才进门控；nfft=4096 作分辨率敏感性。
- 判据：`reproduce_b_screening.thresholds`，两套分开报——**采样网格小增益界**
  `−20·log10 max|(H−Ĥ)e^(−jω2)|` 与 **正实轴穿越**；`lag_first=1`、2 拍调度各计一次。
- 拟合：`segment_gram`/`solve_ridge`，ridge=1e-9，窗口不跨段，`y[n]=Σh[k]·u[n−1−k]`。
- 统计只用源有效帧（15407/段），不把尾部静音算进残差或相干。

门控合计 **1066 / 4046 = 26.3 %**。**460–3000 Hz 实质没有覆盖**（门控 6 个 bin），一律记未知，不填数。

原因是注入太低：mic 只有 −33 dBFS，开环底噪约 −36…−37 dBFS。**这两个数之差 3–4 dB 是含源总功率
与背景功率的差，不是纯信号 SNR**；按同宽带扣背景 $\mathrm{SNR}=10\log_{10}(10^{\Delta/10}-1)$ 换算，
纯信号 SNR 只有 **0–1.8 dB**，单 bin 相干上限 $\mathrm{SNR}/(1+\mathrm{SNR})\le 0.5$，
与实测中位 0.28–0.35 自洽。

新布局 `max|H|` 只有 **+3.15 dB**（旧房间夹具 +11.11 dB @8380，旧 8.4 kHz 峰在这里已不存在），
所以这个夹具是弱耦合、但路径长、信噪比差的组合。

## 4 (a) 325 Hz 处的 |H| 与 CD

325.0 Hz 不落在 5.96 Hz 网格上，取两侧 bin（321.87 / 327.83，相干 0.89 / 0.88）在对数幅度上插值：

| 模型 | \|H\| | \|Ĥ\| | 残差 \|H−Ĥ\| | **CD(325)** |
|---|---|---|---|
| 板上 `93f7ab6e`（旧布局） | **+1.24 dB** | −2.31 dB | **+5.50 dB** | **−4.27 dB** |
| 新布局重拟合 512（in-sample） | +1.24 | −1.41 | −9.63 | **+10.86** |
| 新布局 512，CV 折 a（train 024→test 135） | +1.24 | −2.00 | −8.53 | +9.76 |
| 新布局 512，CV 折 b（train 135→test 024） | +1.24 | −0.72 | −10.86 | +12.10 |
| 不装模型（Ĥ≡0） | +1.24 | — | +1.24 | 0.00（定义值） |

**CD 是负的。** `|H−Ĥ|` 比 `|H|` 高 4.27 dB（这就是 CD 的绝对值；`+5.50` 是残差路径的**绝对电平**，
两个数不同量，不能混用）：板上这套系数在新布局上不是"抵消不够"，是**在放大残差**。
这个判断不依赖噪声：325 Hz 处两半 H 的差是 −7.9 / −7.0 dB，而残差比它高 12.5 dB。

重拟合的 +10.86 dB **不能当严格下界**：复数估计误差可让 `|H估计−Ĥ|` 变大也可能变小，同批 in-sample
还可能偏乐观。可以说的是"残差已经落到分半差以下（−9.63 对 −7.02），说明该频点的 CD 超出本批数据
能分辨的范围"，因此只能报 **≥10 dB 量级**，不能报精确值。

## 5 (b) 512 抽头在新布局的允许增益（两个判据）

先划清：下面两列都是**判据给出的界**，不是实测最大增益，也不是硬件性能上限。实测值是唯一的现场事实。

| 配置 | 采样网格小增益界 | 正实轴穿越（nfft=8192，源有效帧） |
|---|---|---|
| **板上 `93f7ab6e`（A 实际跑的）** | **−8.69 @417.2** | −5.84 @327.1 |
| 新布局重拟合 512（in-sample） | **+5.27 @417.2** | +10.95 @323.3 |
| 新布局 512 CV 折 a / 折 b | +5.34 / +4.82 | +8.96 / +17.44 |
| 不装模型（Ĥ≡0） | **−3.15 @417.2** | +3.06 @3730.8 |

三条要读：

1. **A 的 −5.5 dB 与"旧系数"对得上，但不是我们这个界对得上。** 界给 −8.69，比实测保守 3.2 dB；
   与实测接近的是穿越判据（−5.84 vs −5.5，差 0.34 dB）——**而穿越判据不稳定，见 §6**。
2. **板上那套比不装模型差 5.5 dB（界）**，方向与 A 的板上比较（旧系数更差、约 3 dB）一致。
   所以"限制点从 435 移到 325"不是主因：310–450 Hz 整段的 CD 都是负的，相位选中哪个 bin 就哪个 bin 叫。
3. **换成在新布局上重拟合的 512，界从 −8.69 升到 +5.27，差 +13.9 dB。** 同口径比较，
   不要把界和实测直接相减——那会把判据的保守程度算成收益。

## 6 判据稳定性：这是本轮最该记住的一张表

同一份数据、同一套 H，只改两件事（统计窗口 / nfft），**穿越判据就不可复现**：

| 判据 | 全 16384 帧 8192 | 源有效 15407 帧 8192 | 全帧 4096 | 源有效 4096 |
|---|---|---|---|---|
| 旧系数 界 | −8.49 | −8.69 | −7.68 | −7.56 |
| 旧系数 穿越 | **−5.66 @326.5** | **−5.84 @327.1** | **+0.05 @3973** | **+0.02 @3973** |
| 零系数 界 | −3.16 | −3.15 | −2.41 | −2.25 |
| 零系数 穿越 | −1.64 @328.3 | **+3.06 @3730** | +3.95 @3731 | +4.18 @3731 |
| 候选 界 | +5.12 | +5.32 | +6.63 | +6.82 |
| 候选 穿越 | +11.70 | +10.02 | +21.03 | +21.11 |

- **界稳定**：旧 −7.6…−8.7、零 −2.3…−3.2、候选 +5.1…+6.8；两者之差的比较更稳
  （候选−旧 +13.0…+13.9，零−旧 +4.3…+5.3）。所以本轮只用界做定量结论。
- **穿越不稳**：低频的穿越点只在 nfft=8192 存在，且零系数在换窗口后从 −1.64 跳到 +3.06。
  上一版用"−5.66 vs 实测 −5.5"当验证，是挑了有利的组合，**撤回**。
  正确说法：**穿越判据在本批数据上给不出可依赖的绝对阈值**，只能说明"相位条件大致落在 320–330 Hz 附近"。

## 7 (c) 只压 325 一个点的陷波要多深

陷波在目标频点上是乘性的，深度 A 直接把该 bin 的界抬高 A dB。所以"要多深"必须和"压完之后天花板在哪"一起问。

| 基线 | 到 0 dB | 到 +6 dB | 挖掉 325±25 后的天花板 | 单点陷波够不够 |
|---|---|---|---|---|
| 板上 `93f7ab6e` | 325 处需压 **5.50 dB** | 需压 **11.50 dB** | **−8.69 @417.2** | **不够** |
| 新布局重拟合 512 | 已 +9.63，不需压 | 差 3.63（实际绑定 417.2，只差 ~0.7） | +5.27 @417.2 | 0 dB 够；+6 dB 差一点 |

板上系数那一行是决定性的：**325 处压 5.5 dB 确实能把那一个点推到 0 dB，但 387–447 Hz 这一整片
（−7.1…−8.7 dB）会立刻接住。** 300–460 Hz 逐 bin 界（dB）：

```
板上      310:-3.5  316:-4.2  322:-5.0  328:-6.0  387:-7.9  393:-7.9  399:-7.8
          405:-7.6  417:-8.7  423:-8.2  429:-7.8  435:-7.1  447:-4.8
重拟合    310:+12.2 316:+13.8 322:+11.9 328:+7.6  387:+6.6  393:+8.3  399:+12.2
          405:+10.0 417:+5.3  423:+5.5  429:+5.5  435:+7.1  447:+12.7
```

不是"一个单模"，是**一整片 140 Hz 宽**。所以：**在现在这套系数下任何浅陷波都不够；换成新布局的
系数之后，325 Hz 上根本不需要陷波**，那时限制点是 `|H|` 峰 417 Hz，再到 +6 dB 只差约 0.7 dB。

## 8 机制：不是模态搬家，是延迟错了 57 帧

| | 冲激响应峰位 |
|---|---|
| 板上 `93f7ab6e` | 第 **128** 抽头（=滞后 128） |
| 新布局重拟合 512 | 第 **184** 抽头 |
| 实测 H 的冲激响应峰 | **第 185 帧**（亚采样 184.66） |

旧 0.5 m 正向夹具的 `ref→mic` 延迟是 124/125 帧。板上那套的峰落在 128，与新路径差约 57 帧
（1.17 ms ≈ 40 cm）。整套滤波器的抽头都指向一个早到 1.2 ms 的信号，所以低频残差是正的。

纯延迟平移扫描（只挪系数、不动别的）：

| shift | 界 | 目标点 CD |
|---|---|---|
| 0（现状） | −8.69 | −4.27 |
| +40 | −6.27 | +0.45 |
| +55 | −2.01 | +6.73 |
| **+60** | −1.21 | **+10.12** |
| +68 | +3.58 | +12.29 |
| 参照：重拟合 | +5.27 | +10.86 |

**CD(325) 约 15 dB 的缺口里，大部分只由延迟错配解释。** 但平移不是修复方案：它同时砍掉 60 抽头的
尾部记忆、并把高频拟合打散（界最高只到 +3.6，重拟合是 +5.27），所以正解还是按新布局重拟合。

## 9 板上系数的身份缺口

`93f7ab6e` 不在 `models/` 任何一条里。我只能从冲激响应峰位（128，对应旧夹具 124/125 的延迟）和
残差反推它是旧布局的产物，**不能从训练记录确认**。这也是本轮把候选正式登记进
`models/manifest.json` 的原因。

另一个缺口：六份采集的 metadata 里 `fixture_id` 仍写着 `room_v1_20261021`（旧编号），
而实际是新布局。这属于采集端要改的东西，不是分析能补的。

## 10 A 的第 4 节推测：长记忆到底值多少

时域残差（总体 / 300–460 Hz）与小增益界，in-sample 与 3/3 交叉验证：

| 抽头 | 总记忆 | 扣掉 185 帧延迟后可用 | 总体抑制 in/cv | 300–460 in/cv | 界（CV） |
|---|---|---|---|---|---|
| 256 | 5.24 ms | 1.45 ms | 1.78 / 1.66 | 1.51 / 1.38 | −2.16 |
| **512** | 10.49 ms | 6.70 ms | 3.89 / 3.64 | 4.72 / 4.59 | **+4.82** |
| **680**（当前帧预算上限 681） | 13.93 ms | 10.14 ms | 4.17 / 3.87 | 5.85 / 5.68 | **+5.49** |
| 1024 | 20.97 ms | 17.18 ms | 4.64 / 4.27 | 7.39 / 7.30 | +9.72 |
| 2048 | 41.94 ms | 38.15 ms | 4.95 / 4.43 | 8.58 / 8.40 | +10.07 |

1. **方向对，量级不如他想的。** 512（10.5 ms）→ 2048（42 ms）在 300–460 Hz 只多 3.7 dB（cv），
   总带只多 0.8 dB。拖尾确实可收，但收它是小头。
2. **卡住在当前串行 MAC 的每帧计算预算，不在器件。** 512→680（3N+3=2043 拍，帧预算内、未综合验证）
   只 +0.7 dB；512→1024（3075 拍，超出每帧 2048）才有 +4.9 dB。**681 不是 BRAM 上限**：
   FIR 的 `coefficients`/`history` 两个 24 位数组在 512 抽头合计约 24.6 kbit，680 抽头仍装进同一个块；
   512 时 BRAM 80 % 主要来自回放源与抓取缓冲。
3. **256 只有 1.45 ms 可用记忆**——512 抽头里 3.79 ms 是纯传播延迟，这解释了为什么 64/128 抽头完全无效。

## 11 边界（不得越过）

- 全部是**离线数字**。没有板上复测的新系数，没有 ASG，没有 MSG，没有听感。
- 460–3000 Hz 未过门控（门控 6 bin），该段的 `|H|`、CD、界一律**未知**，不得插值。
- 判据的绝对阈值不稳（§6），只有**同口径的相对比较**可引用。
- 板上 `93f7ab6e` 的来源只能反推，不能从训练记录确认。
- 重拟合的 +5.27 是同一场次 in-sample / 3-3 交叉验证，**不是留出场次**，也没有第三场。
- 参考电平只有一档（mic −33 dBFS），"H 随电平变"未被检验。
