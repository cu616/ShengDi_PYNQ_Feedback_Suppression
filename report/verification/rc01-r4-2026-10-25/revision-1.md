# RC0.1-r4 预测（口径修订 1）——两臂闭环

> **这是口径修订，不是事后追认的"事前预测"。**
> 原稿在 `README.md`（提交 `dbf2858`），保留不动；其中受迫响应口径已作废，本文取代之。
> 触发：C 的独立反例——`M=0` 时 OFF 与 ON 是**同一个闭环**，ON/OFF 必须是 0 dB，
> 而原实现在 `H=0.5、Q12=817、429.153 Hz` 给出 **+0.906 dB**。反例成立，是我把 OFF 当开环 `H` 直接比。
> 基准：C = `60b3a30` 的对审 JSON；工作点仍取 r4 包常量（Q12=817／−14 dB／Codec40／EQ identity／delay 2 拍）。

## 1 修了什么

| 项 | 原稿（作废） | 修订后 |
|---|---|---|
| OFF 臂 | `T_off = H`（开环） | **`T_off = H/(1 − g·D·H)`**（闭环，预测恒零） |
| ON 臂 | `T_on = H/(1 − g·D·(H−M))` | 不变 `T_on = H/[1 − g·D·(H−M)]` |
| 带内受迫响应 | 按 `|H|²` 加权后逐 bin 比值 | **两臂各算 `|T|²`，带内功率积分再比** |
| 余量／环路增益 | 原稿写成 `g + 允许增益`（**负号算两次的公式错误**，既不是余量也不是环路增益） | **余量 = B − g**；**环路增益 dB = g − B = −余量**，分开列 |
| 派生量 | — | 新增 `M≡0` 与 `M≡H` 两个闭式控制，进 JSON |

`D = e^{−jω·2}`，`M` 含 `lag_first=1`。两个控制（同一门控网格，300–1000 Hz）：

| 数据 | `M≡0` | `M≡H` | 闭式 | 差 |
|---|---|---|---|---|
| train 8192 | **+0.000e+00 dB** | −1.046 | −1.046 | 0 |
| train 4096 | **+0.000e+00 dB** | −1.054 | −1.054 | 0 |
| heldout 8192 | **+0.000e+00 dB** | −1.253 | −1.253 | 0 |
| heldout 4096 | **+0.000e+00 dB** | −1.126 | −1.126 | 1.1e−15 |

`M≡H` 时 `T_on ≡ H`，闭式 = `Σ|H|² / Σ|H/(1−gDH)|²`，与实现逐位吻合。

## 1.1 判据性质（N1）

- `max|g·L| < 1` 是**小增益充分条件**，不是必要条件：只在**完整频率范围**与相关稳定性假设
  （线性、时不变、无饱和）成立时才担保稳定。本门控网格只有 29% 的 bin 过门（8.4k 带 7.5%），
  因此它**不能担保全频稳定**，也**不能**因为"某处 <1"就说该频段一定不啸叫。
- 因此下文一律称 **采样网格小增益界 B**（`1/max|·|`，只在过门控 bin 上），不再叫
  "允许增益"或"Nyquist 必要条件"——旧的四处措辞（本文 §2 末句、§1 旧表格的"其实是环路增益"、
  `band_switch_table` 注释、入口 `[7]` 的"（Nyquist 近似）"）已一并改掉。
- 它与正实轴穿越是两套估计，**分别报告**，不互相替代，也不拼成一个区间。
- **余量 = B − 实际增益 g**；**环路增益 dB = g − B = −余量**。
  原稿的 `实际 + 允许` 是把负号算了两次的**公式错误**，那个量既不是余量也不是环路增益。

## 2 采样网格小增益界与余量（留出 6 段，nfft=8192）

| 量 | OFF | ON | 差 |
|---|---|---|---|
| **采样网格小增益界 B** = 1/max\|H\| 或 1/max\|L\|（dB） | **−7.40** | **+2.77** | +10.17 |
| **余量 = B − 实际增益 g**（dB） | **+6.60** | **+16.78** | +10.18 |
| 环路增益 dB = g − B（dB） | −6.60 | −16.78 | — |
| **正实轴穿越**（另一套估计，独立报告） | −6.46 | +6.60 | — |

与 C 给的参考值（OFF +6.605、ON +16.778）一致（差 0.005 dB，取整）。4096 为 +7.43 / +18.56。

**这个 B 的口径**：它就是"在这批**过门控 bin** 上，环路增益还差多少 dB 到 1"，即一个小增益充分条件的下界；
**不是**必要条件的估计，也**不是**全频稳定判据。它与正实轴穿越是两套估计，分别报告、不拼区间。
未过门控的 71% 频段（8.4k 带 92.5%）对这两个数都没有贡献。

## 3 受迫响应（修订后的主要变化）

| 频带（留出 8192） | 门控/总 | ON−OFF（带功率） | 逐 bin 范围 | 更差 bin |
|---|---|---|---|---|
| 300–1000 | 90/117 | **−1.15 dB** | — | 0 |
| 1000–3000 | 312/336 | **−0.22 dB** | — | 0 |
| 8200–8600 | 5/67 | **+0.31 dB** | — | 0 |
| 合格 bin 参考（非现场全带 RMS） | 1189/4046 | **−0.42 dB** | −4.06 … +2.46 | **1 @3517 Hz** |

**统计量说明（N2）**：这一行是**过门控 bin 上的白谱稳态参考**，不是现场全带 RMS，也不覆盖整个物理频带
（29% 的 bin 过门，8.4k 带 7.5%）。它只回答"在这些 bin 上、稳态、白源假设下两臂差多少"。

留出 4096 全带 −0.42 dB（−3.93…+2.49，更差 0）；训练 8192 −0.48（−3.97…+2.77，更差 0）、
训练 4096 −0.47。**四个表都是 ON 略安静、且低频带最明显**，方向一致。

因此原稿"全带 +0.02 dB、基本无差别"的结论**作废**；正确说法是：
**ON 应比 OFF 略安静，300–1000 Hz 约 −1.2 dB，全带约 −0.4 dB；1000–3000 约 −0.2 dB。**

### 3.1 8.4 kHz 仍不可判

67 个 bin 只有 5 个过门控（8321/8327/8351/8357/8416），峰顶 8368 Hz（+6.64 dB，相干 0.770）被挡；
训练 10 段这一带能过 10 个、全带最差点正好落在 8368，留出 6 段退到 8357。
**同一峰顶随划分进出 0.8 门**，所以 `+0.31 dB`（甚至 4096 的 −3.16 dB）都不能当这一带的结论。

### 3.2 关于那 1 个"更差 bin"

原稿说"四个表更差 bin 全 0"是**错的**（只看了三个带，没看"全带"行）。
实际：三个带内确实全 0，但留出 8192 的**全带**有 1 个，在 **3516.7 Hz**（不在 C 的三带内）。
它只是"该 bin 上 `|L|>|H|`"，幅度小、且随窗长消失（4096 为 0），**不作为恶化结论**，但必须列出来。

## 4 三个方向（修订版）

1. **300–1000**：可判。预测 ON 更安静 −1.15 dB（4096 −1.08，训练 −0.99/−1.02，四表同向）。
   小增益界改善 +10.2 dB、余量 +6.60 → +16.78。
2. **1000–3000**：可判但小。−0.22 dB（四表 −0.21…−0.24）；小增益界改善 +12.2 dB。
3. **8200–8600**：**未知**（覆盖 7.5%，峰顶未进门控）。

**可能恶化**：三个带内 `|L|>|H|` 的 bin 数都是 0；全带有 1 个（3517 Hz，见 §3.2）。
这句只对**这一份 H** 成立——10-21→10-24 同一夹具 8.38 kHz 变 −5.98 dB/+39.5°，
换场次后某些 bin 可能翻正；未覆盖的 71% 没有依据，一律记未知。

## 5 否定条件（修订）

**先说清楚三条不能当判据的事**（C 指出的）：

- **配对漂移门禁 1.5 dB 是"两臂能不能配对"的配置一致性门槛，不是测量分辨率**。
  原稿"1.5 dB 以内分辨不了"已删除。能不能分辨，要看这批配对自身的 repeat 间散布，不能预设。
- **保护触发 ≠ 啸叫**。保护还受定音门禁、削顶、单次尖峰、音响待机、增益档位影响。
- **`|g·L| > 1` 不充分证明失稳**：小增益判据只看幅度，还要相位条件；真实系统有饱和、保护、
  电平依赖的 H。
  所以既不能宣称"必啸叫"，**也不能给出固定的增长时间**。
  **原稿的"385 dB/s、0.1 s 到 +30 dB"已删除**：即使线性、参数固定，单频幅值超过 1 也不足以
  推出失稳，更不构成"多久会炸"的判据。

**A. 调查触发条件（不是严格否证规则）**

预测本身没有独立的误差量级（同一份数据换窗长就差 0.1–0.4 dB，换场次更大），
所以下面几条只用来**触发调查**，不写成"出现即证明预测错"：

1. 300–1000 Hz 的 `on_minus_off_band_response_db` **两次都 ≥ 0 dB** 且配对合格 → 与预测 −1.15 dB 反向，值得查。
2. 合格 bin 参考 ON−OFF **> +1 dB**（ON 明显更响）→ 与预测 −0.42 dB 反向，值得查。
3. 门禁通过、源在窗内、无削顶，−14 dB 出现 `observed_growth` 或保护，且独立核实非门禁/削顶/待机引起
   → 与余量 6.6 / 16.8 dB 不相容，值得查。
   但**保护本身不能否定未覆盖频段的预测**——保护可能由别的机制触发，也可能发生在没进门控的 bin 上。

**B. 只是证据不足（不能支持也不能否定）**

1. 配对不合格：`pair_path_drift > 1.5`、`stop_reasons` 非空、`source_response.valid != true`、
   `recovery_ok != true`、两臂帧区间不一致。
2. 只剩一个有效 repeat（`repeats=2` 有一个废掉就无法确认方向）。
3. 8.4k 带无结论（覆盖 7.5%）。
4. ON−OFF 差值落在本批配对自身的 repeat 散布之内——**散布只描述这一批的重复性**，
   不能当成替代 1.5 dB 的新分辨率门槛，也不外推到别的批次。
5. 保护未触发、−14 dB 跑完、60 s 工程通过：这些在 OFF 臂同样成立，本身不含信息。

**C. 配置错误，单独归类**：系数/位流/增益/EQ/源 sha 不符 → `configuration_matches` 直接判掉，不进结论。

## 6 窗长与时间尺度（修订）

- `14408 帧` 是**尾部有效子窗**，整段运行仍是 2.52 s（C 已说明）。原稿的"单位待确认"删掉。
- 8192 与 4096 两套数字分开报；窗长造成的差（本例 0.1–0.4 dB，跨场次时更大）属本套离线筛选的敏感性，
  不是通用误差条，也不能用来否定更小的独立成对实测。
- 频域裕度回答"稳态有没有自激模态"；2.52 s 窗测的是被源驱动的受迫响应。
  两者不是同一件事，本文不拿其中一个去补另一个。
