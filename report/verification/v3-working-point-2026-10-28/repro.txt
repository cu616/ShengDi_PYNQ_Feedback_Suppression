==============================================================================
v3 演示工作点：从 A 的 322 Hz 三点反推（不引入新数据）
==============================================================================

[1] 三个量各自是什么（先把口径分开，别混着报）
    CD(322)        残差深度（A 报的 6.37 dB）
                     = cancel 支路真正被最小化的量，衡量**模型拟合程度**
    环路提升        bypass − open = 49.19 − 45.44 = **+3.75 dB**
                     = 闭环把这一带抬高了多少，**抵消最多能收回这么多**
    声学差          bypass − cancel = 49.19 − 44.43 = +4.76 dB
                     = 环路提升 +3.75 + cancel 过冲 +1.01 = +4.76（自洽）
    → **可听收益的量级是第 2 项（+3.75 dB），不是 CD，也不是声学差。**
      声学差多出来的 1.01 dB 是 cancel 比 open 还低，属过抵消/估计误差，不能计入收益。

[2] 由实测提升反推 322 Hz 处 H 的相位（这决定后面所有外推）
    |H| = 10^(4.40/20) = 1.6596（线性）
    g   = 10^(-8.0/20) = 0.3981，故 g|H| = 0.6607（环路幅度 -3.60 dB）
    |1 − gH| = 10^(−3.75/20) = 0.6494
    → cosφ = 0.7680，**φ = ±39.8°**
    → 322 Hz 处 H **不在正实轴**（差 40°），所以 g+|H| 的 dB 相加只对**幅度界**成立，
      不能用来推「提 1 dB 增益换多少响度」。

[3] 临界 g（同一个 |H|，两种口径）
    零系数：g|H| = 1 → g = 1/1.6596 = 0.6026 = **-4.40 dB**（幅度界 -4.40，一致）
    候选  ：g·max|H−Ĥ| = 1 → max|H−Ĥ| = 1/10^(0.68/20) = 0.9247，
            故 g ≤ 1.0814 = **+0.68 dB**
    → 稳定裕度差 = +0.68 − (-4.40) = **5.08 dB**（这是界差，不是实测 ASG）

[4] 零臂的 played/source（= 音响比输入响多少），以及提 g 能换到什么

    ⚠ 三点必须看清：
      · played/source 在 **g = -6.7 dB 见顶 3.87 dB**，之后提 g 反而更小——
        因为 φ≈40°，|1−gH| 的增长快于 g。**−8 dB 时的 3.75 dB 已经贴近这个顶。**
      · g ≥ -4.40 dB 之后零臂已自激，线性模型不再适用（那几行只是外推，不可达）。
      · 候选那 5.08 dB 增益余量**换算成多少输出，离线算不出**——见 [5]。

[5] 候选能多开 5 dB 增益，但换成多少输出：离线未知（这条要如实写）
    零臂：played/source = 1/|1 − gH|，H 已知（幅度 + 相位由 [2] 反解）→ 可算。
    候选：played/source = 1/|1 − g(H−Ĥ)|，需要 **H−Ĥ 的幅度与相位**。
          幅度有（max 0.9247），**相位没有**：离线只有 |H−Ĥ| 的逐点模，没有它的辐角。
          若同相，g 逼近临界时它会发散；若反相，它会小于 1。区间太宽，等于没有。
    → **所以「候选能不能开得更大声」在离线只能记未知，必须现场同 g 对照测。**
      能写进报告的只有：候选的稳定裕度比零臂高 5.08 dB（界差，非实测 ASG）。

[6] bypass vs cancel 对照：建议的量与阈值（同 g、同源、同距离）
    主判据（现场可做、可复算）：
      322 Hz 三点复测，同一 g 下报三个数：
        · 环路提升 = bypass − open      （本次 +3.75 dB）
        · 声学差   = bypass − cancel    （本次 +4.76 dB）
        · 过冲     = open − cancel      （本次 +1.01 dB，应≈0）
      判读：声学差 ≥ 环路提升 − 1.5 dB 且过冲在 ±1.5 dB 内 → 抵消在该点成立。
    语音臂（唯一能说「可听」的量）：同一句话、同一距离、同一 g，两臂各 3 遍；
      读数 = 300–460 Hz 能量占比 + 宽带 RMS；听感由听众两次、顺序随机判断。
    必须同时满足才判这一臂有效：bit22=0、四类饱和计数 0、峰值 ≤ −6 dBFS、completed。
