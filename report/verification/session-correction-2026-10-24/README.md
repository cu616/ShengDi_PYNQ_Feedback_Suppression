# 现场 H 变了多少：用 A 的复测数据预测并交付一版会话修正系数

> 输入：A 2026-10-24 的现场 H 复测（白噪声数字注入、n=8192、相干>0.7、无外部声源）、
> 门禁版三臂结果、`cancel_zero` 空测更正。脚本 `scripts/make_session_correction.py`，
> 输出 `models/room_v1/session_20261024/`。

## 0 结论

1. **A 的更正成立**：`cancel_zero` 那次是空测（ref=mic=−37.7 dBFS、前一次啸叫把功放推进限幅），
   "模型把可用增益从 0 拉到 −6 dB"这句话撤回。我上一轮据此提的"参考臂无效"是对的，但**物理结论要以门禁版为准**。
2. **"会话传递"成立，而且现在可量化**：8.38 kHz 处幅度 −5.98 dB、相位 +39.5°，远超我设的反证门限
   （<1 dB、<10°），所以不是系数写错，是那次标定的 H 已经不适用于这次现场。
3. **用部署模型对现场真值算阈值 = −7.42 dB**，A 实测"−9 dB 稳、−6 dB 叫"——**预测先于数据落在括号内**。
4. **会话修正系数预测 +6.74 dB**，A 用门禁协议重标定后拿到 **≥6 dB**，两边独立收敛到同一量级。
   限制点从 8.4 kHz 换到了 **381 Hz**（标定批本来就弱的地方）。

## 1 方法

现场真值取 `H_session(f) = H_calib(f) · C(f)`，`C` 由 A 的频带偏差分段线性插值（300 Hz 以下、
12 kHz 以上按 0 dB/0° 收口）。把部署模型乘上 `C`，用 512 个实系数在 250–13000 Hz 上做加权最小二乘
（权重外带 0.15，避免为了带内牺牲带外），再量化到 Q20。

**不能拿模型自己当代用真值**——第一版就是这么写的，结果自洽到 −30.9 dB，把标定残差整体抹掉了。
必须用标定批的 `H_calib` 乘 `C` 当真值，才有意义。

## 2 数字

| 模型 | max\|E\| | 位置 | 阈值 |
|---|---|---|---|
| 部署 `candidate_512`（标定批拟合） | +7.42 dB | 8368 Hz | **−7.42 dB** |
| 会话修正 `candidate_512_session_20261024` | −6.74 dB | 381 Hz | **+6.74 dB** |

8.2–8.6 kHz 带内修正残差的不确定预算：

| 带内 δ | 阈值 |
|---|---|
| 0 dB / 0° | +6.74 dB |
| 0.5 dB / 5° | +6.74 dB（仍被 381 Hz 限住） |
| 1 dB / 10° | +6.47 dB |
| 2 dB / 20° | +0.84 dB |
| 3 dB / 30° | −2.84 dB |

即：**只要带内修正准到 1 dB/10° 以内，0 dB 就有 6 dB 以上余量**；差到 2 dB/20°，余量归零。

## 3 与 A 实测的对照

| 项 | 预测 | A 实测 |
|---|---|---|
| 部署模型阈值 | −7.42 dB | −9 dB 稳、−6 dB 啸叫 → 阈值在 (−9, −6) |
| 重标定后可用增益 | +6.74 dB | ≥6 dB（门禁版，0 dB 时 mic −35.4） |

预测没有被数据推翻，也没有被数据证明到"精确"——两次都落在 1 dB 量级的同一档。

## 4 边界与反证

- 这份修正**只对这一次会话**（同一夹具、同一 hp_volume、同一注入电平）。A 报的 `ref→mic` 延迟是
  125/124/124，若复测时对齐方式又变，1 拍错位在 8.4 kHz 就是 62°，足以把结果推翻。
- 若 0 dB 仍啸叫：主频在 8.2–8.6 kHz → 带内修正不准；在 300–1000 Hz → 低频短板（381 Hz 相干仅 0.81）。
  两条都指向"用现场 npz 重拟合"，而不是继续手调这个掩模。
- 要提高余量，下一个杠杆是 300–1000 Hz 的标定质量（提高注入电平、提高相干），不是加抽头。

  可以把"掩模近似"换成"真拟合"，预期能把限制点也从 381 Hz 推走。
- 未上板、未做任何声学动作；上面的阈值都是模型推算，不是 ASG。
