# 首次残差越界：定位、可证的 8 dB 提前，与首选修复（2026-10-27）

> 依据：A = `d17ff29`（现场轮记录）、`03d4126`（两臂对照）、`a7d945d`（稳态两臂）；B 起点 `da67305`。
> 源码：`src/rtl/feedback_fir.v`、`src/rtl/audio_pl_replay.v`、`board/audio_replay/replay_trial.py`。
> 复算：`scripts/analyze_residual_overflow.py`（单文件、只依赖 numpy，可直接拷到板上跑）。
> **本轮不改 RTL、不改系数、不重训、不操板。** 修复方案涉及契约语义，按规则交队长确认后再由 A 实施。

## 0 一句话

**这次保护不是一个算术意外，是"残差处钳位比输出约束早 8 dB"这个设计缺陷在语音上必然触发的结果。**
在 −8 dB 下，残差相对麦克风可以放大到 **1.84 倍**（发生在 **390–401 Hz**，不是 328 Hz 那个稳定边界），
所以麦克风峰值只要到 **−5.3 dBFS** 残差就碰满幅；而现场门限是 −6 dBFS 峰值 —— **只剩 0.7 dB 余量**。
首选修复：宽残差（25 位）保留到乘增益之后再钳。**这条能证明在 −8 dB 下输出永远不会越界**（见 §4）。

必须先说清的边界：**我没有拿到这次失败试次的原件**（A 分支里 10-27 只有 JSON 摘要，没有 npz）。
下面第 3 节给出的是一条**可被那份原件直接否证**的机制，不是已经证实的唯一原因。原因可能并存。

## 2 钳位点在增益之前：这是可证的 8 dB 提前

RTL 的实际链路（逐行读出来的）：

```
residual   = clip(mic − pred, ±2^23)      ← feedback_fir.v:35-38，钳在满幅 1.0
gain_prod  = residual × gain_q12          ← audio_pl_replay.v:173
gain_held  = (gain_prod + 2048) >> 12     ← 这里才乘增益
mix        = injection + gain_held        ← audio_pl_replay.v:54
tx_word    = clip(mix, ±2^23)             ← 输出真正的约束
```

−8 dB 时 `gain_q12 = round(4096×10^(−8/20)) = 1631`（实际 −7.998 dB）。
所以**输出侧能容纳的残差是 `2^23 / 1631 = 2.51 倍满幅`，而残差在 1.0 处就被钳掉了**。

两者比：`20·log10(2.51) = **8.0 dB**`。**这就是"中间量过早缩窄"的准确含义**：钳位比物理约束早 8 dB。

这也解释了为什么 `prediction_saturations` 是 0、`residual_saturations` 却是 8：
预测在 1.0 以内没事，但 `mic − pred` 是**两个各接近满幅的量之差**，25 位量能到 ±2，很容易先撞到 1.0。

## 3 为什么偏偏在语音上触发：PS 拓扑的残差会放大到 1.84 倍

这一拓扑（预测相减，prediction-subtraction）在单频下的精确关系是：

$$\frac{R}{M}=\frac{1}{1+g\,e^{-j2\omega}\,\hat H(\omega)}$$

其中 $M$ 是麦克风、$R$ 是残差、$e^{-j2\omega}$ 是 2 帧调度延迟、$\hat H$ 是部署的 Q20 模型。
**分母只取决于模型和增益，与真实路径 $H$ 无关**，所以这条式子可以直接用来算"残差会不会越界"。

用候选系数算出来（300–10250 Hz 扫描，8192 网格）：

| 增益 | `min|1+g·e^{-j2ω}·Ĥ|` | 出现频率 | 残差/麦克风 | 麦克风峰值到多少残差即满幅 |
|---|---|---|---|---|
| −6 dB | 0.426 | 396.4 Hz | **2.35×** | 0.426（−7.4 dBFS） |
| **−8 dB** | **0.544** | **396.4 Hz** | **1.84×** | **0.544（−5.3 dBFS）** |
| −10 dB | 0.638 | 396.4 Hz | 1.57× | 0.638（−3.9 dBFS） |
| −12 dB | 0.712 | 396.4 Hz | 1.40× | 0.712（−2.9 dBFS） |
| −14 dB | 0.771 | 396.4 Hz | 1.30× | 0.771（−2.3 dBFS） |

最低点在 **390.4–400.8 Hz**，那里 `|Ĥ| = 1.13…1.17`、相位 **−158°…+179°**（正好跨过 180°）。
即：模型在这一小段是**反相**的，相减变成相加，残差比麦克风还大。

**现场余量只有 0.7 dB。** 现场门限是"麦克风峰值严格低于 −6 dBFS"= 0.501，
而 −8 dB 下残差满幅需要 0.544 → 门限内残差已经到 **0.92（92%）**。
所以任何一次说话、只要峰值贴着门限、又在 396 Hz 附近有一点能量（元音 F1 就在这一带），就会撞线。

**这与 A 观察到的"白噪通过、语音失败"一致，而且差别不在波峰因数**：白噪把能量摊在 300–10250 Hz，
396 Hz 附近的**窄带幅度**很低；语音把能量压在 300–420 Hz（元音 F1），同一宽带电平下那一带的
**窄带幅度**高得多。而残差越界只看 `|mic(f)|/|1+g·e^{-j3ω}Ĥ(f)|` 在那个频点的值，
所以"同样响"的白噪和语音在这里完全不是一回事。**不能用"白噪平稳所以没有瞬时峰值"解释这件事。**

**同时要指出一件容易被误读的事**：越界频率在 **396 Hz**，而稳定边界是 **328 Hz**（|H| 峰 +4.40 dB）。
两者不是同一件事。**残差越界不能当成"环路在 328 Hz 再生"的证据**，反过来也一样。

### 8 个饱和样本说明什么

8 个样本 = **164 µs**。在 396 Hz 一个周期是 2.54 ms（124 个样本）。
一个幅度刚刚超过满幅的正弦，每个周期大约有 `(2/π)·arccos(1/A)` 比例的点超线：
A = 1.0058（超 0.05 dB）时是 8.5 个/周期 —— **正好对上**。
所以"8 个"更像"刚刚越线"，不像一次猛烈过载。但保护每 2 ms 轮询一次，**不能据此排除"本来会继续涨"**。

## 4 首选修复：宽残差保留到增益之后

### 4.1 改什么

- `feedback_fir.v`：保留现有的 25 位 `difference`，**新增一个 25 位输出**（例如 `residual_wide_pcm[24:0]`），
  只做钳位到 25 位（实际上不会发生）。现有的 24 位 `residual_pcm` 原样保留——抓包格式、复算脚本、
  契约里"残差 24 位"的记录语义都不动，它继续当**诊断量**用。
- `audio_pl_replay.v`：`gain_product <= residual_wide × gain_q12`（25×12 → 41 位，现有位宽够）。
- 保护语义：守卫改挂在**真正的输出约束**上（`gain_saturations` / `mix_saturations`），
  不再挂在中间量上。`residual_saturations` 继续计数、继续上报，只是不再中止播放。

**这不是"吞掉饱和标志"**：标志还在、数还在报，改的是"哪个量代表物理越界"。
现在挂在中间量上，等于把 8 dB 的余量当成故障。

### 4.2 为什么它能覆盖这个失效模式（可证，不是估计）

由 §3 的式子，输出与麦克风之比有精确上界：

$$\left|\frac{U}{M}\right|=\frac{g}{\left|1+g\,e^{-j2\omega}\hat H\right|}\le\frac{g}{\min\left|1+g\,e^{-j2\omega}\hat H\right|}$$

| 增益 | 输出/麦克风 上界 | 麦克风到满幅时输出 | 结论 |
|---|---|---|---|
| **−8 dB** | **0.732** | 0.732 | **无论输入多大都不越界** |
| −6 dB | 1.176 | 1.176 | 麦克风超过 0.85（−1.4 dBFS）才越界 |

另一条更粗的界（不依赖模型）：宽残差下 `|residual| ≤ |mic| + |pred| ≤ 2`，
−8 dB 乘完增益最多 `2 × 0.398 = 0.796 < 1`。两条路径给出同一结论。

**所以在 −8 dB 这一档，"残差越界 → 保护停机"这条路径被彻底消除**，而输出侧的真实越界仍会被
`gain/mix` 计数抓住。−6 dB 档要留一条注意：麦克风到 −1.4 dBFS 以上仍可能越输出。

### 4.3 它会改变什么、不会改变什么

- **不变**：环路增益、模型、系数、延迟、调度、输出电平关系。宽残差只是不再丢掉已经算出来的信息。
- **零系数臂完全不受影响**：Ĥ ≡ 0 时残差 ≡ 麦克风 ≤ 满幅，本来就不会钳。所以基线数字与候选臂仍可公平比较。
- **会变**：越界时不再截断波形。原来会把峰值削平在 0.398（−8 dBFS），现在按原样输出到 0.73 以内。
  削平本身会往环路里注谐波，所以这一步同时去掉了失真的来源。
- **必须重新综合核对时序**：只加 1 位通路、不加状态，但 WNS 现在只有 +0.287 ns，不能口头保证，要跑一次。

### 4.4 失败条件（出现任一条就不要按这个方案走）

1. **guard 抓包里首次越界那一刻，`|g·residual_wide| ≥ 1`** → 宽残差仍越输出，本方案不覆盖这次事件，
   转 §5 的备选。
2. **越界前残差 RMS 单调爬升 ≥100 ms，且主频在 328 Hz** → 那是声学再生，钳位只是症状；
   此时放宽钳位等于让环路叫得更响，**不能单独采用**，要先定增益/限幅策略。
3. **麦克风被钉在 ±1.0（ADC 削顶）** → 先把输入电平按门限处理，宽残差只是让失真变成"干净地过载"。
4. **改动使 WNS 变负** → 换实现方式（例如把增益乘移进 FIR 的最后一级），不是硬上。

## 5 备选（只在 §4.4 第 1 条成立时才考虑）

按证据强度排序，不做批量扫参数：

1. **预测路径缩放**：把 Ĥ 乘一个固定 α < 1（等效减小 |Ĥ|），使 `min|1+g·e^{-j2ω}αĤ|` 抬高。
   α = 0.8 时 −8 dB 的最小分母从 0.544 抬到约 0.63（放大 1.58×），但**抵消深度同比下降**。
   依据要写清：这是拿抵消换裕量，不是免费的。
2. **只在 390–401 Hz 限幅预测**：窄带、可定点实现，但会在该带引入非线性，且需要额外的频带判据，
   复杂度高于宽残差，收益更小。
3. **降增益**：**不作为修复候选**。这会改变工作点、掩盖问题，而且队长已明确不允许用降音量制造成功。

## 7 本报告**不能**支撑的结论

- 不能说"根因已定"。原件没到手之前，§3 只是**可被否证的机制**，且可能与输入电平、ADC 削顶并存。
- 不能说"候选无效"或"候选有效"。这次事件发生在保护逻辑上，不是抵消效果上；
  白噪两臂的 6.8–7.9 dB 是 C 复核的指标，与残差越界不是同一件事，**不能互为数值互证**。
- 不能说"环路在 328 Hz 再生"。越界频率在 396 Hz，`prediction_saturations = 0` 本身也不排除再生，
  但没有证据支持，就不写。
- 不能把 §4 的方案当成"已经解决"。离线算术只能证明"给定输入下不会越界"，
  **改完之后的闭环稳定性必须重新上板看**。
