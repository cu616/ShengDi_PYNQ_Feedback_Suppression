## 2 钳位点：仍然可证地早 8 dB

```
residual  = clip(mic − pred, [−2^23, 2^23−1])              ← feedback_fir.v:35-38（25 位减法后立刻钳）
gain      = round_half_away_zero(residual × gain_q12, 12)  ← audio_pl_replay.v:167-173
out       = clip(source + gain, 24 位)                     ← audio_pl_replay.v:54-58
```

−8 dB → `gain_q12 = 1631`。输出侧能容纳的残差是 **4096/1631 = 2.512 倍满幅**，而残差在 **1.0** 处就被钳 →
**钳位比物理约束早 `20·log10(2.512) = 8.0 dB`**。这条与机理无关，只与拓扑和增益有关。

## 3 首次越界：波形、增益后范围

A 的记录给了越界附近的样本（`mic` 行比 `pred/residual` 行**早一个样本**，见 §6.1），对齐后：

| 项 | 值 |
|---|---|
| mic（归一化） | 0.978 → 0.999（**贴着 ADC 满幅**） |
| prediction | −257,741 … −205,315（**−0.031 … −0.024**，即 −30…−32 dBFS） |
| 宽残差 `mic − pred` | **1.0084 … 1.0231 × 满幅**（超出 +0.07…+0.20 dB） |
| 乘 −8 dB 后输出 | **0.401 … 0.407 × 满幅 = −7.9 … −7.8 dBFS** |
| 输出侧余量 | **+7.8 dB**，`gain_saturations = 0`（与事实 1 一致） |

**所以：这次越界在整个输出链里只值 −7.8 dBFS，离输出满幅还有 7.8 dB。** 它不是"信号太大"，
是"1.0 这个中间上限太早"。

再补一条：`prediction_saturations = 0` 在这里确实只是"pred 没越它的界"，**它不排除声学再生**——
pred 只反映模型对已播放信号的响应，不反映环路是否在自激。

## 4 "宽残差"能解决什么、不能解决什么

**能解决（可证）**
1. **1.0 处的过早钳位**：`4096/1631 = 2.512` 倍的余量，本次只用到 1.023，还剩 7.8 dB 没用。
2. **由此产生的误停**：本轮这次 guard 停机，按新通路不会触发。
3. **钳位造成的削波失真**：原来把峰值削平在 0.398，现在按原样输出到 0.407 以内。

**不能解决（必须写清）**
1. **输入跑到 ADC 满幅**：两臂都到 0.0 dBFS。这是输入/证据有效性问题，与钳位无关。
2. **是否再生**：满幅本身既不证明也不排除再生（队长与 C 都已指出）。
3. **模型在 396 Hz 的窄带放大**：它只在"麦克风 0.54 且内容集中在该带"时才咬人，本次没走到那一步。
4. **候选优劣**：这一轮两臂对照无效，**不能**用本方案把结论改成"候选通过"。

一句话：**它是"别在中间把可用的信息砍掉"，不是"让这次失败变成成功"。**

## 7 工具修正（对应 C 的五类边界）

| C 的检查项 | 上一版的行为 | 修正后 |
|---|---|---|
| 合法负满幅 | `|x| >= 2^23` 判越界，把 −2^23 也算进去 | 判据 `x > 2^23−1 或 x < −2^23`；−2^23 合法（用例 `test_negative_full_scale_is_legal`） |
| 负数舍入 | `(x·g + 2048) >> 12`，Python 对负数向下取整 | 按 RTL：`(|p|+2048)>>12` 再还原符号；`−2048 → −1`、`+2048 → +1`，并证明与向下取整不同 |
| 未知历史前缀 | 只把前缀排除在"失配"统计外 | 前缀 `taps+1` 帧同样排除在**首次越界、余量、计数**之外；历史区越界单独报 |
| Q20 身份 | 覆盖模型后仍照常给结论 | 系数不同即 `attribution=停止` 且退出码 2；整数重放失配同样停止 |
| 实际时间范围 | 只报帧数 | 窗口按真实采样率报 ms；覆盖 <100 ms 明确写"增长趋势记未知" |

另外补三条硬失败：**文件不存在 / 缺必需字段 / 无有效帧** → 打印 `FAILED:` 并退出码 2。

**主辅两条路径**：主路径完全用抓包里的 `mic` 与板上 `prediction` 重建 25 位差（不依赖模型，
直接对上 `residual_saturations`）；辅路径用 `coefficients_q20` 整数重放 `prediction` 交叉核对。
"身份"和"失配"都是辅路径的门，只有辅路径过了才允许把结论归因到当前系数。

### 9.2 13 dB 的定位：落在最后一块，而不是整轮

A 给的捕获窗内每 2048 帧（41.94 ms）的 mic 包络：

| 块 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| RMS dBFS | −38.6 | −37.6 | −40.2 | −39.2 | −26.7 | −29.7 | −33.2 | **−12.6** |

- 前 4 块（168 ms）在 −38…−40 dBFS，接近静音；
- 第 5 块跳到 −26.7（+12.5 dB），第 6、7 块又落回 −29.7 / −33.2；
- 第 8 块（末 41.94 ms，越界就在这一块里）翘到 **−12.6 dBFS**，比第 7 块高 **+20.6 dB**；
- 整窗 mic 贴 ±满幅 **26 个样本，最长连续 24 帧（0.49 ms）**；而残差贴轨只有 8 个——
  因为只有 pred 为负的那 8 个样本才会让 `mic − pred` 超过 +满幅。

**所以那 13 dB 不是"整轮输入比预检高 13 dB"，而是"最后 42 ms 比前面高 20 dB"。**

### 9.3 这一段更像讲话的起停，不像环路在爬（倾向，未定案）

环路在这个裕量下的时间常数是可算的：328 Hz 处 `g·|H| = 0.398 × 1.66 = 0.66`，即每圈 −3.6 dB，
一圈 3.05 ms → **≈ −1.18 dB/ms**。若环路真的在起振，它应当**单调**地以几十 dB / 42 ms 的速率变，
且不会中途回落。

实测的序列是 **+12.5 → −3.0 → +20.6** dB：**先起、再落、再起**。一个在爬的环路做不到"落"。
所以**倾向**：末尾那块是讲话的起停（更响/更近），不是再生。

**但这只是倾向，不是结论**：逐块 RMS 分不开"讲话变响"和"环路被讲话激励"。定案要看那一块的谱——
环路会在 328 Hz 附近出窄线（窄带占比高），讲话是共振峰结构（主频随元音走）。

### 9.4 一行命令就能判（同一次板上静默跑，不需要新采集）

```bash
python3 analyze_residual_overflow.py \
  --npz <blind2_cand_1746867731709459239.npz 绝对路径> \
  --envelope --block 2048
```

新增的 `--envelope` 会为每块打印 **RMS / 峰值 / 贴轨样本数 / 主频 / 窄带占比**：

- **末块主频落在 320–340 Hz 且窄带占比明显高于前几块** → 偏环路；
- **末块主频随元音在 300–800 Hz 之间、窄带占比与前几块同量级** → 偏讲话。

这一条不能单独当再生判据（占比不是再生的充分证据），只用于给 9.3 的倾向定案或推翻。

### 9.5 关于改驱动

A 问要不要改 `replay_trial`（带时间线的 live_run，或把捕获环加长到覆盖全程）。**B 的意见是先不改**：

1. 这条异常只影响"那次为什么那么响"，**不影响候选判定**——这一轮两臂本来就无效；
2. 改捕获环会同时动驱动、抓包格式与既有复算脚本，冻结前风险大于收益；
3. §9.4 的一行 FFT 很可能就够了。

若队长要保留可追溯性、又不想动驱动，更省的做法是：**下次有声运行前，先用同一句话、同一位置、输出静音
记一次电平**（`input_check` 已有），把"预检"和"实跑"钉在同一句话上。**要不要改驱动由队长定**，B 不自行决定。
