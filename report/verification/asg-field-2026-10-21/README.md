> 数据来源：A 的实测（`report/verification/audio-replay/2026-10-21-asg-field.md`）
> + B 手上的三个标定文件（`training_box_v1.npz`、`validation_box_v1.npz`、
> `candidate_box_v1_256.json`）。
> **本文全部数值为模型推算，不是实测 ASG。** 实测阈值来自 A，写在这里只作输入。

```text
python scripts/diagnose_mismatch.py --data-dir <三个文件所在目录> --msg-bypass-db -18
```

## 1. 结论

**B 在 2026-10-21 给出的预测（旁路 −26 dB、抵消 −12.5 dB、ASG +13.5 dB）在板上不成立，
被 A 的实测否定。** 否定不是"差几个 dB"，是**符号错了**：实测抵消比旁路更早起振。

原因不是抽头数、不是估计器、不是低频分辨率，而是 **Ĥ 的幅度比真实 H 大了约 2.5 倍**：

| 量 | 值 | 来源 |
|---|---|---|
| 标定峰值 \|H\| | +26.06 dB @381 Hz | 标定数据 H1 估计（相干 0.970） |
| 实测旁路起振 | ≈ −18 dB | A 实测（噪声 −18 起振 / 人声 −18 跑满 10 s 稳定） |
| ⇒ 实测峰值 \|H\| | ≈ +18.0 dB | 由上一行按稳定判据反推 |
| ⇒ 耦合比 β | **0.395（−8.06 dB）** | 上面两行之差 |
| ⇒ 实测 \|H−Ĥ\| | ≈ +21.6 dB | β·H̄ 代入，Ĥ 不变 |
| ⇒ CD 最差 | **−3.64 dB** | 20·log10(18.0/21.6) |

也就是说：**标定这套系数是按"比真实强 2.5 倍的路径"拟合的**，减过头，残差比原来的环路还强。
A 用两条不等式反推出 `CD_worst ≤ −1.5 dB`；本文由旁路阈值定 β 后独立算出 −3.64 dB，
同向、同量级。

## 2. β 是一个自由参数，而它预测了第二个观测量

β 由 A 的**旁路**起振阈值定出（−18 dB），此后它没有任何可调余地。
用这个 β 去算**抵消**的起振阈值，是一次真正的预测，不是把同一组数搬两次：

| | 计算 | A 实测 | 判定 |
|---|---|---|---|
| 旁路起振 | −18.00 dB（定 β 用） | ≈ −18 dB | 输入 |
| **抵消起振** | **−21.63 dB** | **≤ −19.5 dB（人声 10 s）** | 预测成立：21.63 ≥ 19.5 |
| CD 最差 | −3.64 dB | ≤ −1.5 dB | 同向，差 2 dB |

A 的 −1.5 dB 是用**两条不等式**推的（抵消 −19.5 起振 + 旁路 −18 稳定）。
本文只用一个点（旁路 −18）定 β，再独立算出 −3.64 dB；两者相差 2 dB，
落在 β 的点估计误差（±1 dB 导致 CD 变化约 ±1 dB）和 10 s 窗口的下界性之内。

**所以"幅度失配"这一条解释了两个互相独立的观测量**：旁路阈值、抵消阈值。
换成"抽头不够""估计器不好""低频分辨率差"任何一个解释，都只能解释其中一个。

**起振频点是另一条独立佐证。** 相位允许起振的频点（∠H_eff·e^{−jω·2} 穿过 2π 整数倍处）：

| | 本报表候选 | A 实测 | 偏差 |
|---|---|---|---|
| 旁路 | **417 Hz**（次为 978 / 1693 Hz） | **423 Hz** | 6 Hz，小于一个 FFT bin（11.9 Hz） |
| 抵消 | **262 Hz**（次为 691 / 1347 Hz） | **274 Hz（人声）**、232 Hz（噪声） | 12 Hz，约一个 bin |

延迟、相位、`played[n+2]` 调度这一层都是对的；**唯一错的是幅度**。
它也解释了为什么 381 Hz 两次都没起振：那是 β=1 的峰值，β≈0.4 时已不是。

## 3. A 第 5 问：两个数

### 3.1 200–300 Hz 子带的 `max|H−Ĥ| / max|H|`

| 条件 | 抽头 | max\|H−Ĥ\|/max\|H\| | 子带内 CD 最差 |
|---|---:|---:|---:|
| 标定自身（β=1.00） | 256 | 0.278（−11.11 dB） | −5.04 dB |
| 标定自身（β=1.00） | 512 | 0.229（−12.81 dB） | −1.98 dB |
| 失配 −6.6 dB（β=0.47） | 256 | 1.054（+0.45 dB） | −13.44 dB |
| **失配 −8.1 dB（β=0.395）** | **256** | **1.419（+3.04 dB）** | **−15.19 dB** |
| 失配 −8.1 dB | 512 | 1.518（+3.63 dB） | −11.24 dB |

**答案：在推定实测条件下是 1.42（+3.05 dB），在这个子带内确实大于 1 —— 即抵消在放大环路。**
但要注意一个更严重的事实（下一节）：**不是只有 200–300 Hz 放大，是全带放大。**

### 3.2 全带 `CD(f)` ≤ 0 的频段与宽度

β=0.395、256 抽头、相干门控 155–10967 Hz：

```text
CD <= 0 占评价频带 100.0%，连续段：155 - 10967 Hz（宽 10812 Hz）
```

**没有任何一个频段是"抵消有益"的。** 逐子带最差值：

| 子带 | 256 抽头 CD 最差 | 512 抽头 CD 最差 |
|---|---:|---:|
| 150–200 Hz | −13.92 dB | — |
| 200–300 Hz | −15.19 dB | −11.24 dB |
| 300–400 Hz | −3.68 dB | — |
| 400–500 Hz | −6.65 dB | — |
| 500–700 Hz | −6.22 dB | — |
| 700–1000 Hz | −5.63 dB | — |
| 1000–3000 Hz | −15.96 dB | — |

所以 A 的假设"低频先崩"**部分成立但要修正**：低频确实在崩（150–300 Hz 的 CD 最差
是 −13…−15 dB，最严重），但中频同样在崩（1000–3000 Hz 也有 −15.96 dB）。
这不是"低频特有"的问题，是**幅度失配作用在全带**，低频只是最先被激励出来
（人声基频在那儿，能量最集中）。

## 4. A 第 6 问：明确取舍

### 4.1 三个候选全部被定量否定

同一个 β=0.395 条件下比 ASG（越大越好）：

| 方案 | 全带 ASG | 抵消起振 | 判定 |
|---|---:|---:|---|
| 现状：256 抽头 + 全带抵消 | **−3.64 dB** | −21.6 dB | 有害 |
| 加抽头到 512 | **−4.93 dB** | −22.9 dB | **更差 1.3 dB** |
| 分频段 / 加高通（只留 CD>0 的频段） | **+0.00 dB** | −18.0 dB | 退化成旁路 |
| 换估计器（用真值 H，理想上界） | 上界 | — | 见下 |

三条否定理由，各自独立：

1. **加抽头**：512 在 200–300 Hz 的 CD 最差确实从 −15.19 改善到 −11.24（+3.95 dB），
   但**绝对水平仍为负**，救不回来；而全带 ASG 反而更差，因为 512 在标定条件下学得更准，
   幅度失配时的偏差更大。**模型越精确，失配时越危险。**
2. **分频段 / 高通**：CD≤0 覆盖 100% 频带，没有可保留的"好频段"。
   只留 CD>0 等于全部关掉，ASG 回到 0——那不叫抑制，那叫旁路。
3. **换估计器**：拟合早已在最优附近。把**已知真值**截断到同抽头数，与拟合模型的最差频点
   CD 只差 0.15 dB（见 `report/verification/algorithm-2026-10-20/` 的真值核对）。
   问题不在"估得准不准"，在"输入的场景本身变了"。

### 4.2 取舍：按当前夹具重新标定，不动架构

| 方案 | 全带 ASG | 抵消起振 | 成本 |
|---|---:|---:|---|
| **按实测幅度重标定（256 抽头）** | **+13.53 dB** | **−4.47 dB** | 一次采集 + 一次拟合 |
| 系数整体乘 β=0.395（重标定的近似） | +13.53 dB | −4.47 dB | 改一个 json |

两条给出同样的 ASG，因为当 β 匹配时 `ASG = |H|/|H−Ĥ|` 与 β 无关——
**这正是"失配"这个诊断的可检验推论**：只要把幅度对齐，当初标定的 13.5 dB 就该回来。

推荐顺序：

1. **先做 5 分钟的验证**：把 `candidate_box_v1_256.json` 的系数整体乘 0.395，
   在 −12 dB 测旁路 / 抵消各 10 s。若抵消安静、旁路啸叫，β 假设成立。
   （这项只改系数文件，不动 RTL，不动 overlay。）
2. **再做 10 分钟的根本修复**：在当前夹具、当前摆位下重新采集 training + validation，
   重新拟合。它同时修正幅度和形状，不依赖"形状没变"这个假设。

**在 β 假设被验证之前，不要动 512 的 RTL，也不要改分频段。** 那两件事都得等
标定问题解决后才谈得上——匹配条件下 512 只多 1.15 dB（+13.53 → +14.68），
而现在它带来的是 −1.29 dB。

## 5. A 第 7 点：`audio_closed` 不出声的后果

A 实测 `audio_closed` 的 DAC 无贡献、同批配对只差 +0.06 dB。因此：

- 2026-10-19 / 10-20 那批"闭环 bit_exact、零模型与真实模型两模式通过"
  **只证明 PL 算术正确，不证明回路成立**。它从来不是效果证据，现在连"闭环能跑"
  都不能算。B 此前在 `STATE` 的"已验证"里引用过这条，已按此更正。
- 本轮所有实测都在 `audio_replay`（bit `dadbbbab…ddcb05`）上完成，
  A 已把闭环测试迁到那里。B 后续的预测与验收一律以 `audio_replay` 为准。

## 6. 需要 A 核对的三个现场条件

β=−8 dB 的含义是"实测耦合比标定弱 2.5 倍"。标定与实测的 `fixture_id`、`hp_volume`
都是 `box_v1_20261016` / 40，**所以差异只能来自这三处之一，而标定没有记录它们**：

1. **麦克风**：标定与实测是同一只吗？是同一条输入通路（`LINE_IN` / `MIC` 软件选择）吗？
2. **摆位**：标定时的麦克风/音响坐标是多少？实测是 `[2,2,1]` / `[12,6,3]`。
   标定 npz 的 metadata 里**没有位置字段**，这是标定的元数据缺陷。
3. **音响音量**：`hp_volume=40` 是 Codec 的，功放/有源音响自身的旋钮位置有没有动过？

只要有一项不同，β 就有物理解释，重标定是正确修复。三项都相同而无解释，
则要考虑标定用的 overlay（bit `6e22cb…`）与 `audio_replay`（`dadbbbab…`）
在输入增益或 Codec 配置上有差异——这条需要 A 查两份 overlay 的初始化脚本。

## 7. 局限

- β 由"实测旁路起振 −18 dB"单点反推，是个**点估计**。A 的数据里噪声源在 −18 起振、
  人声源在 −18 稳定在同一档，两者一致，所以精度约 ±1 dB；但"10 s 不起振"只是下界，
  真实 β 可能略大于 0.395。
- 重标定收益 +13.53 dB 的前提是**路径形状不变、只有幅度变**。若摆位变化同时改变了
  共振结构，重标定仍是正确做法，但收益未知。
- 2 s 窗口低估风险这一点已被 A 证伪（10 s 窗口下抵消更早起振）。B 此前所有基于
  模型的"起振增益"都是稳态判据，不受窗口影响；但 A 的实测阈值必须一律用 10 s 口径。
- 未解释：为什么同一增益下噪声源旁路起振、人声源旁路稳定。线性时不变系统不该如此。
  B 的猜测是峰值因数不同（人声峰均比高，先触到饱和保护而非真正起振），但这需要
  A 的逐项饱和计数才能判定，**本文不下结论**。
- **本轮没有用整数闭环模拟做交叉验证，只用频域口径。** 试图用 `closed_loop_sim`
  复现实测阈值时发现它的发散判据在"长 room + 高增益"下非单调：同一份数据里
  g=−20 dB 判为发散、g=−10 dB 判为稳定。已修掉一处真实缺陷（麦克风满幅此前未计入
  发散判据，ADC 削顶后环路"不再增长"会被误判成稳定，与 A 的判据口径也不一致），
  但非单调性未消除，排查需单独开一轮。**在它修好之前，凡引用 `find_msg` 的阈值都要
  先与 `1/max|H_eff|` 对照**；此前在合成数据上的三行对照（2.11/6.48/15.23 dB）
  用的是短 room 与低阈值，不受这条影响。
