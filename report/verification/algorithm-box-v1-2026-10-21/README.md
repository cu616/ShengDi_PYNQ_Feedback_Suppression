# 真实箱体 v1：逐频点路径与稳定增益（2026-10-21）

数据：`training_box_v1.npz`、`validation_box_v1.npz`、`candidate_box_v1_256.json`，
由 A 从板卡拷出。夹具 `box_v1_20261016`，`hp_volume=40`，采样率 48828.125 Hz，
各 32768 帧。训练用于拟合，验证只用于评价。
命令：`python scripts/analyze_path.py --data-dir <目录> --output analysis.json`
（`analysis.json`、`run.txt` 为本目录同批产物）

**全部数字是"从模型算出来的预测"，不是实测 ASG。** 声学闭环还没跑过。

## 1. 结论

1. **这个箱子在 381 Hz 有一个 +26.1 dB 的共振**（相干 0.970，不是噪声）。
   它就是会啸叫的地方，也是整条链路的瓶颈。
2. **旁路状态下，数字增益超过约 −26 dB 就会啸叫。**
   之前的 −36 dB 测试比这条线低 10 dB，所以那一批**在物理上不可能起振**，
   "没听到尖叫"不含任何信息。
3. **开启 256 抽头抵消后，能推出约 13.5 dB 的额外余量**（相位口径 17.3 dB）。
   这是本项目第一次给出"算法到底换来多少"的真实数字——仍是预测。
4. **512 抽头只比 256 多 1.2 dB**（14.7 vs 13.5）。之前基于合成数据怀疑
   "512 可能值 +9 dB"的推测，在真实箱体上不成立。**保留 256 是正确决定。**
5. 抵消在 10.6–10.9 kHz 反而略微有害（CD −3.3 dB），但那里不是决定点。

## 2. 真实路径

| 项 | 值 | 依据 |
|---|---|---|
| 可用频段（相干 ≥ 0.8） | 155 – 10967 Hz | 门控后带内相干中位 0.915 |
| 路径峰值 | **+26.1 dB @ 381 Hz** | 相干 0.970 |
| 次峰 | 405 Hz +25.8；525 Hz +22.9；727 Hz +17.5；811 Hz +16.0 | 局部极大 |
| 麦克风 RMS / 峰值 | −21.54 / −6.21 dBFS | 与 −28.86 dBFS 的激励相比整体 +7.3 dB |
| 直流偏置 | −69.5 dBFS | 可忽略，RTL 不减 bias 不构成问题 |
| 20 Hz 以下 | **不给数值** | 相干仅 0.04，H 估不出来 |

模型与估计的一致性（381 Hz 处）：

| 抽头 | \|H\| 估计 | \|Ĥ\| 模型 | 差 |
|---:|---:|---:|---:|
| 128 | 26.1 dB | 20.0 dB | 6.1 dB |
| 256 | 26.1 dB | 25.2 dB | **0.9 dB** |
| 512 | 26.1 dB | 26.6 dB | −0.5 dB |

说明 256 抽头确实把这个共振学进去了，不是碰巧。

## 3. 稳定增益

`MSG = 1/max|H_eff|`；conservative 是安全下界，phase_gated 是相位过零点的实际起振点。

| 抽头 | 宽带降低 | CD 中位 | MSG 旁路 | MSG 抵消 | **ASG** |
|---:|---:|---:|---:|---:|---:|
| 128 | 4.20 dB | 1.77 dB | −26.06 | −21.25 | 4.82 / 6.12 dB |
| **256（现行）** | **9.69 dB** | **1.84 dB** | **−26.06** | **−12.53** | **13.53 / 17.33 dB** |
| 512 | 10.17 dB | 2.04 dB | −26.06 | −11.39 | 14.68 / 18.22 dB |

读法：`max|H| = 26.1 dB @381 Hz`，`max|H−Ĥ| = 12.5 dB @417 Hz`。
**峰和残余峰都落在同一个共振上**，所以 ASG 基本等于该频点的抵消量（13.6 dB）。

注意 `CD 中位` 只有 1.84 dB 而 ASG 有 13.5 dB，两者不矛盾：
决定稳定性的是峰值那一个频点，不是全带中位数。这正是"宽带平均"和"稳定增益"
不能互相替代的实证。

## 4. 现场该测什么

按 B 的判断，增益点（Q4.12 数字增益，dB 相对 1.0 倍）：

- **起点 −32 dB**：比旁路阈值低 6 dB，保证一开机不叫。
- **对照点 −24 dB**：旁路应明显啸叫（阈值 −25.4），抵消应安静（阈值 −8.0）。
  这是同一增益下唯一能一眼看出差别的点。
- **终点 −12.5 dB**：再往上抵消也可能起振。

预测：在 −24 dB 处，旁路叫、抵消不叫。**如果抵消也安静但旁路也不叫，说明现场
路径与这次标定时不同**（箱盖、麦克风位置、音量任一变化都会改变 `H`），那次数据作废。

## 5. 限制

- 模型预测，不是实测。夹具、`hp_volume=40`、箱盖状态都必须与 10-16 标定时一致。
- 标定只有 0.67 秒 × 2 轮；不覆盖长期漂移、温度、人走动。
- 10.7 kHz 附近抵消略为负值，说明模型在高频段没有真正建模（能量低、相干边缘）。
- 加权拟合候选在验证集上宽带崩到 −7.35 dB（过拟合），已否决，不作为候选。
- 真实 MSG/ASG、端到端延迟、音质仍全部未验证。
