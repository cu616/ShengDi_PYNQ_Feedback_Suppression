# B 第一轮：模型诊断、闭环参考模拟与实验范围（2026-10-20）

负责人 B（数据与算法）。本轮不接触板卡、不播放、不使用任何新建录音；
全部结论来自已有源码、已有报告中的实测数值，以及已知真值的合成路径。
**还没有一条结论是真实箱体上的实测 MSG/ASG。**

## 1. 本轮解决的问题

把"预测误差降低 9.8 dB"这个数，换成现场真正需要的两个数：
**在哪个频点上抵消还剩多少 dB，以及数字增益能推到几 dB 才开始啸叫。**

## 2. 结论

1. **宽带 RMS 不是评价指标，而且会给出错误的排期决策。** 合成里抽头从 256 加到 512，
   宽带只涨 2.6 dB，稳定增益差 ASG 涨 8.9 dB。用宽带数看，会得出"512 只多 0.37 dB，
   不值得做"的结论——这个结论在合成里是错的。真实箱体必须用本轮的逐频点口径重算。
2. **限制来自抽头覆盖长度，不来自估计器。** 把**已知真值**的冲激响应截断到 N 抽头，
   与拟合出来的 N 抽头模型，最差频点抵消深度差不到 0.15 dB
   （128/256/512 抽头：真值 −1.9/4.5/11.2 dB，拟合 −1.95/4.59/11.33 dB）。
   换更好的估计方法不会有用，只有加长或改结构才有用。
3. **架构上限约 680 抽头。** 每抽头 3 拍、帧预算 2048 拍 → 3N+3 ≤ 2048 → N ≤ 681。
   换成距离：256 抽头 = 5.24 ms = 1.79 m，512 = 3.60 m，681 = 4.79 m。
   "会议室"场景只要麦克风—音箱超过 2 m 加混响尾就装不下，这是硬约束。
4. **加权拟合（按 |H| 加重）方向对、收益小，本轮不推荐。**
   合成里 ASG 只 +0.18 dB，代价是 CD 中位数掉 1.07 dB。不值得为它改流程。
5. **硬件增益上限 +18.06 dB（8 倍 Q4.12）**，这决定了现场最多能推到哪，
   也决定了"抵消后可能根本推不响"是正常结果而不是失败。

## 3. 两套独立算法互相核对

可信度来自这里：一套在频域算 `max|H-Ĥ|`（`path_analysis.py`），
一套逐帧跑整数定点环路、按 RTL 的 `played[n+2]=gain(residual[n])` 调度
（`closed_loop_sim.py`）。两者实现完全独立。

| 模式 | 预测（保守下界） | 预测（相位口径） | 整数环路模拟实测 |
|---|---:|---:|---:|
| 旁路 | −2.02 dB | 2.12 dB | **2.11 dB** |
| 抵消 256 抽头 | 4.16 dB | 6.84 dB | **6.48 dB** |
| 抵消 512 抽头 | 13.11 dB | 16.87 dB | **15.23 dB** |

三行实测值都落在预测区间内、且贴近相位口径。说明：
`MSG = 1/max|H-Ĥ|` 这个口径对这个架构是成立的；保守口径是安全下界（平均低估 2–4 dB），
相位口径是现场会先叫的位置。证据：`cross-check.txt`。

## 4. 合成夹具上的抽头对照

夹具：直接到达 + 两次反射 + 一个 820 Hz、衰减 260 采样、长 1200 采样的共振尾
（刻意让 256 抽头装不下）。源 −26 dBFS，噪声 −58 dBFS。

| 抽头 | 核周期 | 帧预算 | 宽带降低 | CD 中位 | CD 最差 | ASG（保守/相位） |
|---:|---:|:--:|---:|---:|---:|---:|
| 128 | 387 | 通过 | 5.83 dB | 7.50 dB | −1.95 dB | 0.90 / 1.39 dB |
| 256 | 771 | 通过 | 12.36 dB | 24.67 dB | 4.59 dB | 6.18 / 4.71 dB |
| 512 | 1539 | 通过 | 14.98 dB | 25.77 dB | 11.33 dB | 15.12 / 14.75 dB |
| 768 | 2307 | **超出** | — | — | — | 不可用 |

读法：**CD 中位数很好看（24 dB），但最差频点只有 4.6 dB，而决定稳定性的就是最差那个点。**
这就是"9.8 dB 宽带"和"能不能多推 6 dB 音量"之间的全部差距。

## 5. 加权候选（本轮否定的结果）

按 `|H|^γ` 给拟合误差加权，让模型在容易啸叫的频段更准，γ=1.0：

| 指标 | 基线 LS | 加权 g=1.0 | 变化 |
|---|---:|---:|---:|
| 宽带降低 | 12.36 dB | 12.33 dB | −0.03 |
| CD 中位 | 24.67 dB | 23.60 dB | **−1.07** |
| CD 最差 | 4.59 dB | 4.76 dB | +0.17 |
| ASG 保守 | 6.18 dB | 6.36 dB | **+0.18** |

方向正确（最差频点和 ASG 都略微改善），但代价明显、收益在 0.2 dB 量级，
低于估计误差本身。**结论：保留 256 抽头基线估计器，不为此改动流程。**
如果真实数据上共振峰的 CD 显著低于中位数（预期会），再考虑提高 γ 或换 minimax。

## 6. 直流与低频

`fit_path` 在拟合时减掉了均值，但 **RTL 不减 bias**：残差会带着直流进环路，
再乘增益送出去。合成里 bias 只有 −93 dBFS，可忽略；真实数据的 bias 要在板上量。
另外 20 Hz 以下的环路增益单独报告——合成验证里出现过"低频漂移先于啸叫发生"，
它看起来不像啸叫（是逐渐变响的闷声），容易被误判成"没事"。

## 7. 现场增益范围（合成夹具的示例，不是真数据）

- 起点 = 旁路保守起振增益 − 6 dB = **−8.0 dB**
- 终点 = 抵消相位口径 − 2 dB，且不超过 +18.06 dB = **+4.2 dB**
- 步进 3 dB，点位 −8 / −5 / −2 / +1 / +4 dB
- **对照点 −0.0 dB**：这一点旁路应当明显啸叫、抵消应当安静

这个"对照点"是一次现场实验里唯一能一眼看出差别的增益。相比在 −36 dB 下反复听，
它把"有没有效果"压缩成一个二值判断。真实数字必须等第 8 节的板上分析。

## 12. 限制

- 合成夹具是"小箱体 + 长共振尾"的近似，不代表真实箱体的 `H(f)`。
  第 4 节所有数字只在合成意义上成立，**不能写进报告当作实测性能**。
- 频域估计在窄共振处的分辨率约 12 Hz（4096 点窗），更窄的峰需要更长窗。
- 抵消深度的可测上限受分段数限制：32768 帧 / 4096 点窗 = 15 段，约 49 dB。
  超过这个量级的差异不可信，但远高于我们关心的 0–20 dB。
- 增益建议绑定 `fixture_id` 与 `hp_volume`；换音量后 `H` 线性缩放，MSG 要按 dB 平移。
