## 6 事前预测与有限网格判读（现场前写定）

对照范围按 A 允许的五档：**−14 / −12 / −10 / −8 / −6 dB**。同一夹具（音响距麦 100 cm 侧对、棉已盖、
听众就位）、同一源、同一音量，**同一轮里跑零系数臂与候选臂**。每档记录：完成 / 起振 / 保护，
以及模态占比（辅助，不作单独判据）。

**方向**：候选臂的"最高稳定档"应不低于零系数臂。**量级只写作离线界差**：8192 网格 +5.08 dB、
4096 网格 +8.48 dB。这是**两个 FFT 网格、同一门控规则下的小增益界差异**，不是现场收益区间，也没有"保底"。
小增益界是充分条件，**界不足不能推出一定起振**——所以"零系数臂在 −6 dB 会起振"只是待检验预测，
不是已知事实（界绑定在 321.9 Hz、`|H| = +4.40 dB`，0 dB 增益时环路增益已 1.66 倍，这是我们预期它先失败的依据）。

**判读规则（有限网格 + 删失）**：

| 观测 | 结论 |
|---|---|
| 零臂在某档起振/保护，候选臂**同一档完成** | 有分辨，记"候选 ≥ 该档与零臂失效档之间距"——是**单边下界**，不是收益点估计 |
| 候选臂在某档失败，且**该档零臂已完成** | 有分辨的失败 → 否定候选 |
| 两臂在同一档都失败 | 未分辨（除非候选失败档更低） |
| **两臂到顶（−6 dB 都完成）** | **未分辨 / 区间未知**：只能报"候选在 −6 未见起振，收益未测出"。**不要求**进入 −4/−2，**也不据此否定** |
| 只出现单次保护或模态占比偏高，但同档仍完成 | 记辅助证据，**不单独构成否定** |

明确不做：不机械比较"最高完成档"当作分辨出来的差异；不把"两臂都稳"当成候选有效；不在未授权时要求 −4/−2。
若这一轮落在"未分辨"，正确的回报是"网格不足、区间未定"，而不是"都没叫、所以没用"，也不是"需要加档"。
