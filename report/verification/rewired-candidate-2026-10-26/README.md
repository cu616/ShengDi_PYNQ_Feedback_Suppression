## 2 划分与对齐（先冻结，再算）

- **固定划分（时间序）**：train = 第 1–4 段，dev = 第 5 段，**val = 第 6 段只在最后评一次**，不参与任何选择。
- 第二估计：even/odd 3/3 交叉验证。
- **段边界保留**：拟合按段各自构造历史，窗口不跨段；每段尾部静音（977 帧）不进统计。
- **两种口径分开报**：
  - **诊断口径**（用于频域）：六段对齐到共同整数延迟 184（第 4–6 段各滞后 1 帧）。只改统计时基，
    **物理延迟完整保留**（对齐后亚采样延迟仍 184.04 帧），模型峰位 184 = 实测 H 的冲激响应峰 184。
  - **部署口径**（用于时域收益）：**不对齐，直接逐段跑原始六份**——现场没有"对齐"这一步。
    结果见 §4.1，与诊断口径差 0.4–1.6 dB，**收益不是对齐造出来的**。

## 4 比较结果（量化后系数，零系数为基线）

### 4.1 时域：诊断口径与部署口径分开

| 评价集 | 总体抑制 | 300–460 Hz 抑制 |
|---|---|---|
| train（拟合内，4 段） | 3.05 dB | 5.08 dB |
| dev（拟合内，1 段） | 1.40 dB | 4.93 dB |
| **val（未参与，1 段）** | **1.43 dB** | **3.48 dB** |
| 3/3 CV（024→135） | 2.10 dB | 4.61 dB |
| 3/3 CV（135→024） | 2.10 dB | 4.87 dB |
| **不对齐、逐段原始六份（部署口径）** | 1.01…3.65（中位 **2.36**） | 3.49…6.00（中位 **4.93**） |

逐段（部署口径，300–460 Hz）：`00` 4.75 / `01` 6.00 / `02` 4.92 / `03` 5.04 / `04` 4.94 / `05` 3.49 dB。
后两段（mic 高 3.5 dB 的那两段）带内收益并未明显变差，说明那 3.5 dB 更像整体电平抬升而非路径突变。

### 4.2 频域：两个判据 + 分辨率敏感性

| 判据 | 零系数 | 候选 | 差 |
|---|---|---|---|
| 采样网格小增益界（8192，绑定） | −4.40 dB @321.9 | **+0.68 dB @333.8** | **+5.08 dB** |
| 正实轴穿越（8192） | −3.66 @316.7 | +5.83 @321.6 | +9.49 dB |
| 小增益界（4096） | −2.57 @441.1 | +5.91 @441.1 | +8.48 dB |
| 正实轴穿越（4096） | +6.35 @4509 | +21.19 @5166 | — |

**只有"界"能当定量结论**（同上一份报告的教训：穿越对窗口与网格都太敏感，这轮 8192 与 4096 相差 1.8–5.2 dB）。
界的候选−零系数差落在 **+5.1 … +8.5 dB**，保守取 **+5.1 dB**。

### 4.3 关键频点 CD（`CD = 20log10(|H|/|H−Ĥ|)`）

| 频点 | \|H\| | \|H−Ĥ\| | CD | 相干 |
|---|---|---|---|---|
| 321.87 | +4.40 | −5.71 | **10.11** | 0.89 |
| **333.79** | +3.65 | −0.68 | **4.33**（最差，绑定） | 0.86 |
| 423.19 | +3.18 | −3.26 | 6.44 | 0.92 |

**短板明确**：333–340 Hz 有一个约 25 Hz 宽的弱区（CD 3.5–4.3），夹在 322（10.1）与 387（10.1）两个好区之间。
这是本候选的界被压在 +0.68 dB 的直接原因，不是全带都只能做 4 dB。

### 4.4 恶化部分

- CD 最差的过门控频段是 **300–460 Hz（4.33 dB @333.8）**；其余各段最差 4.65（3–8.2k）/5.76（460–1k）/
  6.84（1–3k）/7.97（8.2–8.6k）。都为正，但没有一段超过 10 dB。

**缺测（不得插值）**

- **300 Hz 以下**：未进门控（本轮一律 ≥300 Hz）。
- **10250 Hz 以上**：未评估。
- 闭环 ASG、真人语音误切、听众可辨放大、跨场次、随电平变化：全部未测。
- 本批只有一档注入（`ref` 约 −19.5 dBFS），**没有第二档证据**，所以"更响时 H 是否变"仍是未知。

**风险**

1. 批次内第 5、6 段电平高了 3.5 dB，若那是路径变化而不是电平抬升，模型对这两段就偏乐观。
2. 333–340 Hz 的弱区如果正好是现场最先起振的频点，候选的实际收益会低于 +5.1 dB。
3. 本候选是**同场**拟合＋同场留出，**不是新场验证**；预测收益是离线预测，不能写成已实现。

## 6 事前预测（现场前写定）

对照范围按 C 给的离散档：**−14 / −12 / −10 / −8 / −6 dB**，同一夹具（音响距麦 100 cm 侧对、
棉已盖、听众就位）、同一源、同一音量，**同一轮里跑零系数臂与候选臂**。

- **方向**：候选臂的"最高稳定档"应高于零系数臂。
- **量级**：按界口径 +5.1 dB（保守）/ +8.5 dB（4096 分辨率），折算到 2 dB 一档，预期 **≥2 档**。
- **具体预期**：零系数臂预计在 **−6 dB 起振**（界的绑定在 321.9 Hz，|H|=+4.40 → 0 dB 增益时环路增益已 1.66），
  −8 dB 大概率仍稳但已在振铃；候选臂预计 **五个档全部稳定**。
- **否定条件（看到就走，不解释成还要更多数据）**：
  - 候选臂最高稳定档比零系数臂高 **≤1 档（≤2 dB）** → 未兑现预期，候选否定；回头查装载/场景/电平，不再加算法。
  - 候选臂在任一档出现比零系数臂更早的起振或更高的模态占比 → 直接否定。
  - 高 **≥2 档** → 支持候选，但仍需第二轮同条件重复才能写"可重复"。
- **可能分辨不出来的情况（必须提前说）**：如果两臂在 −6 dB 都稳定，而 C 不授权进入 −4/−2，
  那么这一轮**无法判定**候选是否兑现——因为 2 dB 的网格分辨不了 5–8 dB 的改善。
  出现这种情况时不要用"都没叫"当结论，应回报"网格不足、需要授权 −4/−2 两个判定档（带保护）"。
