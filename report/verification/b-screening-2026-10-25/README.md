## 0 决定（一句话）

**沿用 512 抽头基线，不加 EQ、不加第二个算法核；把默认系数换成同场标定的那一版，并把"标定失败即旁路"写成硬规则。**

理由：跨场次换系数会让预测从 +4.7 dB 掉到 −1…−5 dB（比不装还差），这个量级远大于任何系数微调（≤1 dB）
或固定 EQ（+3.5 dB，要动前向通路与参考取点）。

## 1 三项修正（对应任务一、二、三）

### 1.1 相位穿越：重写为"正实轴 + 相邻 bin + 不跨缺口"

旧 `phase_consistent_threshold` 把相位按 2π 折回后找变号，于是 **+179°→−179° 的折返被当成零相位穿越**，
并且会在门控选出的频点之间跳着插值。重写为 `positive_real_crossing`（`scripts/diagnose_peak_margin.py`）：

1. 只在**原始网格相邻、且两端都过门控**的 bin 之间插值（不跨低相干缺口）；
2. 在虚部过零处插值**复数环路**，**要求 Re>0**；±180° 折返处 Re<0，直接排除；
3. **小增益与穿越分开报**：`max|L|<1` 是充分条件，`1/max|L|` 是保守下界；正实轴穿越是另一套估计，
   两者不可互相替代，也不把任一个说成必要条件或绝对天花板。

回归测试 `sim/feedback/test_phase_crossing.py`（4 项）覆盖：复核给的 400/410 Hz 反例（现在返回 inf）、
真实穿越（−10°→+10° → +6.15 dB @405 Hz）、跨缺口不插值、两个口径不混用。

**与独立复核逐个吻合**（同一份 lowband2、同一个 strong 模型）：

| 窗长 | 我的小增益下界 | 复核 | 我的穿越估计 | 复核 |
|---|---|---|---|---|
| 4096 | +7.01 dB @441 | 7.009 @441.07 | +9.87 dB @882 | 9.865 @882.28 |
| 8192 | +4.75 dB @441 | 4.747 @441.07 | +7.95 dB @882 | 7.945 @881.93 |

这句要同时记住：**同一份数据换窗长，判据值变 2–4 dB**。所以这套离线判据的分辨率只有 ~±2 dB，
撑不起"≤2 dB 的改善"这类结论——这也是本轮不交系数微调候选的直接原因。

未覆盖频段：过门控 bin 只占 27–29%。所有数字只在过门控频带上成立，**其余频段记未知，不外推**，
也不把这些数字说成整条 Nyquist 的稳定保证。

### 1.2 分段边界：时间域回归不再跨段拼接

`np.concatenate` 后再建滑动窗口，会把上一段的样本当成下一段的"历史"。现在时间域拟合按段构造
（`G = Σ_seg XᵀX`、`b = Σ_seg Xᵀy`，段间不共享历史行）。

因此**撤回上一轮"两级抽取 +1.0 dB"这个数**：那是拼接历史 + 跨段频谱算出来的，不可信。
该路线本轮本来也不启动，不再补算。

频域路径不受影响：`estimate_H` 本来就是逐段做 Welch（每段 16384 = 4 个 8192 窗），窗口不跨段。

### 1.3 相干不换算成绝对地板

`−10·log10(1−C)` 是**相对麦克风功率的可解释比例**，不是 `20log10|H−Ĥ|`，也不是可稳增益，
更不能当 ASG。此前"残差与 u 相干 0.023 ⇒ 地板 0.1 dB"这种写法不再使用；改成"可线性解释的功率占比"，
并且与"物理上不能改善"这个结论脱钩（噪声、漂移、非线性、泄漏都能压相干，不能据此锁定单一原因）。

## 3 筛选 a：固定 512 抽头的加权 / 多场次系数 —— 否定

| 尝试 | 留出集结果 | 判断 |
|---|---|---|
| 正则化强度 1e-9 / 1e-7 / 1e-5 / 1e-3 | +2.68 / +2.68 / +2.64 / −1.22 dB（下界） | 无收益，越大越差 |
| 低频加权（×5、×20、仅带内） | 300–1000 改善 1–1.8 dB，但 1000–2000 从 −9.5 掉到 +0.9，总阈值反而退 | 零和搬运 |
| 迭代重加权求最差频点最优 | 训练集抬升、留出集不变 | 过拟合 |
| 多场次合并拟合 | **无法验证**：只有两个"同夹具正面"场次，其中 10-23 在话筒故障期，合并后两场都是"见过的" | 不能交未验证的系数 |

结论：**512 抽头这组容量已经被吃满**，加权是搬运、正则化无用、多场次无独立数据可验。

## 4 筛选 b：现有 FIR 之后加少量固定 biquad —— 否定

在留出 6 段上、模型不变，只在前向通路加陷波（`scripts/eval_forward_eq.py`）：

| EQ | 小增益下界 | 正实轴穿越 | 语音代价 |
|---|---|---|---|
| 无 | +2.77 @435 | +6.60 @424 | — |
| 435（8 dB，Q8） | +3.66 @3910 | +7.83 @883 | 435 Hz −7.0 dB，−3 dB 宽 54 Hz |
| +3900（8 dB，Q8） | +6.23 @888 | +7.83 @883 | 3900 Hz −5.6 dB，**−3 dB 宽 488 Hz** |
| +880（8 dB，Q8） | +6.28 @340 | +10.01 @1599 | 880 Hz 再 −7 dB，宽 110 Hz |
| 再加 1585 / 340 | +6.28…+6.77 | +10.04 | 每加一个都在语音带上再削一刀 |

**收益 +3.5 dB（两套判据一致）**，代价是：3.9 kHz 处 488 Hz 宽的缺口（辅音清晰度）、
前向数据通路要加一段 IIR、**参考取点必须移到 EQ 之后**（否则预测器模型失效，接口语义要改），
而 +3.5 dB 低于夹具重复性 σ=1.59 dB 的"≥5 dB 才认"门槛。

在 3 天内为 +3.5 dB 动前向通路和参考取点，风险与收益不成比例；**本轮不交 EQ 候选**，
系数与频响留在 `scripts/eval_forward_eq.py` 可复算，若 27 日之后基线稳定且时间允许再议。
