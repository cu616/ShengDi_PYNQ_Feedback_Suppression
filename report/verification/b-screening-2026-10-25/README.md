## 2 基线（部署 Q20、lag_first=1 + 2 拍调度）

两个判据**分别报，不合并**：`小增益下界` 是 `max|L|<1` 的充分条件（保守），
`正实轴穿越` 是 Nyquist 近似估计。两者不可拼成"可用增益区间"，也不据此对外承诺 +3 dB 或 +5 dB。

留出 6 段（`seg_10..15`），`L(f)=(H−Ĥ)·e^{−jω·2}`：

| 窗长 | 过门控 bin | 小增益下界 | 正实轴穿越 | 同门控 FIR-off（Ĥ≡0） |
|---|---|---|---|---|
| 8192 | 1189/4097（29.0%） | **+2.77 dB @435 Hz** | **+6.60 dB @424 Hz** | −7.40 / −6.46 dB |
| 4096 | 558/2049（27.2%） | **+4.56 dB @441 Hz** | **+10.71 dB @884 Hz** | −6.57 / −5.83 dB |

相对同门控 FIR-off，模型贡献 +10.2 / +13.1 dB（8192）。**这是"模型有没有用"的正确比较线，
不是 0 dB。**

全 16 段（含训练段，**不能当独立验证**，只用于和独立复核对齐）：

| 窗长 | 小增益下界 | 正实轴穿越 | 复核 |
|---|---|---|---|
| 8192 | +4.75 @441 | +7.95 @882 | 4.747 @441.07 / 7.945 @881.93 |
| 4096 | +7.01 @441 | +9.87 @882 | 7.009 @441.07 / 9.865 @882.28 |

**窗长敏感性**：同一份数据、同一个模型，两窗长相差 1.8–4.1 dB。这是**本套离线筛选的敏感性**
（离散频网 + 有限段数 + 门控成员变化），**不是通用的 ±2 dB 误差条**，也不能用来一概否定
小于 2 dB 的独立成对实测。

**覆盖限制**：过门控 bin 只有 27–29%，其余频段一律记**未知**，不外推、不当成"稳定"。
门控边界本身会换限制点：8.4 kHz 处 8363 Hz 相干 0.763（被排除）、8416 Hz 0.829、8708 Hz 0.805
（都在边界上），所以该频段的读数对门控敏感，必须连着门控一起报。

留出集分带残差（8192，相干≥0.8）：

| 频段 | max\|H−Ĥ\| | 位置 | 相干 |
|---|---|---|---|
| 300–1000 | **−2.77 dB** | 435 Hz | 0.95 |
| 1000–2000 | −6.75 | 1591 Hz | 0.97 |
| 2000–3400 | −11.01 | 2009 Hz | 0.93 |
| 3400–6000 | **−3.66 dB** | 3910 Hz | 0.90 |
| 6000–8200 | −6.72 | 6580 Hz | 0.84 |
| 8200–8600 | −12.08 | 8416 Hz | 0.83 |
| 8600–10250 | −9.43 | 8744 Hz | 0.90 |

**跨场次（10-23 场次，话筒接线松脱期，只作压力测试）**：小增益 −5.33 dB、穿越 −3.94 dB @8434 Hz；
该场次 FIR-off 是 −11.27 / −9.63 dB。**即跨场套用仍然比"不装"好 +5.9 / +5.7 dB，但绝对值转负**
——按预测，**尚无支持 0 dB 工作的证据、存在风险**。小增益充分条件不满足不等于已证明失稳（门控频网还有缺口）。这两句必须一起说，缺一句就会得出"关掉更好"的错误结论。

`candidate_512`（10-23 拟合）在新场次、同门控：小增益 −4.54 @8416、穿越 −0.62 @3641，
相对 FIR-off +2.86 / +5.84 dB。**同理：它仍有贡献，只是尚无支持 0 dB 工作点的证据。**

10-23 那一批的原始 NPZ 未交 C，**本报告里它的两个数字只有 B 侧复算，未经 C 独立复核**；

## 4 筛选 b：现有 FIR 之后加固定 biquad —— 否定

只在前向通路加陷波（`Q=8`、深 8 dB），模型不变，留出 6 段：

| EQ | 小增益下界 | 正实轴穿越 |
|---|---|---|
| 无 | +2.77 @435 | +6.60 @424 |
| +435 | +3.66 | +7.83 |

| +880 | +6.28 | +10.01 |

代价：435 Hz 处 −8.0 dB（落在语音 F1）、3898 Hz 处 −8.0 dB 且 −3 dB 缺口约 488 Hz（辅音）、
前向数据通路要加 IIR、**参考取点必须移到 EQ 之后**（契约语义变更）。+3.5 dB 是幅度筛选参考，未含因果 SOS 的相位与量化，不足以支撑改前向通路。

**口径声明**：上表用的是**幅度曲线**，不含真实因果 SOS 的复频响、系数量化与额外延迟。
所以它只能叫"筛选参考"。要把 EQ 写成可部署收益，必须另补因果 SOS 复频响与量化证据；
本轮已否定该候选，不做这一步，也不为它新增 RTL。

## 5 分段边界控制（C 要求的那条）

| 控制 | 结果 |
|---|---|
| 5a 评估侧：`seg_10` 整条 vs 切成 8 片逐片复位，**按同一批全局帧**配对 | 整条有效 15872 帧、逐片有效 12288 帧、配对 12288 帧；逐样本最大差 **0**，RMS 差 **0.00 dB** |
| 5b 拟合侧：逐段拟合 vs 拼段拟合 | 二者在留出集上相差 **0.00 dB**（拼段只多 4608 行 = 9 个边界 × 512） |
| 5b 评估侧：拼段流 vs 逐段复位 | 拼段流把抑制**少报** 0.20 dB（边界白得的预热同时带进不可预测的换段跳变，两相抵消） |

结论：只要每片保留 ≥512 帧段内历史，分段与整段在配对帧上完全等价，**分段本身不制造收益、也不构成分辨力**。若改用不同样本集合（12288 帧 vs 15872 帧）比较，差 −0.17 dB，那是**选窗差**，不能当最小可辨改善。本报告所有残差/抑制一律用逐段复位口径，并报帧数。

**因此上一轮"两级抽取 +1.0 dB"的撤回保持不变，但不能归因于拼段**——那个数字来自不可比的残差口径
（不同窗长/对齐混在一条流上），已整体废弃；两级抽取本轮不启动，也不补算。

## 6 板端记录的正确读法（引用 A 的记录，B 未操作板卡）

A 的 `closed_loop/`：`strong_g0p0` 两次守住，`strong_g3p0` 一次守住、一次 **748 帧（≈15.3 ms）后触发保护**。

- 这**不能**当"数秒尾段"，**不能**当精确起振阈值，**不能**用来验证预测下界（+2.77 dB 那一条）。
- 保护触发、削顶、单次尖峰都**不等于啸叫**；它们只说明保护路径动了。
- 预测（+2.77 / +6.60）与实测（守住 / 触发保护）**分开写**，本节不声称任何"验证通过"。
