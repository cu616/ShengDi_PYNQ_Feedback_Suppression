## 3 定点与因果延迟

- `L(f) = (H − Ĥ)·e^{−jω·2}`。Ĥ 已含 `lag_first=1` 的那一拍；**两拍调度延迟只在 `L` 里加一次**，
  不给预测支路重复加（实现里由 `model_response(..., lag_first)` + 环路乘 `e^{−jω·2}` 各计一次）。
- 时域：`prediction_pcm` 与 `microphone` 同帧对齐，`residual = mic − pred`。
- 拍预算：`3×512+3 = 1539 ≤ 2048`，与现有 512 位流一致。
- 复算入口默认 `--delay-frames 2`；改这个数必须同时改 `lag_first` 口径说明，不可只改一处。

## 4 参考取点

`reference` 必须是**实际送给 DAC 的字**（现在无 EQ，所以等于 `u`）。
本轮不加 EQ，参考取点不变。**若将来加前向 IIR，参考必须移到 IIR 之后**，否则 Ĥ 语义失效，
属契约语义变更，要走最小兼容变更表。另：若 `reference` 记的是增益级输出（`g·residual`），
则 `mic/ref` 不是 `H`，而 `mic/pred` 仍是 `H/Ĥ`（与 g 无关）。

## 6 独立数据比较（同数据、同门控、同延迟配置，只换系数）

留出 6 段（`seg_10..15`，两窗长分开，两个判据分开）：

| 模型 | 窗长 | 小增益下界 | 正实轴穿越 |
|---|---|---|---|
| calibrated（同场拟合） | 8192 | **+2.77 dB @435** | **+6.60 dB @424** |
| calibrated | 4096 | +4.56 @441 | +10.71 @884 |
| candidate_512（10-23 拟合，跨场） | 8192 | **−4.54 @8416** | **−0.62 @3641** |
| **FIR-off 基准（Ĥ≡0）** | 8192 | −7.40 | −6.46 |
| FIR-off 基准 | 4096 | −6.57 | −5.83 |

读法（**三句缺一不可**）：

1. 同场拟合的系数，两套估计分别给出 +2.77 dB（充分条件下界）与 +6.60 dB（Nyquist 估计），
   **不能拼成一个"可用增益 +2.8…+6.6"**，也不据此对外承诺 +3 或 +5；
2. 跨场套用 `candidate_512` 时绝对值为负 → 按预测，**尚无支持 0 dB 工作的证据、存在风险**；小增益充分条件不满足不等于已证明失稳（门控频网仍有缺口，未覆盖频段未知）；
3. 但它相对同门控 FIR-off 仍高 **+2.86 / +5.84 dB**。所以**"跨场系数"≠"关掉抵消更差"**，
   只是不够支撑 0 dB 工作点。做任何"模型有没有用"的比较，都必须对 FIR-off 这条线，不是对 0 dB。

跨场次压力测试（10-23 场次，话筒接线松脱期，**不作独立验证**）：calibrated 小增益 −5.33、
穿越 −3.94 dB @8434；该场 FIR-off 为 −11.27 / −9.63 dB。

## 8 事前预测（预测，不是实测性能）

- 同场标定 + 本系数：小增益下界 **+2.77 dB**、正实轴穿越 **+6.60 dB**（8192 窗长，留出 6 段）。
  两个数分开用，不合成一个区间。
- 换场次未重新标定：0 dB 附近甚至为负，**不承诺任何提升**。
- 分辨率：窗长改变使判据值差 1.8–4.1 dB，这是本套离线筛选的敏感性，**不是通用 ±2 dB 误差条**，
  也不能用来否定小于 2 dB 的独立成对实测。
- 引用 A 的 σ=1.59 dB / 极差 4.71 dB 时必须注明：那是**整捕获窗口**的重复性，不能代替 C 源内定音门禁的重复性。

## 9 否定条件（出现就停批，不在现场调参）

1. 同场标定后、同一 g 下 **0 dB 就触发保护**（或 mic 峰接近满幅）→ **静音停批、保存原始包**，交 B 复核，不升档。
   先排除非啸叫原因（定音门禁、保护误触、削顶、单次尖峰、音响待机），再谈与预测是否一致；
   **保护触发本身不能直接推出"与预测矛盾"，也不能当成起振阈值。**
2. `+3 dB` 两次重复都触发保护而 0 dB 稳 → 同样先排除上述非啸叫原因；确认是环路失稳后，才谈下调对外口径。
3. 装配的系数哈希与 §2 不符 → 一律当未标定处理，**不装载旧场系数**。
4. 标定链失败（门禁、定音、源关闭任一不通过）→ **静音停批、保存证据**；
   **不在原增益下自动旁路**，旁路要由操作者独立核实工作点后显式开始。
