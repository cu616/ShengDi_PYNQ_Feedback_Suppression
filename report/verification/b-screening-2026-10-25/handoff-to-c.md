## 3 定点与因果延迟

- 环路：`L(f) = (H − Ĥ)·e^{−jω·2}`。Ĥ 已含 `lag_first=1` 的那一拍，**不要再给预测支路额外加两帧**；
  两拍是调度延迟（`u[n] = sat(source[n] + g·residual[n−2])`），只出现在 `L` 的这一项里。
- 时域口径：`prediction_pcm` 与 `microphone` 同帧对齐；残差 `residual = mic − pred`。
- 拍预算：`3×512+3 = 1539 ≤ 2048`，与现有 512 位流一致。

## 4 参考取点

`reference` 必须是**实际送给 DAC 的字**（现在没有 EQ，所以等于 `u`）。
本轮不加 EQ，因此参考取点不变；**若将来加前向 IIR，参考必须移到 IIR 之后**，否则 Ĥ 的语义失效，
属于契约语义变更，要先走最小兼容变更表。

## 8 事前预测（这是预测，不是实测性能）

- 同场标定 + 本系数：**可用数字增益 ≈ +2.8…+6.6 dB**（小增益下界与正实轴穿越两种口径的区间），
  保守取 **+3 dB** 作为对外口径。
- 换场次、未重新标定：**0 dB 附近甚至为负**，不能承诺任何提升。
- 度量分辨率：同一份数据换窗长，判据值差 2–4 dB；所以凡是 <2 dB 的差异都不要写成结论。

## 9 否定条件（出现就回退，不在现场调参）

1. 同场标定后、同一 g 下 **0 dB 就保护触发**（或 mic 峰接近满幅）→ 与预测矛盾，回退旁路，
   保留原始包交 B 复核，不升档。
2. +3 dB 的两次重复都触发保护而 0 dB 稳 → 实测门槛低于预测下界，按 +0…+3 dB 口井交付。
3. 装配的系数哈希与 §2 不符 → 一律当未标定处理，回退旁路。
4. 标定链失败（门禁、定音、源未关闭任一不通过）→ **不要装任何旧场次系数**，直接旁路。
