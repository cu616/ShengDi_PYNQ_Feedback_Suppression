# 300–1000 Hz 的残差能压到多少：512 抽头做不到 −15 dB

> 触发：A（08965d2）要求交一版在 300–1000 Hz 把 `max|H−Ĥ|` 压到 −15 dB 以下的 512 系数；
> 并给出新标定（16 段、−12 dBFS、相干 0.93、拟合残差 7.36 dB、带内 `max|H−Ĥ|` −5.42 dB @435 Hz）。
> 结论：**这个指标在 512 抽头（乃至 681 抽头）下不存在可交付的解**，缺口是记忆长度与夹具重复性，
> 不是拟合技巧。下面每个数字都可用仓库脚本复现。

## 1 先接受 A 的三条

1. 带限 300–3400 对抵消无收益（+3.65 → +3.89 dB）：接受，`381 Hz` 本来就在通带里。
2. 低频标定加强（相干 0.81 → 0.93）把可稳增益从 +3.65 抬到 +5.42 dB：接受。
3. 夹具重复性 σ=1.59 dB、6 次 1 kHz 定音极差 4.71 dB：接受。**从这轮起我对外只给 ≥5 dB 量级的结论**，
   上一轮的 "+6.74 dB" 应当读作 "+5 dB 量级"。

## 2 部署模型的分频段残差（本仓 6 段标定批，相干门控 0.8）

| 频段 | max\|H−Ĥ\| | 位置 | \|H\| | 相干 | 对应阈值 |
|---|---|---|---|---|---|
| 300–1000 | **−6.64 dB** | 381 Hz | +5.73 | 0.81 | +6.64 dB |
| 1000–2000 | −11.93 | 1621 Hz | +0.84 | 0.84 | +11.93 |
| 2000–3400 | −12.29 | 3028 Hz | +0.05 | 0.87 | +12.29 |
| 3400–6000 | −6.79 | 4220 Hz | +3.49 | 0.93 | +6.79 |

**A 的表里缺 8600–10250 这一段**，而板上啸叫主频三次都是 **9131 Hz**——它落在 A 报的四个频段之外。
这一段必须补上，否则"限制点 381–435 Hz"这个结论没有被覆盖到实际起振的那个频点。

## 3 为什么 512 抽头到不了 −15 dB

**（a）抽头数扫描（同一批、带内加权、in-sample，属乐观上界）**

| 抽头 | 300–1000 的 max\|E\| |
|---|---|
| 256 | −0.20 dB |
| 512 | −9.44 dB |
| 680 | −13.42 dB |
| 1024 | −12.11 dB |
| 2048 | −14.82 dB |

`in-sample` 已经把噪声一起拟合了，所以这是**乐观上界**；即便如此，680 抽头也只到 −13.4、2048 才 −14.8。
每翻一倍抽头约 +3–5 dB，要到 −20 dB 需要 ~3000 抽头。而架构上限 681 在本器件上还到不了：
512 抽头的位流 BRAM 已经 80 %，680 放不下。**所以“继续加抽头”这条线在现有位流上已经关闭。**

**（b）模态的时间常数**：381–435 Hz 这个峰 −3 dB 宽 95 Hz → Q≈4.5，振铃时间常数
`τ = Q/(πf) ≈ 3.3 ms`。512 抽头 = 10.5 ms ≈ 3.2τ，即模型只能记住 3 个时间常数；
要压 20 dB 需要 ~10τ ≈ 33 ms ≈ 1600 抽头。和 (a) 扫描一致。

**（c）交叉验证（训练 seg 0–2，测试 seg 3–5）**

| 抽头 | 训练 max\|E\| | **测试 max\|E\|** |
|---|---|---|
| 512 | −9.13 | **−5.15** |
| 680 | −11.20 | −5.10 |
| 1024 | −12.56 | −5.83 |
| 2048 | −12.28 | −3.85 |

加抽头对独立测试集没有帮助，甚至变差（拟合噪声）。同一批两半的 `H` 自身就差 **−4.08 dB**（相干 0.5 时的
估计噪声）。**所以在我这份数据上，低频残差的地板是测量决定的，不是滤波器决定的**；
A 的 0.93 相干数据地板会低得多，但要分清"能到多少"和"能证明多少"。

## 4 A 那个验收指标本身有两个口子

1. **只看幅度、不看相位**。`max|H−Ĥ|` 是必要条件；实际起振点在 `arg((H−Ĥ)e^{-jω·2})=0` 的穿越处。
   A 自己的数据就是反例：带内最大在 435 Hz，起振却在 9131 Hz 和 457 Hz。
   应改用相位一致阈值（`scripts/diagnose_peak_margin.py` 已实现），否则会拿一个不该优先修的频点当靶子。
2. **分带窗口没有覆盖到实际起振频点**（见 §2 的 8600–10250）。

## 5 如果真要 +20 dB，该动的是什么

按 `max|E|` 反推：`|E| = −15 dB` 只能给 +15 dB；要 +20 dB 得 `|E| = −20 dB`。

| 方案 | 预期 | 代价 |
|---|---|---|
| 512 抽头调权重 | 最多 −10…−12 dB，且会牺牲高段 | 零成本，但不解决问题 |
| 681 抽头（架构上限） | −13 dB 左右 | 需要改 RTL 常量，已到顶 |
| **抽取二级**：6.1 kHz 上 384–512 抽头 | 等效 3000–4000 抽头（60–80 ms），可到 −18…−20 dB | 加一级 8× 抽取（半带级联）+ 一个 384 抽头 FIR；MAC 约 2.3 MMAC/s，只有主 FIR 的 9 %；延时线 384 字，比在 48.8 kHz 存 3072 字的 BRAM 便宜得多 |
| 物理解耦（话筒/音响 0.5 → 1.5 m） | 带内耦合少 ~9 dB，等效把"要压的量"直接削掉 | 零 DSP，但要重摆夹具、重标定 |

**我的判断与 A 一致：数字侧再调系数收益已经很小；能过关的是抽取二级或物理解耦，两者都需要先有 0.93 相干的数据。**
