# 8.4 kHz 峰处的环路裕度：增益缺口是"会话传递"，不是系数符号

> 触发：A 报告同一夹具、同一数字增益下的三臂对照——旁路 0 dB 稳、cancel 在 −6 dB 啸叫、
> 主频 8285 Hz；并请求诊断 8.4 kHz 附近 `H−Ĥ` 的相位与幅度。
> 数据：A 的 `manifest/`（房间 6 段 seg_0…5，ref+mic，16384 帧/段，延迟均为 125）
> 与 `model_512.json`。复现：`scripts/diagnose_peak_margin.py`。

## 0 结论

1. **模型在 8.4 kHz 处没有反相**。用这 6 段估计的 `H` 与部署的 `model_512` 相减：
   `|H| = +11.11 dB @8380 Hz`（相干 0.975），该频段 `CD = +21.5…+39.4 dB`，
   相位差 `−2.8…+4.8°`。8.29 kHz 处 CD 为 **+32.2 dB**。不存在"某频点反相"。
2. **缺口在会话传递**。同一模型在这 6 段上的失稳阈值是 **+6.64 dB**（必要判据）/
   **+7.32 dB**（相位一致判据，含 2 拍闭环延迟），A 实测为 **−6 dB**——相差 13 dB。
   同一个系数不可能既是 +7 又是 −6，差的是"这批数据里的 H"与"A 现场那一刻的 H"。
3. **8.4 kHz 峰的裕度本来就极薄**，因为 `|H| = +11.1 dB`（3.59 倍）：要把残留环路增益压到 1 以下，
   模型在这个 bin 的相对误差必须优于 **−11.1 dB**。实测容差（本报告 §4.2）：
   错位 **0.2 拍** 阈值掉到 +1.1 dB、**0.3 拍** 到 −1.9 dB、**0.5 拍** 到 −5.8 dB；
   峰值幅度过预测 **2.6 dB** 阈值即 −1.8 dB、**4.5 dB** 即 −7.4 dB。
   0.5 拍或 4 dB 就足以把 A 的 −6 dB 复现出来。
4. **A 的三臂对照里参考臂不成立**：`cancel_zero`（Ĥ=0、回路闭合）的阈值算出来是
   **−11.11 dB**，在 0 dB 必然啸叫。它在 0 dB 被记为"稳"，说明该臂的回路没合上，
   或者"稳"是假阴性。旁路臂是开环（不把 residual 加回去），任何增益都"稳"，
   **不能作为"不用模型的可用增益"**。因此"模型把可用增益从 0 dB 拉到 −6 dB"这句不成立；
   真实对照应当是 cancel_zero 与 cancel 的阈值之差。

## 1 复现

```bash
python scripts/diagnose_peak_margin.py --data-dir <6 段 npz 目录> --model <模型 json>
python scripts/diagnose_peak_margin.py --data-dir ... --model ... --emit-dir <目录>   # 生成 ±1 拍诊断变体
```

估计口径：Welch（nperseg 4096、Hann、50 % 重叠）累加 6 段，`H = S_um/S_uu`，
相干门限 0.8、下界 300 Hz（662/2049 个 bin，平均相干 0.943）。
阈值两种：必要判据 `max|H−Ĥ|`（环路增益必要条件），相位一致判据在
`arg[(H−Ĥ)e^{-jω·2}]=0` 的穿越点插值 `|H−Ĥ|`。

## 2 256→512 补零等价（C 的集成门禁）

判定：**等价**，条件是零必须补在**尾部**（`padded[k]=h[k] (k<256)`、`padded[k]=0 (256≤k<512)`），
即零对应最大滞后，而不是头部。

`scripts/verify_padding_equivalence.py`（A 的 `model_256.json` / `model_256_pad.json`）：

| 检查 | 结果 |
|---|---|
| 头部 256 项与原模型相同 / 尾部 256 项全零 | 是 / 是 |
| 浮点逐样本最大绝对差 | 5.55e−17（16384 帧；卷积累加顺序不同造成的末位差，不是不等价） |
| **Q20 + 24 位饱和逐样本** | **0 / 4096 不符，饱和计数 0 vs 0** |
| 反例：零补在头部 | 15701 / 16384 不符（最大差 0.352）——证明该检查有分辨力 |
| 系数指纹（Q20 数组 sha256，前 16 位） | base `ce31dbcede31e711`，padded `914e0ab4192b71fb` |

三点必须写进集成记录：
- 等价的是**数学传递函数**；抽头数、每帧 3N+3 拍、BRAM 占用、流水线级数由编译期 `TAPS` 决定，
  不因系数为零而改变。所以"补零等价"只保证 `prediction` 相同，不保证"省资源"。
- 浮点路径**不会**逐位相同（累加顺序变了），板上是 Q20 整数路径，逐样本相同。
- A 那次 bit-exact 只能证明"RTL 与下发的数组一致"。若数组本身是前补零，比对仍然会全过。
  区分办法就是本节的检查：尾部补零 → 与 256 位流的 `prediction` 逐样本一致；前补零 → 立刻差到 0.35。
  A 报告 0 处不符，等价于确认补零位置正确。

## 3 8.4 kHz 频段：模型与这批 H 的实测关系（shift=0）

| freq | \|H\| | \|Ĥ\| | 相位差 | CD | 相干 |
|---|---|---|---|---|---|
| 8297 Hz | +8.32 | +8.52 | +0.4° | +32.1 dB | 0.981 |
| 8392 Hz（峰附近） | +10.79 | +10.68 | +2.1° | +28.3 dB | 0.964 |
| 8488 Hz | +8.71 | +8.77 | +4.8° | +21.5 dB | 0.975 |

即：这个频段 CD 是正的、相位是对的。**"8.4 kHz 反相"不成立。**

限制频点不在 8.4 kHz，而在别处：`max|H−Ĥ| = −6.64 dB @381 Hz`（CD 只有 +12.4 dB），
相位一致判据落在 4215 Hz（+7.32 dB）。这与既有结论"房间 512 的短板在 300–1000 Hz 与 3.9 kHz"一致。

## 4 缺口从哪来：三条独立证据都指向"会话 H 与标定 H 不同"

### 4.1 阈值差 13 dB

本批 6 段上 `model_512` 的阈值 +6.64 / +7.32 dB；A 实测 cancel 在 −9 dB 稳、−6 dB 啸叫。
如果系数有问题，误差是**固定的**，不会时而 +7 时而 −6。

### 4.2 灵敏度预算（本批 H，只平移/缩放模型）

亚采样错位（8380 Hz 处 1 拍 = 61.8°）：

| 错位 | 0 | 0.1 拍 | 0.2 拍 | 0.3 拍 | 0.5 拍 | 1.0 拍 |
|---|---|---|---|---|---|---|
| 阈值 | +6.64 | +5.70 | +1.13 | −1.86 | **−5.81** | −11.18 |

峰值附近幅度过预测：

| \|Ĥ\|/\|H\| 偏大 | +1.5 dB | +2.6 dB | +3.5 dB | +4.5 dB |
|---|---|---|---|---|
| 该点阈值 | +3.0 | **−1.8** | −4.7 | −7.4 |

A 的 −6 dB 恰好落在"0.5 拍错位"或"约 4 dB 峰值过预测 + 少量错位"这两条线上。
两种都是**会话级**差异，不是系数书写错误。

### 4.3 宽带 \|H\| 本身就差了 3.26 dB

| 来源 | 宽带 \|H\| |
|---|---|
| 标定批 6 段（按参考能量加权、相干门控） | **+3.26 dB** |
| A 旁路臂 0 dB（ref = mic = −36.5 dBFS） | **0 dB** |

标定时的源是 −24 dBFS RMS，A 的对照是 −36.5 dBFS，差 12.5 dB。
在 +11 dB 的窄峰上，3.26 dB 的过预测正好把阈值压到 −4…−5 dB。

### 4.4 已排除的部署故障

| 假设 | 该假设下的阈值 | 与 A 的 −6 dB |
|---|---|---|
| 加载路径只吃到前 256 个系数（后半截零） | −2.37 dB @425 Hz | 差 3.6 dB，且限制频点在 425 Hz，不是 8.4 kHz |
| 前补零（零在最大滞后侧） | −15.23 dB @8463 Hz | 差 9 dB |
| 整拍错位 ±1 | −11.2 / −11.3 dB @8.4 kHz | 比 A 更差，方向不符（错位更多只会更坏） |

三个都解释不了 −6 dB，说明下发通路本身没有明显故障——这与 A 的 bit-exact 结果一致。
剩下能同时给出 −6 dB 与 8.285 Hz 主频的，只有"亚采样错位 + 峰值过预测"的组合。


## 5 三臂对照的参考臂无效

- `bypass`（无预测）：`u = source`，**开环**。阈值无穷大，任何增益都"稳"，不能当"不用模型"的基线。
- `cancel_zero`（Ĥ=0，回路闭合）：`residual = mic`，环路增益就是 `|g·H|`，
  `max|H| = +11.11 dB` → 阈值 **−11.11 dB**。0 dB 时环路增益 3.6 倍，必然啸叫。
  A 在 0 dB 判"稳"，因此该臂要么没合上回路，要么"稳"是假阴性
  （有源音响待机/压缩都能造出这种读数）。
- 恒等式检查：数字注入下 `mic/ref = H`，与 g、与 Ĥ 都无关
  （`ref` 是 PL 实际播放的 `u`）。A 的表里 bypass 0 dB、cancel −9 dB（+8.6 dB）、
  cancel −6 dB（−14.5 dB）三处互不相容，必须有一处 `ref` 不是播放信号，或通路在该增益下被压缩。

另外，闭环里 `mic/pred = H/Ĥ` 也是**恒等式**（`pred = Ĥ·u`、`mic = H·u`），
这是不需要额外标定的模型误差测量，A 现有的捕获就能算。

**这两个平移变体是诊断探针，不是候选**：在本批 H 上它们的阈值是 −10…−11 dB（故意变坏），
只有"A 侧延迟确实差整拍"时才可能变好。不要写进部署清单。

## 7 反证条件（谁对谁错怎么判）

- 若 A 给出会话 `mic/ref`（闭环任一档、同一源电平），其 8.38 kHz 处 `|H|` 与标定批相差 <1 dB、
  相位差 <10°，则本报告 §4 的"会话传递"结论被否定，缺口回到系数或部署实现上。
- 若 `cancel_zero` 在 −9 / −6 dB 也不啸叫，则 §5 的"该臂回路没合上"被否定，
  需要检查 `u = sat(source + g·residual)` 在 Ĥ=0 时是否真的执行。
- 若换用会话 H 重拟合后，`cancel` 在 0 dB 仍啸叫，则"过预测是主因"被否定，
  下一个怀疑对象是 2 拍调度延迟在环路里的实际值（不是 2）。
