## 0 一句话

**两次成功与后来削顶之间差的不是距离，是 20–24 dB 的输入电平；而这一层差异用"量一下电平"是分不开的——
两种解释给出同一个数。** 能分的是频谱形状与环路签名，需要成功那两次的原件。
**不依赖这一答案就能定的两件事**：A 记的"环路增益 −19 dB、正增益可行"**不成立**（那是能量平均，稳定性看峰值，
峰值处 −8 dB 时环路增益是 −3.60 dB）；现有候选**适用**，且它兑现时 328 Hz 一带的共振抬升会掉 5–10 dB——

## 2 两个待判解释

### 解释一：当时的输入链灵敏度低 20–24 dB（部分接触）

麦克风线半接时既可能恒读（事实 7），也可能只是衰减。若当时衰减 23.9 dB，则同一 5 cm 语音本应读 −4.0，
实测读 −27.9。**连带后果**：环路增益也一起低 23.9 dB → 当时 −8 dB 的环路增益约 **−31 dB**，
即**近讲那次几乎没有反馈**，听到的是"无环路的放大"。

预言：若真在 5 cm，谱应有明显近讲低频抬升；主频应由语句决定，两次不同（253/298 就是两次不同）。

### 解释二：当时实际距离远大于 5 cm（约 78 cm）

链路灵敏度未变，只是声学距离不同。−27.9 相对 −4.0 差 23.9 dB，折距离 5 cm × 10^(23.9/20) ≈ **78 cm**。

预言：谱形应接近远场（低频无明显近讲抬升）；且 328 Hz 一带应与当前 −8 dB 同强（环路一直是活的）。

### 现有材料能支持到哪

- **倾向解释一**：两次成功的主频是 253 与 298 Hz，**两次不同**；而同一几何下的环路模态固定在 328 Hz
  （事实 9 五档全是 328 Hz，A 的 −8 dB 记录也是 331 Hz）。主频随语句变、且都明显低于环路模态，
  更像语句谱峰带出来的，不像环路在振。
- **但不能定案**：−8 dB 时环路只有 3.6 dB 裕量，共振 Q 很低，即使环路是活的也未必主导谱峰。
  而且"单模占比"本身不是再生的充分证据（新规则已写明）。

### 能分开它的证据（一次列清，全部是**已有**原件，不要求重采）

### 一个必须说清的观察：量电平分辨不开这两个解释

明天如果按计划"先量 25 cm 的 mic 电平"，**两种解释给出同一个数**：

| 距离 | 解释一预测 RMS | 解释二预测 RMS |
|---|---|---|
| 25 cm | −17.98 dBFS | −17.98 dBFS |
| 40 cm | −22.06 dBFS | −22.06 dBFS |

代数上恒等（都锚在当前 −4.0 dBFS @5 cm 这一点上）。所以这一步**只能**决定"这一档合不合格"，
不能决定"当时到底发生了什么"。不要把它当成分辨实验。

**而且这一步大概率先不合格**：按 16.6 dB 波峰因数，25 cm 的峰值约 **−1.4 dBFS**，40 cm 约 **−5.5 dBFS**，
而现场门槛是峰值 < −6 dBFS（要求 RMS ≤ **−22.6 dBFS**）。也就是说 25 cm 大概率过不了门槛，
要么把距离推到 45–50 cm，要么降源电平。这是算术推断，不是测量；手机源的电平和 AGC 都未知，以现场实测为准。

## 3 单位与饱和：先独立核对，再谈风险

RTL 逐行读的结果（`feedback_fir.v:30` 与 `:32`）：`rounded = (|acc| + 2^19) >> 20`，随后
`clip` 到 **±2^23 计数**。`scripts/verify_r4_waveforms.py` 里 `SCALE = 2**23`，同一约定。
所以：

| 量 | 满量程 | 说明 |
|---|---|---|
| 系数（Q20、signed24） | ±8.0 | 2^23/2^20。本候选最大 \|q\| = 47879 = 0.0457，只用满量程 **0.57 %** |
| PCM（reference / mic / prediction） | ±1.0（±2^23 计数） | **饱和阈值在这里，不在 8.0** |

- **"‖h‖₁ ≤ 1 就不会饱和"是充分条件，不是充要条件。** 本候选 ‖h‖₁ = **2.2875843** > 1 →
  "任何合法输入都不饱和"**不成立**。上一版拿 8.0 当分母算出的"还差 10.9 dB"已在 `254b8e9` 撤回，本次独立复核确认撤回是对的。
- **真正决定风险的是窄带增益，不是 L1。** `max|Ĥ(f)| = 1.2309`（+1.80 dB）@ 359.1 Hz；
  `|Ĥ| ≥ 1` 只在 **292.1–421.7 Hz** 这 88 个 bin（占 0.5 %）。
- **边界例子（手算 + 整数复现互相独立）**：359.1 Hz 持续单音，解析阈值 A_u ≥ 0.8124（−1.80 dBFS）；
  用 RTL 逐样本整数路径跑 16384 点，在该幅度上恰好出现 **1 个**饱和样本，−3 dBFS 时 0 个、pred 峰值 0.8714。
  白噪声 RMS 到 −6 dBFS 时 pred 峰值只有 0.3144，不饱和。
- **本批实测**：`|u|` 峰值 −6.00…−8.26 dBFS，pred 峰值 **−22.07 dBFS**，六份合计饱和 **0**（与 metadata 一致）。
  这是**这一档电平下的观测**，不是任何电平下的保证。
- **结论落点**：候选在这个工作点不会饱和；只有环路真跑到接近满幅（自激）时 pred 才会饱和。
  那时饱和计数是**结果**，不是模型失效的证据——按这条读，不要反过来用它否定候选。

## 4 先把"耦合"拆成五个口径，再说环路裕量

同一份修线后数据，五种都被叫过"耦合"：

| 口径 | 值 | 用途 |
|---|---|---|
| A 时间域电平比（rms mic / rms ref） | **−11.29 dB** | 宽带电平比 |
| B 带内能量平均（300–10250，门控） | **−11.01 dB** | **A 记的"−10…−12 dB"就是这个** |
| C 带内幅度中位 | −13.84 dB | 描述 |
| D 带内幅度**峰值** | **+4.40 dB @ 321.9 Hz** | **稳定性只看这个** |
| E 峰值频率 | 321.9 Hz（300–345 Hz 整段 +2.5…+4.4 dB） | 模态位置 |

**A 记的"loop gain = −8 + (−11) ≈ −19 dB，远低于 1，所以正增益可行"是把口径 B 当成了环路增益。**
峰值口径下逐档是：

| 增益 | 环路增益（峰值口径） | 小增益余量 | A 实测 |
|---|---|---|---|
| 0 dB | **+4.40 dB** | −4.40 | 满幅啸叫 ✔ |
| −4 dB | **+0.40 dB** | −0.40 | 响但浑（占比 0.68）✔ |
| −6 dB | **−1.60 dB** | 1.60 | 近再生掩蔽（0.37–0.70）✔ |
| −8 dB | **−3.60 dB** | 3.60 | 稳（0.12–0.16）✔ |

两者差 **15.4 dB**。**A 的实测台阶与峰值口径逐档对上，与 −19 dB 不自洽。**
所以"正数字增益可行"的推论要撤回；0 dB 时环路增益是 +4.4 dB，必然自激（与实测一致）。

### 顺带标定"界有多保守"

静音源台阶实测：−4 稳、−3 临界、−2 起振 → 自激边界 ≈ **−2.5 dB**。
小增益界给 **−4.40 dB** → **界比实测保守约 1.9 dB**（充分条件的正常表现，不是错误）。
这条很有用：它把"界"和"实测边界"之间的固定偏移量第一次量出来了，下一节用它换算候选。

## 6 同条件对照的事前预测

### 6.1 允许的五档内，两臂都不会自激——所以"叫没叫"分辨不了

候选把界从 **−4.40 → +0.68**，同一 FFT 网格、同一门控规则下的**离线界差 +5.08 dB**。
把它当"台阶整体平移"的假设（这是假设，不是保证）：约 **−8 dB 的"稳"点移到 −2.9 dB**。
所以 −14…−6 五档内两臂**都稳**，用"是否起振"做判据会得到"都没差别"——那是判据不够灵敏，不是候选无效。

### 6.2 能分辨的量：源还在放时 328 Hz 一带被抬高多少

线性估计 `boost = −20log10|1 − g·|H||`：

| 增益 | 零系数 环路/抬升 | 候选 环路/抬升 | 预测差 |
|---|---|---|---|
| −14 | −9.60 / +3.5 dB | −14.68 / +1.8 dB | 1.7 dB |
| −12 | −7.60 / +4.7 dB | −12.68 / +2.3 dB | 2.4 dB |
| −10 | −5.60 / +6.5 dB | −10.68 / +3.0 dB | 3.5 dB |
| −8 | −3.60 / +9.4 dB | −8.68 / +4.0 dB | **5.4 dB** |
| −6 | −1.60 / +15.5 dB | −6.68 / +5.4 dB | **10.1 dB** |

**两次比较，二选一即可：**
- **在 −8 dB 比**（A 现在的可用点）：预测 328 Hz 一带的抬升从 +9.4 掉到 +4.0 dB → **差 5.4 dB**。
- **在 −6 dB 比**（离边界更近，差更大）：预测从 +15.5 掉到 +5.4 dB → **差 10.1 dB**。
  但 −6 的零系数臂已经接近再生，非线性压缩会把观察到的差压小，所以**以 −8 为主、−6 为辅**。

### 6.3 同一轮内的锚点（不需要跨场次比较）

**候选 @ −6 dB 应与零系数 @ −12 dB 同量级**（环路 −6.68 对 −7.60 dB，差 0.9 dB）。
所以请**零系数臂也跑 −12 和 −14**——那两档本来就在允许范围内。
判读时用"候选@−6 vs 零系数@−12"这一对，就在同一轮、同一源、同一距离里，不需要任何历史基线。

### 6.4 支持 / 否定 / 仍无法判断

| 观测 | 结论 |
|---|---|
| 候选@−8 的 328 Hz 抬升比零系数@−8 低 **≥4 dB**；或候选@−6 与零系数@−12 相差 ≤2 dB | **支持候选**，兑现量级 ≈ 5 dB；可进第二轮同条件重复 |
| 候选@−8 的抬升比零系数低 **<1.5 dB** | **否定候选**（界口径预期 5.4 dB，只兑现不到 1/4 说明另有机制）；回头查装载/距离/源电平，**不再加算法** |
| 两臂**都**在 −6 自激或都触发保护 | **未分辨**：报"网格不足、区间未定"，不据此否定，也不据此要求进入 −4 / −2 |
| 候选臂比零系数臂**更早**自激或 328 Hz 更响 | **否定候选**，这是有分辨的失败（方向相反，不能用噪声解释） |
| 输入削顶、峰值越 −6 dBFS、或任一次保护触发 | 该档**判无效**，不是候选的结论；先修输入 |

### 6.5 必须写在前面的三句限制

1. 界差 +5.08 dB 是**离线、两个 FFT 网格、同一门控规则下的界差**，不是现场收益，也没有保底。
2. 界比实测保守约 1.9 dB（第 4 节标定的），所以"候选实测边界 ≈ +0.68 + 1.9 ≈ +2.6 dB"只是换算，
   不是承诺；改变的是量程不是事实。
3. 328 Hz 抬升是线性模型估计。零系数@−6 预测 +15.5 dB 已经进入压缩区，实测一定小于这个数；
   **判读只看两臂的差，不看绝对值是否等于表里的数。**

## 7 缺测与边界（不要用离线结论反驳这些）

- 300 Hz 以下、10.25 kHz 以上：本轮无覆盖。
- 460–3000 Hz：修线后有 190 个过门控 bin（该段约 336 个，57 %），不再是"中频未测"，但**不等于整带覆盖**。
- 随电平变化、闭环 ASG、真人误切、听众可辨放大、跨场次：全部未测。
- 数字增益的**符号**不决定听众处的声学放大：−8 dB 那两次听众确认"能放大、很清晰"（事实 1–3），
  这条按新规则记为**成功**，不能因为增益是负的就写成"无扩声"。
- 本报告的 328 Hz 与 A 记的 331 Hz 是同一段的两个估计（8192 点、5.96 Hz 栅格；303–340 Hz 整段 +2.5…+4.4 dB），
  不是两个模态。

## 8 本轮改变了哪个决定

1. **撤回"环路增益 −19 dB、正增益可行"**（A 的 `mic-fault-impact` 结论）→ 换成峰值口径 −3.60 dB @−8 dB。
   这直接决定：**不允许把增益往 0 dB 方向推**，除非候选兑现。
2. **候选被判定为适用**，不需要重训；对照的判据从"有没有叫"改成"328 Hz 抬升差多少"。
3. **"量 25 cm 电平"这一步不承担分辨解释的作用**，只承担门槛检查；不满足门槛就换距离或降源。
