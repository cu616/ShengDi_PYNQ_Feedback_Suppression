# PYNQ-Z2 LINE_IN 麦克风采购要求

建档日期：2026-10-05；验证状态更新：2026-10-11。用途：建立麦克风到音响的实时扩声通路，在 PYNQ-Z2 上研究声反馈啸叫抑制。

2026-10-11 用户确认：已购 MAX4466 模块接入 LINE_IN 可以工作，方案已获得实际输入成功反馈。实际供电、增益、左右声道、录音波形和持续运行指标尚未完整记录。两只新三段领夹麦及新转接线的失败实验、原因猜想与后续对照见同目录《PYNQ-Z2音频排查记录_2026-10-05.md》的 2026-10-11 更新。

## 建议购买的类别

购买“带麦克风咪头、偏置供电和手动可调前置放大的模拟音频模块”，由模块单独取电，向 LINE_IN 输出连续模拟音频。优先选有接线图、原理图和实际录音示例的产品。若不希望焊线，选择带 3.5 mm LINE OUT 的成品；若接受简单接线，可选明确标有 VCC、GND、OUT 的模块，配三段 TRS 接线头。

连接目标：

```text
麦克风＋偏置＋前置放大模块 → LINE_IN → PYNQ 实时处理 → HP+MIC → 已供电音响
```

该方案使用分开的输入输出插孔，不需要现有的 CTIA 耳麦合并转接线。无需把原 Y5 的故障原因完全查清后才推进新方案。

## 电路依据与实验边界

本地 TUL_PYNQ_Schematic_R12.pdf 第 7 张图中，LINE_IN 通过滤波、约 1 kΩ 串联电阻与 10 μF 耦合电容接 ADAU1761 的 LAUX/RAUX，没有从 MICBIAS 向该插孔供电。HP+MIC 的麦克风则走另一条含偏置和切换芯片的通路。因此，LINE_IN 所接模块应自行提供咪头所需偏置及前置放大。

截至建档日，只有耳麦直插 HP+MIC 可录音、音响直插可播放的成功反馈。2026-10-11 更新：MAX4466 接 LINE_IN 已可工作，原耳麦同轮直插 HP+MIC 仍能录到人声；两种输入通路均有兼容附件下的成功对照。这不证明新领夹麦可直接接 LINE_IN，也不代表录音音质、双声道和实时处理性能全部合格。

## 采购参数表

下列数值区分工程选型建议与硬件限制；推荐数值不是对开发板绝对最大额定值的声明。

| 项目 | 要求或建议 |
|---|---|
| 输出类型，必须 | 连续模拟音频波形，能够驱动线路输入；不接受仅声音有无的数字开关量或音量包络 |
| 麦克风及供电，必须 | 模块包含咪头和所需偏置电路，另有供电连接，不依赖 LINE_IN 给麦克风供电 |
| 前置放大，必须 | 模块已经完成音频放大；增益或输出幅度可手动调节，设定后保持固定 |
| 自动处理，必须可关闭 | AGC 自动增益、噪声门、自动降噪、回声消除、自动防啸叫关闭；优先买本来就没有这些功能的模块 |
| 模块电源 | 优先明确支持 3.3 V 的低噪声模块，或正规 5 V 供电成品；供电范围依所买模块说明，模拟输出幅度须单独核对 |
| 输出电平 | 应能调低到数十至数百毫伏交流信号。初调可考虑约 0.05～0.2 Vrms，具体取决于说话距离和音量，以实际录音不削顶为准；这不是硬件最大输入值 |
| 增益范围 | 对普通驻极体咪头，可把约 20～40 dB 手动可调作为搜索起点；最终按咪头灵敏度及实际距离选择，不能只追求最高增益 |
| 频响 | 第一阶段语音实验建议完整模块覆盖约 100 Hz～8 kHz；若研究更宽频段，优选 20 Hz～20 kHz，并核对在实际增益下的频响 |
| 信噪比 | 优选不低于约 60 dB(A)，要求说明测试条件，例如 94 dB SPL、1 kHz；“低噪声”“高灵敏”字样不能代替参数 |
| 最大声压 | 优选至少约 110 dB SPL，留意靠近音响或啸叫时咪头自身也可能过载；这是项目余量建议 |
| 输出阻抗 | 优选低阻单端输出，建议不大于约 1 kΩ；若是差分输出，需要匹配转换电路，不能随意把一端接地 |
| 指向性 | 第一阶段全指向咪头即可，固定麦克风与音响的位置；最终做演讲扩声可选心形指向，但它不能代替算法效果验证 |
| 接口定义，必须 | 3.5 mm TRS 的 Tip=左声道、Ring=右声道、Sleeve=地，或明确标注 OUT/GND。单声道只用一个输入通道也可以 |
| 接线附件 | 已焊好引脚或螺丝端子、短屏蔽音频线、3.5 mm TRS 公头或已接好的音频线。不要把原 CTIA 耳麦合并线当作线路音频接线头 |
| 文档，必须 | 模块级供电范围、引脚图、增益调节说明、输出波形/幅度与直流偏置说明，最好有原理图 |

不必指定驻极体或 MEMS 为唯一技术路线，关键是整个模块提供上述模拟接口。普通 USB、I2S 或 PDM 麦克风没有可直接接 LINE_IN 的模拟输出；它们可以用于其他方案，但会改变当前接口与驱动路线。

## 输入幅度为什么需要可调

ADAU1761 数据手册在 AVDD=3.3 V 时给出 1 Vrms 的满幅参考电平。核对的官方 `select_line_in()` 源码把辅助输入增益设为 0x07，数据手册对应 +6 dB。因此不能把“1 Vrms”直接当作默认配置下板上插孔的通用不失真上限；电阻负载、内部增益、音频峰值都会影响余量。

建议先从低增益开始，在实际距离下说话，检查原始录音峰值。可将最响测试语音的数字峰值约 −18～−6 dBFS 作为初调参考，且波形不出现平顶；此范围是工程建议，不是采购硬门槛。不要只靠浏览器播放器的响度判断，播放器音量或归一化会影响听感。

交流音频幅度与直流偏置是两回事。例如某模块静态输出 1.65 V，不等于它输出了 1.65 Vrms 音频。板上 LINE_IN 已有耦合电容，可隔离合适模拟模块的直流偏置，但仍需控制交流峰值。模块“3.3 V/5 V 供电”不代表可以向 LINE_IN 输入同样幅度的音频，更不能把 VCC 电源脚接到音频触点。

## 可考虑的模块方向

MAX4466 手动调增益的麦克风模块可作为入门候选，需购买带咪头和偏置外围的完整模块。Adafruit 的公开模块是一个有明确文档的参考设计：2.4～5 V 供电、25～125 倍可调、OUT 带 VCC/2 直流偏置。其他商家的同名板不能直接视为完全相同。

MAX4466 的增益带宽积约 600 kHz；按单极点近似，125 倍时带宽约 4.8 kHz，实际模块还受咪头和外围电路影响。用于宽带啸叫实验时不要把电位器开到最高后仍假定有 20 kHz 带宽，需核对所用增益下的响应。

MAX9814 具有 AGC，初始实验不优先选择默认开启 AGC 的成品。芯片可禁用 AGC，但模块必须提供可操作的禁用方式及说明；仅切换 40/50/60 dB 档位不等于关闭 AGC。上述选择是为了让测试时音频回路增益稳定、算法开关前后的比较可解释。

不选只有 D0 声音触发输出的传感器。某些带 A0 的声音检测板也只给出未经适当放大的信号或包络，必须确认 A0 是可录音的连续波形。也不要采购输出给无源扬声器的功率放大器来接 LINE_IN。

## 单声道模块如何接入

模块 VCC 接其规定电源，GND 接音频公共地；OUT 接三段音频公头的 Tip（左输入），Sleeve 接 GND。第一阶段只分析录音左声道，Ring 端按接线方案处理，不因右声道没有声音而判定失败。若要左右同时采集同一信号，应确认驱动能力并设计分配，不能把两个独立输出端直接短接。

若购买带标准 LINE OUT 的成品，可用三段公对公音频线接板子 LINE_IN。建议一并准备这根线，以后也能用电脑耳机输出从低音量开始验证板子的线路输入。

## 可直接发给卖家的需求

> 我需要用于音频录音和啸叫抑制实验的模拟麦克风模块，接开发板的 3.5 mm LINE IN。请提供带咪头、供电及前置放大的完整模块，能输出连续模拟音频，手动调节增益，AGC/自动降噪/防啸叫可关闭或没有这些功能。优先 3.3 V 或 5 V 供电，OUT/GND 引脚明确或带标准 LINE OUT，音频输出幅度能调低到数十至数百毫伏。请提供供电范围、接线图、输出幅度/直流偏置、频响和增益说明；若需接线，请配可接到三段 3.5 mm 公头的线。

## 项目验收和后续软件范围

先用录音保存 WAV 验证 LINE_IN，随后再建立连续的录音、处理和播放通路。现有 `record(5)` 后 `play()` 的顺序只适合验证输入输出，不能构成实时啸叫抑制系统。最终需要控制处理延迟，并保持算法对照实验的模拟增益、声学位置和音响音量一致。
