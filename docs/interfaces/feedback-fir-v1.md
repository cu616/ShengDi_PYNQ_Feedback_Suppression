# 定点反馈抵消核 v1（2026-10-18）

状态：256抽头独立核已通过逐样本仿真和OOC综合布线，不改变已上板overlay。负责人为本轮AI开发，团队人工审阅待进行。接口是内部同步端口，不臆造AXI地址。证据见report/verification/feedback_fir。

- 时钟100MHz，低有效同步resetn；所有输入同域。
- 输入一对同帧reference_pcm和microphone_pcm，均24位补码。reference必须是实际DAC参考（含已有增益/限幅），不能用未播放值替代。
- in_valid且in_ready时接受。输出预测为Σh[k]reference[n-1-k]，当前reference在计算结束才存历史，避免覆盖最老样本。TAPS默认256，支持1..1024。
- 系数24位补码、20位小数。coeff_begin在空闲时启动一次完整加载，随后coeff_valid/coeff_ready按h[0]至h[TAPS-1]顺序传输，无地址；加载完成才接受采样，历史计数清零。中途不能继续使用半套系数。
- 每抽头分读存储器、乘法、累加三拍，累加58位；接受后3*TAPS+3拍产生out_valid，下一拍可接受新样本。256抽头约7.71微秒计算时间，尚非端到端音频延迟。1024抽头超出2048拍/帧预算，不允许直接用于当前实时音频集成。
- 预测结果按半值远离零舍入，再饱和到24位；残差用25位mic-predicted计算，再饱和到24位。两个饱和标志随out_valid有效。
- bypass在接受样本时锁存；输出麦克风原样但仍更新预测历史。无bias减法、无自动增益和自适应更新。
- 忙时输入样本、非法加载等置protocol_error粘滞标志，不覆盖当前计算；复位清除。上层必须检查错误并静音，不能无声丢帧后继续宣称有效。
- 复位取消在途运算、使系数无效；RAM不逐字擦除，以历史有效计数屏蔽旧值。

验收已使用Python任意精度整数参考产生向量，2304帧预测/残差/饱和标志一致，并核对旁路、重载、忙时输入及复位中断。手算半值/饱和/前一帧例子另在软件测试覆盖。独立核通过不等于音频集成或闭环ASG验证；参数范围1..1024是设计范围，本轮只仿真/实现256抽头。
