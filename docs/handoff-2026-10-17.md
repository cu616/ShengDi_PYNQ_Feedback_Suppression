## 当前交付到哪里

已完成基础自定义音频通路的可听验证、两组真实箱体开环标定，以及板卡本地的路径拟合。下一项是可加载系数的定点FIR抵消模块。实时反馈抵消、闭环稳定增益、长时间音质和端到端延迟均未验收。

| 项目 | 证据与边界 |
|---|---|
| 官方录放 | 用户听到有底噪的清晰人声；不等于实时直通 |
| 自定义PL直通 | 用户听到纯音及人声；0.75秒不足以评价语音质量 |
| 开环采集 | 两轮各32768帧，参考序列校验True，满幅样本0，恢复并静音成功 |
| 真实路径模型 | 第一轮训练固定256抽头，第二轮验证误差降低9.6893 dB |
| 附加检查 | 四段9.51～9.96 dB；Q20系数量化后几乎不变；错移参考对照−2.8578 dB |
| 本地验证 | 既有13项软件测试、标定RTL仿真和Vivado实现完成，详见证据目录；本次文档整理没有重跑 |

上述9.69 dB是开环预测误差降低，不是ASG。Q20检查没有模拟完整硬件乘加、舍入、饱和。最大抽头68帧所对应的1.39264 ms也不是系统端到端延迟。完整数字见 [实测分析摘要](../report/verification/audio_calibrate/board-analysis-2026-10-16.md)。
