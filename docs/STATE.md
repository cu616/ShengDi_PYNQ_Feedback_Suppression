## 一句话

在 PYNQ-Z2 上用 PL 侧 256 抽头定点 FIR 抵消声反馈，目标是提高稳定扩声音量；
**目前只有工程链路和数字核对通过的证据，没有任何正常扩声条件下的抗啸叫效果证据。**

> **待核实（2026-10-23 新增，优先级最高）**：A 本轮三臂对照得"cancel 在 −6 dB 啸叫、旁路 0 dB 稳、
> cancel_zero 0 dB 稳"，据此说"模型把可用增益从 0 拉到 −6 dB"。但 `cancel_zero`（Ĥ=0、回路闭合）
> 的阈值算出来是 **−11.11 dB**（`max|H| = +11.11 dB @8380 Hz`），在 0 dB 必须啸叫；
> 而旁路是开环，任何增益都"稳"，不能当"不用模型"的基线。
> 所以这句话的两个前提都不成立，**在 A 给出 cancel_zero 的阈值（衰减率外推）之前不要采用**。
> 见 [peak-margin-2026-10-23](../report/verification/peak-margin-2026-10-23/README.md) §5。
> 旧的口径冲突（本句 vs A 段"箱体 10.8 dB / 房间 4.0 dB 实测 ASG"）同源，一并等这一条澄清。
