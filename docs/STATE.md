  ——旧夹具；B 测得其冲激响应峰在 128 抽头而新布局延迟 185 帧）已改名为
  `...STALE-oldfixture.json`。板上 A/B 证实它比"不装模型"更差，现行测试一律用零系数。
- **固定配置**（[记录](../report/verification/audio-replay/field-config-2026-10-26.json)）：
  音响距麦 **100 cm、侧对**，上方 30 cm 金属板**已盖隔音棉**（属夹具）；听众离音响 20 cm；
  前置增益未动；音响音量最大；Codec 40；48.8 kHz。
- **零系数下的可用窗口**（[证据](../report/verification/audio-replay/live-round-2026-10-26.json)）：
  −8 dB 干净（模态占比 0.12）但听众"完全听不出人声"；−6 dB 能听到放大但被**白噪声样再生**盖住；
  −4 dB 更响但**更浑浊**（331 Hz 占比 0.68）；0 dB 起振满幅。**"又响又清楚"的点不存在。**
- **麦克风松线事故**（[影响评估](../report/verification/audio-replay/mic-fault-impact-2026-10-26.json)）：
  采集阶段三次判废，ADC 恒读 −4.2 dBFS、与源电平和增益都无关；重插后底噪 −35.1 dBFS、
  满量程样本 0。**早前那次"5 cm/−8 dB 确认清晰"是在半接触、灵敏度偏低时测得的**，正常接线
  同一位置会**输入削顶**（mic −4.0、峰值 0.0）。该点不能作为标定工作点。
- **可信的开环数据**（[采集包](../report/verification/audio-replay/bind-capture-2026-10-26/)）：
  6 段 × 16384 帧，源 −6 dBFS 白噪、`zero_coeff=True`、增益 −40 dB 开环；
  ref ≈ −19.6、mic −28.7…−32.7 → **宽带耦合约 −10…−12 dB**；此前"耦合 +15 dB、满音量自激"
  是松线假象，**已作废**。
- **低频抑制尝试失败**（[根因](../report/verification/audio-replay/lowcut-attempt-2026-10-26.json)）：
  自设计 250–470 Hz 抑制系数（|Ĥ| 峰值 2.6）在五个增益点全部触发预测饱和。
  我的 `sum|q| = 4,090,156`，距饱和阈值 8,388,608 还有 6.2 dB → **B 判断正确：是环路发散
  不是字宽**；我把因果搞反了，已改正。（另：仓库 `candidate_room_v1_512.json` 的
  `sum|q| = 8,218,857`，只剩 0.2 dB 余量，已报 B。）
- **停止与留证已核实**：`replay_trial` 顺序为 guard 触发 → PL disarm + Codec 静音 → 读计数 →
  存证 → 抛异常（停声在写文件之前，留证不延误保护）。
- **过程教训（写入判据）**：读数不随激励变化时，**先查接线再谈声学**——今天因此废了三次采集。
- **下一步只等一件事**：B 用 `bind-capture-2026-10-26` 重定绑定频点并给出匹配系数；
  系数到板后按"−8 dB 起、每 2 dB 一档"复扫，判据是"比零系数高多少 dB 仍稳"，再由听众判定。
