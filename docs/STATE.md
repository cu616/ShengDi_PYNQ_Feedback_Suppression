## 一句话

在 PYNQ-Z2 上用 PL 侧 256 抽头定点 FIR 抵消声反馈，目标是提高稳定扩声音量；
**目前只有工程链路和数字核对通过的证据，没有任何正常扩声条件下的抗啸叫效果证据。**

## 当前唯一目标

在正常可听扩声、同一硬件同一增益的条件下，得到旁路/抵消的成对对照，
并测出可重复的稳定增益差（ASG）。其他一切工作都应指向这一件事。

**已验证（有证据）**

- 最小 PL 直通、开环采集、256 抽头 Q20 FIR 板上逐样本一致，误差降 6.92 dB。
- 闭环零模型与真实模型两模式在约 −36 dB 下回读 bit_exact、无饱和、能恢复静音。
- 38 项既有软件测试 + B 线新增 24 项，共 62 项通过。
- 2026-10-21 首次真实声学成对对照（`audio_replay`、关盖箱体）：2 s 窗口下噪声源 ASG ≈ +5.5 dB、
  人声源 ≈ −4.5 dB；**10 s 窗口下抵消起振点进一步下移**（≤ −19.5 / ≤ −15 dB），旁路 −18 dB 仍稳定。
  见[报告](../report/verification/audio-replay/2026-10-21-asg-field.md)。

**未验证（不得当作已实现）**

- 一致可重复的 MSG / ASG；且"稳定"侧阈值必须用正向对照重测（有源音响会待机）。
- 正常可听扩声：关盖箱体外听不清语音，只能听到啸叫。
- 端到端电学延迟；音质；人声误切率。
- `audio_closed` 输出失效的根因（已排除 RTL 顶层、驱动与 Codec 配置，指向 bitstream）。
- 512 抽头的 RTL 仿真与布局布线。
- 完整板级 I/O 时序签核（仍缺 1 输入 / 3 输出延迟约束）。
