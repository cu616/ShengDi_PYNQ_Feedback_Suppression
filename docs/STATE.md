## 一句话

在 PYNQ-Z2 上用 PL 侧 256 抽头定点 FIR 抵消声反馈，目标是提高稳定扩声音量。

**2026-10-22 结论：小信号下抵消是有效的，ASG 预测 +15.1 dB。**
A 改为开环直采 H（不推到啸叫），并交出板上实际算出的 `prediction_pcm`。用板上的 pred
直接相减：**mic 峰值降 11.41 dB、RMS 降 14.06 dB**——这是不依赖窗长、门控与模型的结果。
预测的抵消起振 −11.25 dB 与 A 闭环实测的 −12 dB 起振吻合（差 0.75 dB）。

A 此前算出的 `CD +2.4 dB` 是**相干门控不足**造成的：900 Hz 附近相干塌到 0.005–0.5，
不做门控会把 CD 从 +14.8 dB 拖成 −14.3 dB。

**但仍没有实测 ASG。** 旁路一侧的阈值因音响待机而缺失，"抵消比旁路更早起振"
这个跨试验比较也不成立（两次试验音响状态可能不同）。必须重测。

**2026-10-22 晚：房间夹具（0.5 m）诊断出新结论——限制 ASG 的是抽头时长，不是估计器。**
256 抽头在 300–3000 Hz 的 CD 为负（−0.53 / −1.96），512 抽头全部翻正（+5.41 / +3.76），
全带 ASG 从 +11.32 提到 +16.32 dB。**"加抽头"只需改参数：512 用 1539 拍，预算 2048 拍。**

## 当前唯一目标

在正常可听扩声、同一硬件同一增益的条件下，得到旁路/抵消的成对对照，
并测出可重复的稳定增益差（ASG）。其他一切工作都应指向这一件事。

## 已验证 / 未验证（只在这里写一次）

**已验证（有证据）**

- 最小 PL 直通、开环采集、256 抽头 Q20 FIR 板上逐样本一致，误差降 6.92 dB。
- 38 项既有软件测试 + B 线新增 24 项，共 62 项通过。
- 真实箱体路径已在 155–10967 Hz 上测出并复现（相干 0.970 @381 Hz）。
- **实测（正向观测，可信）**：抵消在 −12 dB 起振；起振频点 抵消 232 / 274 Hz、旁路 423 Hz。
- **小信号（−30 dBFS 注入）下抵消有效**：板上 pred 使 mic 峰值降 11.41 dB、RMS 降 14.06 dB。
- 板上 `prediction_pcm` 与 Python 模型 bit_exact（16128 帧），等效延迟差 −0.115 帧。
- `audio_closed` 的 DAC 无输出，同批配对只差 +0.06 dB（A 于 10-21 查明）。
  **因此 10-19/10-20 那批"闭环 bit_exact"只证明 PL 算术，不证明回路。**

**未验证（不得当作已实现）**

- **实测 ASG**：无。小信号 ASG +15.06 dB 是模型推算，不是实测。
- **音响在线性**：每次试验前未证明音响真的在响，因此所有阈值类结论待重测。
- 标定↔使用耦合差多少：未知（原 −8 dB 的估计已随 β 作废）。
- 端到端电学延迟；音质；人声误切率。
- 512 抽头的 RTL 仿真与布局布线（在失配未解决前没理由做）。
- 完整板级 I/O 时序签核（仍缺 1 输入 / 3 输出延迟约束）。
- `closed_loop_sim` 的发散判据在「长 room + 高增益」下非单调（g=−20 dB 判发散、
  g=−10 dB 判稳定），未修完；引用 `find_msg` 的阈值前必须先与 `1/max|H_eff|` 对照。
