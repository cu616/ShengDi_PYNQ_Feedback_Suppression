# C 产品软件与统一入口

本轮按队长2026-11-01新任务执行；技术现状读 [STATE](../STATE.md)，人工转发消息优先，不恢复REQUESTS派活。

C拥有产品状态机、唯一recal_entry.sh、配置/模型事务、提示编排、现有assemble_experiment的产品打包分支和回包复核。A提供hw_api硬件适配并唯一操板；B提供纯数值evaluate、拟合/独立验证及有界策略。文件边界和输入输出见 [recal-product-v1](../contracts/recal-product-v1.md)。C不替A/B重写实现。

B判定库由C的[消费层](../contracts/recal-policy-consumer-v1.md)承接；该层属于编排边界，不改B阈值/拟合语义。B库原样接入与字段测试不等于实际捕获解析/拟合包装器已交付；完整适配仍按同一evaluate边界封装。

冻结产品以[整机接入v3](../contracts/recal-runtime-v3.md)为准：直接调用B identity/evaluate，ATTEMPTS原样取用；旧三点与v2消费者保留历史范围。同一recal_entry提供A维护检查参数，C只做离线叶子I/O替换验证；板卡仍由A独占。

目标是普通使用者移动设备后按实体CAL，按提示讲话/安静，看到明确结果，按START扩声，拨码切换并STOP；无需AI在线、改代码、选模型。启动静音，候选独立验证与实际安装身份一致后才生效；失败不恢复新场景旧模型。停止不等计算；单次结束真实报告，不拼段声称无限连续。

先使用模拟硬件/固定算法返回完成软件，再由A/B补真实适配。现有Q20/身份/保护/打包工具继续复用；不扩建无用途测评平台，不操板，不重复无关旧全套。验证层次分别报告，不将模拟通过或无保护当成声学效果。

交付为 [操作单](../ref/recal-product.md)、安装包/冻结身份、软件验证、唯一启动入口和一个多布局回包。真实硬件缺灯/键/及时停止能力就明确阻塞，不能用电脑键盘或日志冒充实体完成。
