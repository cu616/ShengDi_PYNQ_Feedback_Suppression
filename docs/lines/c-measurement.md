## 2. 首轮最小交付：修正测量闭环

先完成以下关键能力，再增加功能。不要先做通用判据库、漂亮界面或大型平台。

### 2.1 保护计数和异常证据

核对现行驱动的寄存器定义及解包。如果 clip_counts 依次保存打包的 prediction/residual、gain、mix，prediction 应取第一项低 16 位，residual 取其高 16 位，gain/mix 对应第二、第三项。打包整字不能当 prediction，后两个计数不能错位。按实际契约给 A 修复请求和测试；集成 A 返回的版本。

每次保存实际起止帧、原始四路数据、各类计数、是否早停及错误原因。发生保护后先停止声音并冻结采集，再尽力保存和恢复；落盘失败也要记录原因。不能成功项落盘、被保护打断的关键试次反而无证据。

保护是电平或数值事件，不能把异常字符串含 saturation 自动映射为声学啸叫。旁路未参与输出的预测饱和，也不能直接定义声学阈值；相同旁路输出不应因换模型而获得不同的测量边界。运行保护策略的底层变化交 A 实现和验证。

### 2.2 捕获时间和尾段门禁

每份记录应能定位到整个试次：实际 first_frame、completed_frames、捕获帧数、采样率、源实际结束帧、过渡区、缺帧和未知区间。源结束时刻要核对 ABI 与实际调度，不能仅靠请求时长猜测。

只有捕获区间确实位于源结束及必要过渡区之后，才能称“纯尾段余振”。源计划一秒、保护在几十毫秒发生时，保存的是启动期早停数据。分析器必须拒绝把它当尾段；不得异常后对任意短片段继续算“尾段斜率”。

分别报告原始波形覆盖和全程计数覆盖。末尾窗口未增长只说明这个窗口，全程无饱和不等于全程无增长。观测不足先交最小必要统计方案或准确的 A 线硬件请求，不把缺失区间填成通过。

### 2.3 固定分类，避免再混用指标

使用下面的结果类别，并保留可以同时发生的原始标志：

| 类别 | 依据与限制 |
|---|---|
| invalid | 配置、版本、参考对齐、声源或完整性不满足本轮要求 |
| protection | 保护触发；保留类型、时刻和实际数据，不能自动等于声学失稳 |
| observed_instability | 在有效区间内按预先固定的判据观察到声学增长，附对应证据 |
| no_instability_observed_in_window | 明确的有效窗口内未观察到失稳，不简写成无条件稳定 |
| unknown | 证据不足或多种解释未排除 |

例如保护前已经观察到有效增长，可以同时记录保护标志和增长判定，不能为互斥分类丢掉证据。不填写未经标定的 confidence 百分比，不把未知当 0。

判据与参数在发声前冻结，说明源是否仍在播放、底噪、观察长度和削顶的影响。稳定纯音、人声峰、源起停和数字过冲不能一律算啸叫。非单调结果提示假设或观测需查证，不能删掉不符合预期的档位来恢复漂亮曲线。

只有同条件、同一判据、有效观察长度和足够边界数据，才输出 MSG/ASG 区间及重复结果。保护点、RMS 降低和 CD 不能单独变成实测 ASG；阈值未找到就交已测范围。

## 3. 不依赖新现场实验的验证

先用已获准的历史数据和可控信号完成必要用例：

- 稳定纯音、语音或语音替代信号，增长窄带、衰减余振，源起停和底噪窗口。
- 削顶但无增长、旁路只有预测饱和、保护发生在源结束前、真正位于源结束后的尾段。
- 缺帧、错误索引、参考错位、版本不匹配、通信/执行中断和落盘失败。

预期结果必须有独立依据，不能参考实现与被测程序同方向改错。验证通过就打包，不反复跑没有变化的项目。

原始数据不改。历史复算另存派生结果，保留旧报告、旧判据和新版本，写明结论为何变化。原始录音未经授权不出板；如需板上数据，给 A 一个可本地静默运行的分析程序，只回传获准统计，不自行连接板卡绕过 A。
