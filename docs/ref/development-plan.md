### 2026-10-27 执行顺序

历史配置和观测数只引用 [STATE关键数字](../STATE.md#关键数字)，原件见

取消“先补满十次重复性”和“当前稳定即证明历史距离解释”的推断。

1. **现场前准备**：A 核对已有实现的身份和可用入口；C 在既有流程内准备路径确认、输入检查、短时复现、
   听众静音/开声对照及持续使用分支。操作单须写真实本地/板卡路径、Notebook代码格序号与标题，
   不能让用户自己拼代码。B 同时分析旧材料，不要求现场先等新模型。
2. **核实历史条件**：以同一讲话人和尽量相同的一句话复现，标记讲话、麦克风、音响和听众位置，
   保存现场设置。手机声源不能冒充历史真人；不恢复不可靠接触，不人为制造故障。
3. **输入与路径**：输出静音时检查实际讲话，沿用现有峰值/异常/停止条件。若历史近讲距离输入削顶，
   不闭环硬试；记录“原条件拒绝”，本轮仅允许将讲话距离作为一个自变量，取得不削顶的近讲对照。
   这个对照必须标为变更条件，不能改称原样复现。路径未知时由 A 核实实际播放/接线，C 分析未检出，
   不盲目重复r4或直接删掉检查。
4. **短时复现**：输入和路径合格后，在历史零系数工作点运行两次约10秒；穿插输出静音的听众对照，
   同一句话、同位置、相近声量，询问“是否更容易听清、是否清晰、是否有持续鸣叫/明显失真”。
   记录人工原话和实际输出数据；人声变化造成的不确定性保留，无校准录音不报精确声压差。
5. **成功后固定**：两次均清晰、无保护且未见失稳证据后，保持设置做一次60秒真人使用，
   保存运行时间线和实际捕获范围。这里只验证该可用工作点的持续使用，不重复此前纯工程60秒验收。
6. **候选对照**：B/C确认模型仍匹配场景后，在同一增益、相同条件下运行零系数/现有候选对照，
   复用现有双臂评价。候选无改善、观测不足或失败分别报告；不为制造差别自动升档、换模型或改模拟增益。
7. **失败后收敛**：A 交具体失败类型和可比较记录，B 从已列解释中选一个能被区分的因素，C 确认测量能回答。
   本日最多追加一轮有明确结果分支的定向试验；仍未解决交队长决定范围，不再全局扫参数。

包的质量由**发送方**负责，A 不承担判据实现。每次发实验包或模型包前：

1. **用包内自带的软件夹具空跑一遍**（B/C 的包里都有 `runner is not None` 的软件路径，无需板卡），
   在交接消息里贴固定格式一行，数字必须是实数，不能是"应该可以"：
   `SELFTEST ok | trials=N | window_frames min=<数字> | gate=passed | 预计板端 <分钟>`
2. **包内附机器可读的 `preflight.json`**，由发送方脚本自动计算写入（不接受手写声明）。
   每个 trial 至少给出 `seconds`、`source_frames`、`transition_frames`、`capture_frames`、
   `window_frames`、`ok`，以及顶层 `all_ok`。
   冻结驱动的通用约束：`seconds >= source_seconds + 2442/48828 + 16384/48828 + 余量`（约 1.42 s），
   否则捕获窗为空、分析器只能给 unknown。
   模型包同样给 `taps`、`lag_first`、Q20 哈希，以及 −12/−6/0 三点 `ref/mic` 与期望值的一致结果。
3. A 核对 `all_ok`、实际板端版本及真人条件。为 false、文件缺失或版本不符时，回 `PREFLIGHT_FAIL`
   并附原文，不运行该包；修包是发送方的活。软件 `all_ok` 不代替现场路径与输入检查，
   不自动禁止在适用条件内使用另一份已验证基线。
4. 失败按缺陷类记录（D1 窗口参数、D2 哈希不符、D3 字段缺失、D4 语义与驱动不符）。
   **同一类累计三次**，由 A 带日志请队长裁定，不重复消耗板卡与现场时段。

本条只前移验证位置，不增加发送方总工作量（包本来就必须能在板端跑通），也不要求 A 新建工具。
