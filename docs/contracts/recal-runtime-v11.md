## 现场记录的范围

唯一最终参数来源为[报告§十七](../../report/verification/audio-replay/demo-protocol-2026-11-02/README.md)。+3.0 dB抵消20秒稳定及拨码后约3.49秒保护停声，均为A直接入口的同布局记录；9.13秒是原较长运行中拨码时刻，不能照搬到本包8秒窗。当前产品演示先抵消2–3秒，再拨码，仍需A验证，3.49秒不是本包保证时延。

每次START前SW0拨下；起跑已旁路或没有有效的运行内切换时刻，不能作为“抵消→旁路”对照。保护后仍撤销当前模型资格，拨回开关不自动重启；按提示CAL，通过后才可START。自然8秒结束且资格有效，可再次START。

沿用原驱动饱和保护，不提高阈值或延长响声。播放峰值到0 dBFS/gain_saturations=6是数字满幅，不证明声压、频率或设备安全；417 Hz低频音色不能靠提高数字上限变尖。听感与自动判断分开记录。

- 旁路边界±0.1 dB同点不可复现，不给精确ASG保证；A区间估计限原场景、模型与时长，不能外推。
- 小音响声压及热安全未评估，仅供A值守短时演示。
- 下载期约0.9秒按键观察空窗未验收，不宣称全阶段BTN3≤200ms。
- 一次install捕获bit_exact=False，15872帧全不匹配；同条件下一轮恢复，未复现，原因未解决。新包软件验证不消除此项。
