## 固定配置

本演示包 expected_identity.gain_q12=6900，标称 +4.5 dB；allowed_gain_q12 保留 1631/2303/3254/4096，并增加 6900。允许集合用于硬件维护/初始化，不赋予运行期随意选档：runtime 仍严格比对固定 6900。

训练/验证计划继续 direct_only=true、zero_coeff=true、开环增益0，不改变 B 的三档激励及判据。阶段身份允许0/6900，prepare另允许此前批准的保留增益，以便静音启动和配置切换；安装完成必须实际回读6900，运行不能用其他允许档替代。

run_seconds=8，每次按 START 仅请求8秒，真实报告自然结束或保护提前结束；不循环、不拼段。compute/io均150秒。默认普通包仍保持原配置；只有明确的演示包启用本节。

维护自检使用 maintenance_gain_q12=1631（−8 dB），仅3秒接口链路检查，收据记实际维护增益；避免初始化零模型在6900下形成已知会起振的旁路回路。维护不提交可用模型资格，也不算演示效果。正常产品安装/运行仍固定6900。

## 适用证据与限制

A 的 [现场记录](../../report/verification/audio-replay/demo-protocol-2026-11-02/README.md) 来自同一摆位/模型的直接入口：抵消5秒段在+5.5 dB稳定、+5.6 dB起振；后续现场SW0切换彩排也为直接入口。它们不等于本产品入口、其他模型/布局或长时间运行已验收。

推送前新增的20秒复核须优先纳入解释：+4.5 dB在18.5秒因输入满幅停声，+5.0 dB完成20秒，+5.5 dB在12.6秒输出饱和。输入满幅与环路失稳分开记录，5秒二分不能当持续稳定边界或确定的1 dB裕量。A最新建议+4.0 dB；本包按用户本轮明示继续固定6900/8秒，记录差异，不自动改档、不声称8秒必然安全或稳定。

- +4.5 dB旁路可能很响并起振，由驱动饱和保护停声，属于实际保护，不是软件限幅。
- 小音响长时间工作余量未评估；本包仅供 A 独占值守短时演示。
- 下载期间约0.9秒按键观察空窗未实测，不能宣称全阶段BTN3≤200ms。
- 旁路边界未单独二分。早期所报约2.5–5 dB量级仅限原短段观察，不据此报持续或精确ASG；25 dB麦端电平差和+4.63 dB独立验证预测不称为ASG。

保护后候选资格被撤销，拨回SW0不会自动恢复播放；按产品提示重新CAL，通过后再START。不改为保护后自动重启。自然8秒结束且本场景模型仍有效时，允许再次按START。

操作见 [操作单](../ref/recal-product.md)。新包通过文件/接口检查可交 A 验收，不提前宣称产品演示已通过。
