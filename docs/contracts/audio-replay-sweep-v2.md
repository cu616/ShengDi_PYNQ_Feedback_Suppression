# 预录语音逐档批次接口 v2

状态：实现待验证（本轮板卡静默调试，声音试验未执行）
生产方：A · 消费方：A / B / C
最后变更：2026-10-21 原因：用户授权A直接SSH部署调试，现场改为按钮操作。

继承[v1](audio-replay-sweep-v1.md)的数据来源、固定声源和成对规则，硬件/PCM/寄存器不变。
本版本仅增加以下行为；JSON字段结构不变，schema_version仍为1。

- 3 dB默认网格最后可追加一档0.5 dB向下取整的上限以内档位，距前档至少1 dB；
  每档仍用实际Q12检查原6 dB裕量上限，最多8档。不为获得多档放宽保护上限。
- 标准库按钮页调用同一prepare_sweep/record_source/run_sweep。服务器启动不操作音频，
  仅用户点击并确认现场条件后才调用相关步骤。录音配置前先确认音响断电。
- 只允许一个工作线程；一次性提示ID拒绝双击/旧提示；等待输入15分钟超时取消。
  “停止后续”在下一确认处生效，不作为实时急停。网络不能替代现场断电保护。
- 服务仅绑定板卡直连地址，允许本机以太网地址访问；随机会话令牌、同源POST校验。
  令牌和SSH密码不提交仓库；SSH首次固定主机密钥，后续拒绝密钥不匹配。
- A读取摘要，不下载原始WAV/NPZ。操作步骤见[按钮页说明](../../board/audio_replay/README.md)。

实际板卡范围与进度以[STATE](../STATE.md)为准；本版本不增加ASG或正常麦克风扩声结论。
