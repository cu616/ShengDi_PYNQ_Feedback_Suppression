# 开环残差 overlay 接口 v1
>
> **已冻结（2026-10-20）。** 本文描述的 overlay 是诊断或中间版本，已被 `audio-closed-v1` 取代；
> 保留作历史依据，**不要按本文新增实现、也不要据此加载板卡**。
> 现行契约见 [../README.md](../README.md)。


目标：保持已验证的 I2S 时序与已知激励，将实际DAC参考和同帧ADC交给256抽头核。ADC及残差均不送DAC。原audio_calibrate不变；此为独立audio_residual工程。

- 100MHz，2048拍/帧；默认16384帧，发声预算约0.336秒，独立于ADC VALID。
- `control`沿用bit0启动、bits4:1右移4..10、bit8种子。开始前完整加载256个Q20系数；每轮重新加载以清空历史。停止后结果RAM保留。
- `coefficient_cmd`低24位系数；bit25每翻转一次启动加载；bit24每翻转一次写一个系数。两个事件不得同时发出。写操作仅在arm=0时进行，GPIO电平可保持，不会重复加载。
- `coefficient_status` bit0可写系数，bit1可接收采样，bit2 FIR协议错误，bit3已完成本轮新系数加载，bits19:4加载数量。协议错误需overlay复位恢复。
- `capture_cmd`低14位读地址；bit16=0返回实际参考/麦克风，bit16=1返回预测/残差。两级同步读延迟；软件写地址后需给至少两个PL时钟，读取前可读回命令作总线屏障。
- `capture_status` bit0完成，bits16:1完成残差帧数，bit17配置错误，bit18故障，bit19预测曾饱和，bit20残差曾饱和。只读取完成数量以内的地址。
- 每帧握手时保存参考和麦克风，FIR完成后将四路一起写入RAM。计算可以跨音频帧边界，不能拿下一帧tx_word与上一帧预测配对。
- 运行中改系数、启动时系数不完整、FIR忙时来样本等错误阻断输出；错误锁存，须复位。饱和仅标记，不冒充抑制成功。
- GPIO基址由生成hwh中的IP字典取得，不硬编码地址。新增双通道audio_coefficients，输入/输出各32位；其余IP命名沿用标定工程。

当前已完成256抽头线级仿真及整板bitstream构建，尚未上板。详细结果以progress为准。此overlay用于开环残差核对，不是闭环扩声版本。原始数据留板，现场发声仍由用户手动触发。
