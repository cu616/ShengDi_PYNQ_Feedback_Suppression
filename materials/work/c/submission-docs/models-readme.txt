# 历史标定模型与参考系数

本目录保存不同历史布局下的模型及注册表，用于离线复算和追溯。
模型文件中的 `fixture_id`、采样率、Codec音量和系数哈希限定各自适用条件；不同布局不能直接混用。

| 位置 | 内容 |
|---|---|
| manifest.json | 历史模型身份、格式及派生关系索引 |
| room_v1/ | 房间布局的基线、候选与补零派生模型 |
| box_v1/ | 箱体布局的基线及补零派生模型 |

系数采用24位补码、20位小数，`lag_first=1`；补零派生件与原模型分别记账。
历史模型的推算结果不表示当前装置的实测稳定增益或听感收益。

正式部署的启动模型、行为参数和模型安装事务由 [冻结运行目录](../board/audio_replay/) 中的
`bootstrap-model.json`、`product-config.json` 及运行程序定义。本目录没有用于替换它们的默认部署模型。
现场重标定产生的候选须经本场景验证及安装回读核对后才能成为当前模型。
