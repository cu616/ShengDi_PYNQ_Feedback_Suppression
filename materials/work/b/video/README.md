## 想自己调位置 / 改文字

**拖拽调位置**：用浏览器打开 `core-loop.html`，在地址栏末尾加 `#edit`（整条变成
`file:///.../core-loop.html#edit`）。页面固定停在 17 秒——所有元素都在的时候。

- 右上角出现一个白面板；直接拖图里的方块、文字、箭头，拖到哪就是哪。
- 拖完点**生成代码**，框里会出现 `元素名  translate(x,y)` 的列表。
- 点**撤销全部**可以重来。

把框里的内容整段发过来，我写进源文件并重新渲染 mp4。**不要手改文件里的数字**——
箭头是贝塞尔曲线，端点、控制点、箭头方向三者要一起动，只改一个数会歪。

**只改文字**：搜文件里的 `class="lbl"`（26px 灰）、`class="small"`（21px 浅灰）、
`class="k"`（23px 黑）。字号和颜色在文件开头 `<style>` 里，改 `font-size` / `fill` 即可。

**改一句旁白或字幕**：搜那句话本身，直接替换中文即可，不影响排版（除非明显变长）。

## 动画说了什么、没说什么

- 说的：麦克风同时收到语音与回传；用**实际播放信号**预测回传分量；从麦克风信号里减掉那一份；输出继续参与下一轮。
- 明确否定：**不是把整体音量调小**，**不是检测到危险就静音**。结束卡直接写"抵消的是回传分量，不是把有用语音一起调小"。
- 画面角落常驻"原理示意（非实测波形）"——动画里的箭头和条块是示意尺度，不是板上抓的波形。
- 33 秒是完整版；25 秒处停在"相减完成"，A 的 §8 S3 段是 25 秒，直接截 0:25 即可，不用重渲。

## 数据图的口径

**图 1（322 Hz 三臂）**：无环路 45.44、环路闭合未抵消 49.19、已抵消 44.43 dB。派生量
环路提升 3.75、声学差 4.76、过冲 1.01，三者满足 `声学差 = 环路提升 + 过冲`。
**单频、单摆位、g = −8 dB**，不能外推成整机抗啸叫。出处：2026-10-28 宽残差 v3 实测。

**图 2（换模型）**：同一份独立验证数据（`bind4` 第 5、6 段），300–460 Hz 逐段时域抑制：
本轮重拟合 +4.17、已部署模型 +4.21、旧夹具模型 −4.40、全零 0.00 dB。
这是**离线预测残差**，不是 ASG、不是听感。出处：
[`recalibration-algorithm-2026-11-01/cases.json`](../../../../report/verification/recalibration-algorithm-2026-11-01/cases.json)。

两张图都写了条件、测量量和出处，没有把不同输入档、不同模型、不同场景的数拼在一张图上。
