## 与最新现场参数的对应

粗剪里的字幕和占位卡按下面这组数写，**改动任何一项都要同步改剧本与粗剪**：

| 项 | 值 | 出处 |
|---|---|---|
| 演示增益 | **+1.0 dB（q12 4596）** | demo-protocol §24，**替代 §17 的 +3.0 dB** |
| 单次运行时长 | **60 s** | §17 / §24 |
| 拨码含义 | **SW0 拨上 = 旁路**（关掉抵消） | §17 |
| 旁路起振 | 拨上后 **0.1 s 量级即啸叫**（§24 记 0.06–0.15 s），随后由**输出饱和保护**停声 | §24 |
| 最敏感频率 | 早上 **417 Hz**；当晚复核 405 Hz 的 \|H\| 升到 1.14–1.29 | §17 / §24 |
| 独立验证带内抑制 | **+7.9 / +6.4 dB**（4 段训练，`valid_pass`） | §23 |
| 一轮标定耗时 | **约 150 s**（训练段 6→4 之后；此前 183 s） | §23 |

**两个不要写死的地方：**

1. **增益。** 11-02 当天路径发生过未解释的变化：405 Hz 的 \|H\| 从早上的 0.667 升到 1.14–1.29，同一套配置下 +3.0 dB 从"稳"变成"0.05 秒失稳"，工作点因此退到 +1.0 dB。**字幕上的增益必须以拍摄当天实际写入的 `gain_q12` 为准**，拍完回读一次再上字幕。
2. **标定耗时。** 拟合加速、去掉每段位流重下都还没做，150 s 还会降。剧本 S2 的"实际耗时"留空，等实拍读数填，不预先写死。

## 怎么复现

```bash
# 1. 原理动画：渲染 25 fps 原生帧（约 70 秒）
python materials/work/b/video/render_frames_cdp.py --fps 25 --duration 32.8

# 2. 合成 mp4
ffmpeg -y -framerate 25 -i tmp/vid/frames/f%05d.png \
       -vf "scale=1920:1080:flags=lanczos,format=yuv420p" \
       -c:v libx264 -preset medium -crf 19 -movflags +faststart \
       materials/work/b/video/core-loop.mp4

# 3. 粗剪（依赖 core-loop.mp4）
python materials/work/b/video/make_roughcut.py

# 4. 两张备用数据图（数据硬编码在脚本里，带出处注释）
python materials/work/b/video/make_charts.py
```

全部离线生成，不联网、不调用在线服务。

**渲染用 `render_frames_cdp.py`，不要用旧的 `render_frames.py`。** 旧脚本每帧启动一次浏览器，
单帧约 3.5 秒，只能按 5 fps 渲染再插值到 25 fps——补出来的是复制帧，快速转场会顿。
新脚本只启动一次浏览器，用 CDP 调 `render(t)` 再连续截图，单帧 **0.087 秒**，
可 25 fps 原生渲染，全片 820 帧约 71 秒。

`render_frames_cdp.py` 默认先清空输出目录；**改了 `core-loop.html` 之后不要加 `--keep`**，否则渲的是旧画面。

## 想自己调位置 / 改文字

**调位置**：浏览器打开 `core-loop.html`，地址栏末尾加 `#edit`，页面停在 17 秒（所有元素都在）。

- 右键面板里的下拉框选元素，**用方向键挪**（普通 1 像素、Shift 10 像素），蓝字实时显示当前坐标；
- 或在画面里直接拖；
- 挪完点**生成代码**，把框里内容整段发过来，写进源文件并重渲。

**不要手改贝塞尔曲线的数字**——一条弧由"端点 + 两个控制点"共同决定，只改一个会歪。

**改字号**：文件开头 `:root` 里 `--fs` 一个数控全图（1.25 实测无重叠）。字体 `--font`、标题粗细 `--fwb` 同处。

**改一句旁白或字幕**：搜那句话本身直接替换，明显变长才需调版。

## 动画说了什么、没说什么

- 说的：麦克风同时收到语音与回传；用**实际播放信号**预测回传分量；从麦克风信号里减掉那一份；输出继续参与下一轮。
- 明确否定：**不是把整体音量调小**，**不是检测到危险就静音**。结束卡直写"抵消的是回传分量，不是把有用语音一起调小"。
- 角落常驻"原理示意（非实测波形）"——条块长度是示意尺度，不是板上抓的波形。
- 32.4 s 是完整版；25 s 处停在"相减完成"，S5 直接截 0:25。

## 两张数据图的定位（当前时间线未使用）

剧本已经改成"同一增益拨 SW0 起振"作为核心对照（S4），画面本身就是证据。这两张图对应的实验不是这一组，**硬塞进 S4 会造成拼接口径**，所以留在目录里备用：

**图 1（322 Hz 三臂）**：无环路 45.44、环路闭合未抵消 49.19、已抵消 44.43 dB。派生量环路提升 3.75、声学差 4.76、过冲 1.01，满足 `声学差 = 环路提升 + 过冲`。
**单频、单摆位、g = −8 dB**，不能外推成整机抗啸叫。出处：2026-10-28 宽残差 v3 实测。

**图 2（换模型）**：同一份独立验证数据（`bind4` 第 5、6 段），300–460 Hz 逐段时域抑制：本轮重拟合 +4.17、已部署模型 +4.21、旧夹具模型 −4.40、全零 0.00 dB。
这是**离线预测残差**，不是 ASG、不是听感。出处：[`recalibration-algorithm-2026-11-01/cases.json`](../../../../report/verification/recalibration-algorithm-2026-11-01/cases.json)。

要用于答辩补充材料可以，但必须连同条件一起放，不能只截一根柱。

## 边界

- 未验收的能力不写成已实现：S2 只讲"移动后要按一下重标定"，不讲"自适应"。
- 保护停声与抵消效果分开呈现：字幕写"触发输出饱和保护"，**不写"识别到啸叫就静音"**。
- 不写"刺耳的尖叫"——417 Hz 听感是低频嗡。
- 实拍段保留原声，旁白与音乐不盖住对照。
- 片中出现学校名、账号、私人路径时一律裁切或遮挡。
