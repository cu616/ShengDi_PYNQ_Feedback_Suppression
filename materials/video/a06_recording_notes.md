# a06 录屏说明（真实运行记录 + 真实 Vivado 资源占用，18 秒）

a06 两段素材各约 9 秒，**全部录真实界面**：
- 素材①：板卡现场跑一次 60 秒扩声，录**实时运行记录窗口**（不是演示页、不是截图拼接）；
- 素材②：录 **Vivado 2018.3 的真实实现报告界面**（打开实装位流的 routed checkpoint）。

## 一、素材①：真实 60 秒运行记录

### 1. 打开实时监视窗口

双击 `materials\video\a06_live_run_monitor.bat`。

窗口打开后先把字调大：右键窗口标题栏 → 属性 → 字体 → 选 28 左右 → 确定；
同时把窗口拉到接近全屏。

> 这个窗口只读板卡状态，不操作硬件；内容会随板卡真实状态刷新。

### 2. 录制窗口

开始录屏（1080p/30fps，原片不压缩）。

### 3. 按下面顺序操作板子（与之前的演示流程一致）

1. **SW0 保持在下方**；
2. **长按 BTN0 两秒** → 一键标定（监视窗口会依次显示 preparing / input_capture / quiet / capturing / fitting / validating / installing / ready）；
3. 途中按灯提示：提示音+LD1 时**说 2.5 秒**，LD2 与采集/拟合期间**保持安静**；
4. 看到 **LD1+LD2 就绪**后，**点一下 BTN1** → 开始 60 秒扩声；
5. **正常说话 60 秒**（中间不要停太久，不要碰 SW0）；
6. 跑满 60 秒后，监视窗口自动打印本次真实运行记录：
   - 状态 / 完成帧数 / 实际时长 / 结束原因 / 增益饱和 / 麦克风满量程 / 尾窗电平。

### 4. 录制要点

- a06 只占约 9 秒：建议录完整过程，后期取"运行中计时 + 结束记录"这一段；
- 最终画面要能看清 **completed / 60.00 s / 尾窗电平** 三项；
- 画面里不要出现用户名、IP、学校名、私人路径（监视窗口只显示运行数据，不打印这些）。

## 二、素材②：真实 Vivado 资源占用

### 1. 一键打开真实实现

双击 `materials\video\a06_open_utilization.bat`。

- 它会启动 **Vivado 2018.3**，打开**实装位流对应的 routed checkpoint**（`a06_deployed_routed.dcp`），
  自动执行 `report_utilization` 并弹出 Utilization 报告；
- 等 1–2 分钟，报告出现后：报告窗口内 **Ctrl+滚轮**放大，双击报告标签最大化。

### 2. 录 9 秒

停在 Block RAM Tile / DSPs / Slice LUTs / Slice Registers 四行，数字应显示：

| 资源 | 实装位流（Vivado 2018.3 实测 Routed） |
|---|---|
| Block RAM Tile | 112 / 140 = **80.00 %** |
| DSP48E1 | **3** |
| Slice LUTs | **3 587** |
| Slice Registers（FF） | **5 030** |

> 注意：旧稿里写的 3588 / 5018 来自 10-27 的另一版位流；板上实装位流是 11-01 版，
> **以 Vivado 现场显示为准**。旁白按实际画面念即可。

## 六、录制时长与原片剪辑（重要）

a06 成片只有 18 秒，**不需要把 3 分钟标定录进成片**。素材①只要求"一次完整 60 秒运行 + 结束记录"。

推荐顺序（最省时间）：

1. 先打开监视窗口，**不录屏**；
2. 正常做标定（长按 BTN0，约 3 分钟）→ 等 LD1+LD2 就绪；
3. **此时开始录屏**；
4. 点 BTN1 → 正常说话 60 秒 → 等待窗口打印 RUN FINISHED（completed / 60.00 s / 电平）；
5. 停止录屏（原片约 70 秒），后期剪出 9 秒。

如果希望保留完整流程的连续感，也可以从标定开始一直录（3 分钟+），后期只取运行段；
**只要是同一段连续录制、没有拼接/加速**，就符合"真实记录"。
说明里注明："标定过程在剪辑中省略，素材来自同一次连续录制。"

- 结束记录会一直留在监视窗口上，剪辑时停在那几行；
- 不要用加速、拼接或换镜头来压缩 60 秒。
