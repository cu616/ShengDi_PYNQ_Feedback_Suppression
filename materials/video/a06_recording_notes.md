# a06 录屏说明（运行记录 + 资源占用，18 秒）

本页给拍摄者：两段素材、各约 9 秒，合成 a06（总 18 秒）。均为**屏幕录制**，不要拍屏。

## 一、录屏前设置（两条素材通用）

1. 浏览器全屏（F11），分辨率 1920×1080，系统缩放 100–125%；
2. 字体已按 1080p 加大，录前确认小字仍可读；
3. 关闭通知、隐藏任务栏、关闭输入法候选条；
4. **隐私检查**：画面上不得出现用户名、IP、学校名、私人路径。
   本目录两个 HTML 已去除路径/用户名/网络信息，只保留版本哈希；
5. 录制参数：1080p、30 fps、**原片不压缩不转码**，录完直接存。

## 二、素材 ①「60 秒运行记录」（约 9 秒）

- 打开 `a06_run_record.html`，全屏；
- 录制时从上往下缓慢滚动一屏，停在 "completed / 60.00 s / 0 饱和" 三行处约 3 秒；
- 旁白（可选）："增益 +1 dB、请求 60 秒，实际跑满 60.00 秒，自然结束，没有触发保护。"

关键数字（画面已含）：`gain_q12=4596（+1.0 dB）`、`run_seconds=60`、
`completed_frames=2,929,687`、`实际 60.00 s`、`stop_reason=completed`、`增益饱和 0`、`麦克风满幅 false`。

> 如需更"终端"观感，也可以改用文字版：把同一组字段用终端大字号打印（本目录 README 有字段清单），
> 但画面内容必须与上面的数字一致，不得改成新数据。

## 三、素材 ②「Vivado 实现后资源占用」（约 9 秒）

- 打开 `a06_utilization.html`，全屏，停留约 9 秒；
- 若拍摄机装有 Vivado 且能打开本次实现的工程：**优先录 Vivado 的 Report Utilization 界面**，
  数字必须与本页一致（BRAM 112/140 = 80%、DSP 3、LUT 3588、FF 5018）；
- 旁白（可选）："这是实装位流在 xc7z020 上的实现后资源占用。"

## 四、文件名与交付

```
a06-1_run-record_60s_<拍摄日期>.mp4
a06-2_utilization_<拍摄日期>.mp4
```

- 文件名以 `a06` 开头，原片直出，不压缩、不转码、不加片头片尾；
- 微信发送勾选「原视频」；
- 若重拍过，在说明里写明"素材①重拍 N 次，采用第 N 次"，不要删掉重拍记录。

## 五、a06 说明（随素材一起交付）

```
a06 运行记录与资源表
- 素材① 运行记录：gain_q12 = 4596（+1.0 dB），run_seconds = 60，
  实际 60.00 秒 completed，未触发保护；拍摄时间 <YYYY-MM-DD HH:MM>；重拍情况 <无/第N次>
- 素材② 资源占用：实装位流 audio_replay v3，BRAM 112/140=80%、DSP 48E1 3、LUT 3588、FF 5018；
  拍摄时间 <YYYY-MM-DD HH:MM>；重拍情况 <无/第N次>
- 两段均为屏幕录制，原片未压缩未转码。
```

## 六、注意

- 素材①展示的是**已保存的真实运行记录**（当时的产品面板试次，60 秒跑满），不是新拍摄的假数据；
  画面上"已保存记录回放"一行不要裁掉。
- 不要把 60 秒记录说成"无限连续运行"；本系统是**60 秒一次**的持续运行检查。
- 保护触发不等于识别啸叫，本素材不含保护触发镜头。
