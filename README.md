# 声堤：实时声反馈啸叫抑制系统

ShengDi_PYNQ_Feedback_Suppression 是基于 PYNQ-Z2 的声反馈抑制项目，目标是在真实硬件上提高稳定扩声音量，并测量延迟、音质和 FPGA 资源开销。首版面向桌面扩声，助听场景留作后续探索。

## 当前状态

更新：2026-10-11。目前处于音频通路验证阶段，尚未完成啸叫抑制算法。结果来自用户上板实验反馈，本仓库暂未收录板上 Notebook 和原始 WAV。
