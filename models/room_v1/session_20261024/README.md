# 会话修正候选（2026-10-24）

**只对 2026-10-24 这一次现场会话有效。** 换夹具、换音量、移动话筒或音响、改注入电平，即失效。

生成命令：`python scripts/make_session_correction.py --model models/room_v1/candidate_512.json --out <本目录>`

## 用之前必须知道的

- 它**不是**新训练的模型，是同一模型乘了一个现场掩模；`derived_artifacts`，不进 `models` 注册表，
  C 的 `select_model` 不会自动挑它。
- 预测 +6.74 dB 由 8.4 kHz 修正后的**低频残差**决定（381 Hz），不是 8.4 kHz 了。
  想把余量再拉大，得改善 300–1000 Hz 的拟合质量（该处相干只有 0.81），不是再修 8.4 kHz。
- 若实测仍然在 0 dB 啸叫，先看主频：还在 8.2–8.6 kHz → 带内修正不准；换到 300–1000 Hz → 低频短板。
  两条都指向"用现场 npz 重拟合"，而不是继续调这个掩模。
