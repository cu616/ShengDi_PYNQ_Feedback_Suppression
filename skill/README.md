# 技能包（skill/）

本目录按评测指南 **3.3.5.2** 组织：技能包是把与大模型协作过程中沉淀的经验**显式提炼**出来，
供他人直接复用的目录。评价标准是**可复用性**——陌生队伍拿到本目录，能否直接用到自己的题目上。

## 每项技能的固定字段（指南 3.3.5.2 要求）

每个 `SKILL.md` 必须包含下面五节，缺一不可：

1. **适用场景**：什么情况下该用；需要什么前置条件。
2. **使用方法**：可直接执行的步骤或可直接粘贴的提示词模板。
3. **已验证效果**：在什么环境、用什么证据验证过；给出命令/输出或证据链接。
4. **失效条件**：什么情况下结论不成立，或必须重新验证。
5. **来源**：从哪些失败或观察中总结出来的，保留原始记录位置。

## 贡献规范

- 贡献流程、模板与检查清单见 [CONTRIBUTING.md](CONTRIBUTING.md)。
- 新增技能 = 新建 `skill/<skill-name>/SKILL.md`（目录名用英文小写+连字符），
  并在本页索引表补一行。`<skill-name>` 建议能直接说明用途，如 `pynq-overlay-io`。
- 只写**验证过**的做法；未验证的只能标为“候选”，并写明还缺什么证据。
- 不把账户令牌、校园网凭据、私人录音或未经同意的第三方材料放进技能包。
- 复用他人代码必须保留来源与原许可证。

## 技能包与证据的关系

技能包写“怎么做、为什么这样做、什么时候不成立”；具体某次实验的数字与原始记录在
[report/](../report/) 与 [docs/log/](../docs/log/)，技能包只链接、不复述，避免两处数字漂移。

## 早期麦克风排查（保留）

依据 [音频调试记录](../docs/log/experiments/2026-10-audio-debug.md)：
先确认已知 WAV 播放，再用成功耳麦核对 MIC 输入、MAX4466 核对 LINE_IN，最后逐项比较待测组合。
适用范围：PYNQ-Z2、base overlay、AudioADAU1761；输入选择必须与实际接口一致，重载 overlay 后重新选择输入。
三段/四段数量不能证明触点兼容，噪声也不等于人声。
失效边界：没有导通和带载偏置测量时，不能把稳定噪声直接定性为放大不足、偏置不足或转接线损坏。
以上是早期硬件经验，不是本轮候选的验收入口。
