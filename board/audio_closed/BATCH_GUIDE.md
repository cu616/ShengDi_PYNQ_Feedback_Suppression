此前四项零/真实模型测试已返回bit_exact=true且无饱和，2秒人声旁路也完成。不要重复这些基础项目。本批用于提高试验效率、初步找到可用增益范围，未测MSG/ASG。

## 1. 更新文件

在电脑打开本文件所在audio_closed文件夹。在板卡Jupyter打开base/audio/audio_closed，上传以下四个文件：

- closed_trial.py：覆盖旧版，新增“配置就绪且静音时等待START”。
- closed_batch.py：新增批次控制和汇总。
- manifest.json：覆盖旧版，匹配更新后的文件。
- batch_trial.ipynb：新增批次操作入口。

每个文件点击Upload完成上传；同名提示选择覆盖。bit/hwh、模型和已有录音不用上传或更改。旧试验Notebook保留，避免丢失输出。

## 2. 执行第1个代码格

打开batch_trial.ipynb，点击第1个代码格，按Shift+Enter。它只校验文件和载入代码。看到BATCH_PACKAGE_OK才继续；哈希报错先检查文件是否上传齐全。

## 3. 准备现场

箱体、麦克风、音响接线和位置保持标定状态。手机在箱外固定位置循环播放普通音量人声，整批不要调整手机音量或移动设备。不戴耳机，可以立即切断音响电源。

计划共8项：−30、−24、−18、−12dB，每档旁路/抵消各2秒；hp_volume固定40。没有要求直接开0dB。每次切换和读取数据需要额外时间，16秒只是最大累计发声时间，不是整批总耗时。

## 4. 执行第2个代码格，跟随输入框

按Shift+Enter执行一次；之后输入框用Enter提交。

| 提示 | 你输入什么 | 接下来会发生什么 |
|---|---|---|
| 现场就绪 | READY | 确认现场条件及本地采样保存，开始配置 |
| 配置已完成、当前静音 | START | 立即开始当前2秒试验 |
| 听感 | 0或1 | 0为没听见、1为人声，且结束安静；准备下一项，仍需你再次START |
| 听感 | 2、3、4或q | 分别为杂音、尖叫/增长、结束未静、主动停止；停止整批 |
| 任何START提示 | q | 取消当前试验并恢复，停止整批 |

尖叫时立即切断音响电源；不能把输入框当作播放中的实时停止按钮。脚本错误、算术不匹配、饱和或两项配置不一致也会停止整批。停止后不要重跑来绕过原因。

## 5. 发回一个文件

输出末尾显示batch_results/batch_…/summary.json。在Jupyter文件列表进入该目录，下载并返回summary.json即可。summary.csv便于表格查看；NPZ原始录音留板。每次运行使用独立目录，中途停止也会保留已完成记录及停止原因。
